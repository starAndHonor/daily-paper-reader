## 摘要
流式视频扩散模型在交互式和动态世界模拟方面取得了实质性进展，但传统下一帧生成中嵌套的自回归和去噪循环阻碍了实时部署。最近的滚动窗口方法在不同噪声水平下对多个连续帧进行流水线去噪，提高了吞吐量和长期稳定性。然而，它们以相同的精细空间粒度对每个状态进行词元化，在联合去噪窗口中留下了显著的噪声依赖冗余。我们提出了Ms.Forcing，一种高效的流式视频生成范式，它能根据每个状态的噪声水平自适应调整空间粒度。其多尺度分块（MSP）为噪声较大的状态分配更粗糙的分块，将活动窗口中的词元数量减少45%，而多尺度自注意力（MSSA）将可见非汇合键和值的密度匹配到每个查询的尺度，进一步降低注意力成本。由于两种调度都由窗口位置固定，Ms.Forcing保持了静态且硬件友好的计算图。我们进一步引入了同质噪声水平DMD（H-DMD），它从共享相同源噪声水平的干净预测中组装每个假视频，从而减少DMD训练序列与推理时展开之间的不匹配。多尺度设计有助于抵消通过重叠窗口反向传播带来的额外训练成本。我们通过定量和定性实验表明，Ms.Forcing在单个H200 GPU上达到22.84 FPS，比Rolling Forcing快39.6%，同时在短视频和长视频生成设置中显著提高了VBench分数。

## Abstract
Streaming video diffusion models have made substantial progress toward interactive and dynamic world simulation, but the nested autoregressive and denoising loops of conventional next-frame generation hinder real-time deployment. Recent rolling-window methods pipeline denoising across multiple consecutive frames at different noise levels, improving throughput and long-horizon stability. However, they tokenize every state at the same fine spatial granularity, leaving substantial noise-dependent redundancy in the joint denoising window. We propose Ms.Forcing, an efficient streaming video generation paradigm that adapts spatial granularity to each state's noise level. Its Multi-Scale Patchification (MSP) assigns coarser patches to noisier states, reducing the active-window token count by 45%, while Multi-Scale Self-Attention (MSSA) matches the density of visible non-sink keys and values to each query scale to further reduce attention cost. Because both schedules are fixed by window position, Ms.Forcing retains a static, hardware-friendly computation graph. We further introduce Homogeneous-Noise-Level DMD (H-DMD), which assembles each fake video from clean predictions sharing the same source noise level, thereby reducing the mismatch between DMD training sequences and inference-time rollouts. The multi-scale design helps offset the additional training cost of backpropagating through overlapping windows. We include both quantitative and qualitative experiments to show that Ms.Forcing reaches 22.84 FPS on a single H200 GPU, 39.6% faster than Rolling Forcing, while significantly improving VBench scores in both short video and long video generation setting.

## 1. 核心问题与整体含义（研究动机和背景）

- **问题背景**：大规模视频扩散模型能生成高质量动态视频，但传统双向去噪过程延迟高，不适合交互式流式生成。现有方法如“滚动窗口去噪”（Rolling Forcing, RF）将去噪步骤沿时间轴流水线化，在一个联合窗口中同时处理多个不同噪声水平的帧，提高了吞吐量和长期稳定性。
- **核心缺陷**：RF 对所有状态使用相同的**精细空间粒度**（fine spatial granularity）进行分词（patchification），忽略了去噪过程本身的**粗到细**特性——高噪声状态主要负责低频结构，低噪声状态才需精细细节。这种粒度冗余导致大量不必要的计算，限制了实时部署。
- **整体含义**：本文旨在通过根据每个状态的**噪声水平自适应调整空间粒度**，在保证甚至提升生成质量的前提下，大幅加速流式视频生成，使其更接近实时交互应用。

## 2. 方法论：核心思想、关键技术细节

### 核心思想
利用滚动窗口中窗口位置与噪声水平的**确定性对应关系**，设计**静态多尺度调度**：高噪声状态用更粗的分块、更少的注意力上下文，低噪声状态保持精细处理。

### 关键技术细节

- **Multi-Scale Patchification (MSP)**  
  - 为联合去噪窗口中位置 \(l\) 的状态（对应噪声水平 \(t_l\)）分配一个专属的区块大小 \(p_l\)，满足 \(p_1 \le p_2 \le \dots \le p_T\)（例如 \(p, p, 2p, 2p, 2p\)）。  
  - 每个区块大小对应一个“层级”，共享受训练的 DiT 骨干，但各层拥有轻量级专用模块（patch embedding/de-embedding、LoRA 适配器、潜在残差分支）。  
  - 效果：相比 RF 统一使用 native 大小，MSP 将联合窗口内 token 总数减少 **45%**（当 \(T=5\) 时保留比例 \(\rho_{tok}=0.55\)）。

- **Multi-Scale Self-Attention (MSSA)**  
  - 在注意力计算中，对于来自位置 \(a\) 的 query，只让其可见的**非汇合（non-sink）KV** 的空间密度不超过 query 自身区块大小的密度。  
  - 具体实现：根据 query 与 key 的区块大小比例 stride = \(\max(1, p_a/p_b)\)，对非汇合 KV 进行**空间下采样**；汇合帧（sink frame）始终保留全分辨率。  
  - 效果：在 MSP 基础上进一步减少约 **12.9%** 的点积注意力计算量（对于 5-step RF 配置）。

- **Homogeneous-Noise-Level DMD (H-DMD)**  
  - 识别出 RF 在 DMD 训练中的**训练-推理不匹配**：RF 将不同滚动窗口的干净预测拼接成训练用假视频（heterogeneous assembly），而推理时只使用窗口头部帧，导致帧级噪声边际不一致。  
  - H-DMD 改为：每次迭代中随机采样一个窗口位置 \(j\)，然后从所有连续滚动窗口中提取该位置对应的干净预测，组装成**同源噪声水平**的假视频序列。  
  - 这一做法虽然需要梯度穿过重叠窗口，但 MSP 和 MSSA 降低了计算量，使得训练可行；同时去除了对辅助 Self-Forcing 训练更新的需求。

- **整体框架**：  
  - 基模型：Wan2.1-T2V-1.3B。  
  - 训练流程：先使用 ODE 解对初始化因果注意力；再用 6K ODE 解对预热多尺度模块；最后进行 DMD 蒸馏（共 1400 步）。  
  - 推理时：每个滚动步中，MSP 和 MSSA 按固定调度执行，计算图静态，硬件友好。

## 7. 优点

1. **巧妙利用先验结构**：滚动窗口中噪声水平与位置固定对应，直接设计静态多尺度调度，无需运行时动态路由，保持计算图硬件友好。
2. **系统性的冗余消除**：从分词（MSP）到注意力（MSSA）到训练策略（H-DMD）均考虑了噪声依赖的冗余。
