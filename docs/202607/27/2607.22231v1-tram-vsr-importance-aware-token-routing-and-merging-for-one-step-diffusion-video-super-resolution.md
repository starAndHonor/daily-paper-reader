## 摘要
利用大规模扩散变换器（DiT）先验的视频超分辨率（VSR）可实现卓越的感知质量，但由于处理密集时空令牌序列的二次计算成本，通常不切实际。现有的效率导向方法面临不可逆的细节丢失和时间闪烁风险，这一弱点在一步扩散模型中尤为突出。为此，我们提出TRaM-VSR，一种令牌路由与合并框架，用于自适应令牌分配，同时利用上下文感知视频先验和网络级先验。首先，通过融合运动敏感的时间线索与语义文本相似性来估计令牌重要性，隔离动态对象和结构边界。接着，通过离线规划器进一步校准和调整该重要性，以引导令牌在最优分组的网络块之间进行路由。技术上，在每个路由组内，结构关键令牌在高保真局部流中处理，而信息较少的令牌则聚合为紧凑的全局流，两者均受网络深度调制，并与扩散模型的多粒度特性对齐。大量实验表明，TRaM-VSR在显著加速推理的同时，保持最先进的重建质量和鲁棒的时域一致性。代码开源于https://github.com/Ree1s/TRaM-VSR。

## Abstract
Video super-resolution (VSR) using large-scale Diffusion Transformer (DiT) priors achieves exceptional perceptual quality but is often impractical due to the quadratic computational cost of processing dense spatio-temporal token sequences. Existing efficiency-oriented methods risk irreversible detail loss and temporal flickering, a vulnerability especially pronounced in one-step diffusion models. To address this, we propose TRaM-VSR, a Token Routing and Merging framework for adaptive token allocation, leveraging both context-aware video priors and network-level priors. First, token importance is estimated by fusing motion-sensitive temporal cues with semantic text similarity, isolating dynamic objects and structural boundaries. Next, this importance is further calibrated and adjusted by an offline planner to guide routing across optimally grouped network blocks. Technically, within each routed group, structurally critical tokens are processed in a high-fidelity local stream, while less informative tokens are aggregated into a compact global stream, both modulated by network depth and aligned with the multigranular nature of diffusion models. Extensive experiments show that TRaM-VSR accelerates inference significantly while preserving state-of-the-art reconstruction quality and robust temporal consistency. The code is available at https://github.com/Ree1s/TRaM-VSR.

- **整体含义**：本文提出TRaM-VSR，旨在通过自适应令牌路由与合并，在保持高重建质量和时域一致性的前提下，显著加速一步扩散视频超分。核心思想是联合利用视频内容先验（运动、语义）和网络结构先验（深度层级），实现计算资源向重要区域的动态倾斜。

## 2. 方法论：核心思想、关键技术细节

### 2.1 核心思想
- 将令牌处理分为两个阶段：**离线风险引导的区间规划** + **在线重要性感知路由与合并**。
- 对DiT块进行分组（routed intervals），仅在选定区间内执行令牌压缩，其余层保持全分辨率处理。
- 在路由区间入口处，根据**语义‑时间融合重要性**决定保留哪些令牌；区间内部采用**双流架构**（局部高保真流 + 紧凑全局流）；区间出口通过**身份恢复**机制还原全分辨率令牌网格。

### 2.2 关键技术细节

#### (a) 风险引导的离线区间规划（Sec 4.2）
- 在无压缩基线模型上计算两个层信号：
  - **局部更新幅度** Δℓ
  - **端到端扰动偏移** Sℓ（模拟在ℓ层仅压缩时的输出偏差）
- 定义路由风险代理：`rss_ℓ = Δ̂ℓ · Ŝℓ`（归一化后）
- 通过sigmoid映射得到平滑路由门控 `gate_ℓ ∈ (0,1)`，风险越低，门控值越高。
- 对候选窗口（长度为W）评分 `Score(Ω) = mean(gate)`，贪婪选取R个不重叠高评分区间。
- 默认配置2个路由区间，每个区间使用相同的丢弃比率ρ（超参数）。

#### (b) 重要性感知令牌路由（Sec 4.3）
- **文本相似重要性**：对每个图像令牌，计算其与文本平均嵌入的余弦相似度，进行min-max归一化。
- **时间曲率引导（TCG）重要性**：将令牌重塑为帧‑空间组结构，计算相邻帧间速度向量的夹角余弦，取反余弦值作为曲率κ，反映运动剧烈程度。
- **融合**：加权平均（权重wt:文本，wp:曲率），再次归一化 → 得到每个令牌的语义‑时间重要性得分。
- 根据给定丢弃比率ρ，保留Top-K重要令牌（`K = max(1, N-⌊ρN⌋)`），其余为丢弃集合。

#### (c) 双流令牌合并与身份恢复（Sec 4.4）
- **路由入口（合并）**：
  - 保留令牌送入**局部流**（High‑Fidelity Local Stream）。
  - 丢弃令牌按帧分组成`Gr`组（组数由全局比率γ、上下限决定），每组均值池化得到**全局令牌**（Compact Global Stream）。
  - 工作令牌 = [局部流令牌；全局令牌]。旋转位置编码分别按原始索引和平均索引处理。
- **路由区间内部计算**：双流令牌共同通过该区间所有DiT块，注意力复杂度从`O(N²)`降至约`O((K+Gr)²)`。
- **路由出口（恢复）**：丢弃位置还原为路由入口处保存的原始令牌特征（快照），局部流位置用更新后的输出覆盖。全局流特征被完全抛弃，避免噪声注入。

### 2.3 算法流程（文字描述）
1. 离线规划器在少量校准数据上计算各层门控值，选择风险最低的R个连续区间。
2. 对每个路由区间：
   - 计算输入令牌的语义‑时间重要性得分。
   - 按丢弃比率ρ划分保留集和丢弃集。
   - 保留集 → 局部流；丢弃集 → 均值池化为全局流。
   - 双流令牌拼接后通过区间内各DiT块。
   - 区间出口：丢弃位置还原原始快照，保留位置更新为局部流输出。
3. 整个推理过程为单次前向传播，保留所有区块的原始参数不变，仅修改令牌流。
