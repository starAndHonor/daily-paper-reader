## 摘要
长上下文建模是大语言模型的一项关键能力，然而注意力的二次复杂度仍然是一个关键瓶颈，尤其是在计算密集的预填充阶段。我们之前的工作FlashPrefill通过即时模式发现和基于最大值的动态阈值来降低这一成本；然而，它仍然是一个算法原型，距离生产部署尚有差距。在本文中，我们提出了FlashPrefill V2，它从原型发展为面向实际长上下文服务的方案，主要沿三个维度进行改进。首先，我们引入了一个均值校正项，有效抑制了近似误差，即使在极端稀疏度下也能将性能下降控制在可管理范围内。其次，我们重新设计了稀疏注意力算子，采用PackGQA内存访问、线程束专业化和乒乓流水线，与最新的FlashAttention-3/4实现完全对齐，并支持FP8推理以满足实际量化需求。第三，FlashPrefill V2原生支持分页KV缓存和连续批处理，使其能够作为注意力后端集成到SGLang等现代推理框架中。在NVIDIA H20 GPU（最广泛部署的推理加速器之一）上进行的大量评估表明，FlashPrefill V2在128K上下文长度下，FP8和BF16精度下分别比FlashAttention-2实现了高达47.26倍和27.19倍的加速；在FP8下，与对齐FA3/4的密集基线相比，仍然实现了30.49倍的加速。

## Abstract
Long-context modeling is a pivotal capability for Large Language Models, yet the quadratic complexity of attention remains a critical bottleneck, particularly during the compute-intensive prefilling phase. Our previous work, FlashPrefill, mitigates this cost through instantaneous pattern discovery and max-based dynamic thresholding; however, it remains an algorithmic prototype that is still distant from production deployment. In this paper, we present FlashPrefill V2, which evolves FlashPrefill from a prototype toward practical long-context serving along three dimensions. First, we introduce a mean correction term that effectively suppresses the approximation error, keeping performance degradation manageable even at extreme sparsity levels. Second, we redesign the sparse attention operator with PackGQA memory access, warp specialization, and pingpong pipelining, fully aligning with the latest FlashAttention-3/4 implementations and supporting FP8 inference to meet practical quantization requirements. Third, FlashPrefill V2 natively supports paged KV cache and continuous batching, allowing integration as an attention backend in modern inference frameworks such as SGLang. Extensive evaluations on NVIDIA H20 GPUs---among the most widely deployed inference accelerators---demonstrate that FlashPrefill V2 delivers up to 47.26x and 27.19x speedups over FlashAttention-2 at 128K context length under FP8 and BF16 precision, respectively, and, in FP8, still achieves a 30.49x speedup against an FA3/4-aligned dense baseline.

### 2. 方法论

#### 2.1 总体框架

沿用 FlashPrefill 的两阶段架构：

- **阶段一（索引/选择）**：使用均匀分布的探针查询对 KV 块做均值池化评分，经动态阈值筛选出重要块，输出 CSR 索引；
- **阶段二（稀疏注意力）**：仅对选中块执行精确注意力，未选中块由**均值校正路径**补偿，两路结果在 online softmax 中合并。

#### 2.2 均值校正项（Mean Correction）

- **动机**：极端稀疏下被丢弃的 softmax 概率质量不可忽略（Eq. 4 近似误差增大）。
- **方法**：对每个被剪枝块 J，用其均值统计量（k̄ⱼ、v̄ⱼ）构造替代项 |Bⱼ|e^{s̄ⱼ}(v̄ⱼ,1)，同时贡献分子与分母（Eq. 6），以恢复被丢弃的概率质量。
- **误差理论**：
  - 质量替代项具有二阶精度；分子替代项保留一阶协方差项（Eq. 7）；
  - 输出偏移受三个条件控制：max-based 阈值限制单块质量占比、块内协方差有界且独立性条件下为零、相对直接丢弃，误差从块间偏差降为块内偏差（Eq. 8-11），量级为 O(δ_rms)。
- **实现**：校正块作为流水线中的额外一次迭代，分数加 log|Bⱼ| 偏移以表示 |Bⱼ| 个 token，复用同一 MMA 流水线，无需额外 kernel launch。

#### 2.3 Hopper 对齐的稀疏注意力算子

- **PackGQA 访存**：将 Q 从 R^{L×Hq×d} 重塑为 R^{(g·L)×Hkv×d}（g 为 GQA 比例），使每个 KV 块被同一 KV 组内全部 query 行共享，减少 KV 重复装载，索引元数据缩小 g 倍，并消除短序列下的 tile 浪费。
- **Warp 专用化与乒乓流水线**：一个生产者 warpgroup 用 TMA/cp.async 异步装载 KV，两个消费者 warpgroup 执行 wgmma；GEMM 与 softmax 在消费者内部乒乓重叠（Eq. 14）。
- **FP8 执行**：per-tensor 缩放 + e4m3 量化，概率片段经 2⁸ 偏移映射到 [0,256] 以充分利用动态范围；PV GEMM 通过寄存器重排（column-major V）或共享内存转置（row-major V）适配 wgmma 的布局要求，全程无全局内存流量。
- **索引驱动稀疏遍历**：CSR 索引按倒序遍历；生产者与消费者独立计算同一块序列，无需额外同步；KV 分裂按选中块数等分而非按位置范围，实现负载均衡。
- **稀疏感知负载均衡**：始终允许分裂，设备端按因果工作量降序调度，每 tile 的选中块列表按计数均分。

#### 2.4 端到端流水线与服务集成

- **单遍评分与选择**：fused kernel 维护在线 tile 最大值与块能量，直接写入索引缓冲区，消除独立分数缓冲和第二次 GEMM 传递。
- **分页与变长执行**：K/V 经页表寻址（Eq. 22）；varlen 感知的持久调度器按各请求长度枚举工作单元，与连续批处理执行模型一致。
- **SGLang 集成**：作为标准注意力后端，在 extend（prefill）阶段运行两阶段流水线，decode 回退到稠密注意力；无需改动模型定义、KV 缓存布局或调度逻辑。
- **开销分析**：索引与校正阶段均作用于每块一个池化向量，辅助 FLOPs 随保留密度增大而消失（Eq. 24）；在 ρ=4%、B=128 时辅助开销约 19%。

- **对比基线版本差异**：与 MInference、FlexPrefill 等基线对比时未说明其是否运行在同等优化后的 CUDA 内核上，跨框架比较存在固有偏差。

### 9. 总结与展望

- **总体结论**：FlashPrefill V2 通过三项关键创新——均值校正项、对齐 FA3/4 的 Hopper 稀疏算子、以及分页 KV 与连续批处理的原生支持——将块稀疏注意力从算法原型推进至生产可用水平。在 H20 平台上，128K 上下文下相对 FA2 实现 27–47× 的预填充加速，端到端 TTFT 降低 2–4×，同时精度损失控制在 1–2 分以内，证明了"稀疏感知的预填充加速 + 生产级服务集成"是一条可行且实用的技术路径。
- **对领域的影响**：该工作表明，稀疏注意力在生产环境中的落地瓶颈不在算法本身，而在于与硬件执行模型（TMA/wgmma/FP8）和框架调度语义（分页、varlen、连续批处理）的深度对齐；其均值校正方法也为其他近似注意力算子提供了"补偿被截断概率质量"的通用数学框架。
- **未来方向**：
  - 将预填充阶段发现的稀疏模式复用于解码阶段，突破 decode 阶段无法稀疏化的局限；
  - 将算子迁移至 Blackwell 等新一代架构，利用更细粒度的张量指令进一步提升效率；
  - 设计自适应 chunk 大小选择策略，缓解小 chunk 下索引阶段重复执行的性能回退；
  - 将均值校正思想推广至 streaming attention、sliding window 等混合稀疏模式。

**总结论**：FlashPrefill V2 是块稀疏预填充注意力领域一项工程完成度极高的系统性工作，其价值不仅体现在 27–47× 的算子加速这一数字上，更在于首次以完整形态回应了稀疏注意力走向生产部署的全部关键挑战。尽管在硬件覆盖、解码阶段稀疏化、短序列效率等方面仍有局限，但其方法论与工程实践为后续长上下文推理优化提供了坚实基线。
