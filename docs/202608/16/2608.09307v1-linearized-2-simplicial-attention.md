## 摘要
我们通过将三线性得分重写为复合查询与键之间的内积，提出了一种线性化形式的2-单纯形注意力，使得沿一个令牌轴的求和与普通softmax注意力具有相同的形式。然后，我们使用正随机特征近似该求和，并将整个历史存储在一个固定大小的状态中，而第二个轴则在一个短窗口内的近期令牌上保持显式。这使我们能够在序列长度上实现线性成本，同时获得窗口化2-单纯形注意力所缺乏的全局覆盖。我们使用自定义Triton内核实现它，并将其与Kimi Delta注意力结合，构建了一个完全没有softmax注意力的模型。在匹配计算量下，该模型在比较的架构中取得了最高的平均下游准确率，并且在16k上下文下，它相对于KDA混合模型提高了平均准确率，同时将LAMBADA困惑度从715.6降至602.6。

## Abstract
We present a linearized form of 2-simplicial attention by rewriting the trilinear score as an inner product between a composite query and a key, so that the sum over one token axis takes the same form as ordinary softmax attention. We then approximate this sum with positive random features and store the entire past in a fixed-size state, while the second axis stays explicit over a short window of recent tokens. This enables us to achieve linear cost in sequence length combined with a global reach that windowed 2-simplicial attention lacks. We implement it with custom Triton kernels and combine it with Kimi Delta Attention to build a model with no softmax attention at all. Under matched compute, this model achieves the highest mean downstream accuracy among the compared architectures, and at 16k context it improves mean accuracy over a KDA hybrid while lowering LAMBADA perplexity from 715.6 to 602.6.

## 论文总结：线性化2-单纯形注意力（Linearized 2-Simplicial Attention）

### 1. 核心问题与研究动机

- **背景**：Softmax注意力机制为语言模型提供了对历史token的直接内容访问能力，但其**O(n²)的计算复杂度和不断增长的KV缓存**是部署长上下文模型的瓶颈。线性注意力、状态空间模型等通过固定大小状态压缩历史，但牺牲了精确检索与选择性更新能力；Delta-rule类模型（如KDA）通过纠错式关联记忆改善了这一权衡。
- **2-单纯形注意力的价值与困境**：2-单纯形Transformer引入三线性分数，使查询能同时关联两个早期token，在系统性泛化和三元依赖任务上具有理论优势。但它需要对token对平面计算联合softmax，**计算复杂度高达O(T³)**。已有工作（Roy et al., 2025）通过双向窗口限制使其可落地，但代价是**失去全局覆盖能力**。
- **核心问题**：能否在保持2-单纯形注意力全局感受野（至少一个token轴覆盖完整因果前缀）的同时，将计算复杂度降为序列长度的线性函数？

### 2. 方法论：LinSimp层

- **核心思想**：将三线性分数按特定方向分解，使沿一个token轴（j轴）的求和变成标准的指数点积核，进而可用**正随机特征（positive random features）**近似，将整个历史压缩为固定大小的线性注意力状态；另一轴（锚轴c）保留为最近w个token的显式窗口。
- **关键数学推导**：
  - 坐标级三线性分数 `s_ijc = ⟨τ q̂_i, k̂_j, r̂_c⟩ = ((τ q̂_i) ⊙ r̂_c)ᵀ k̂_j`，对固定 (i, c)，定义复合查询 `z_ic = (τ q̂_i) ⊙ r̂_c`，则 `exp(s_ijc) = exp(z_icᵀ k̂_j)` 恰为标准指数点积核。
  - 使用正随机特征映射：`φ(x) = m^(-1/2) · exp(Ωx − ‖x‖²/2 · 1)`，其中Ω ∈ R^(m×D) 为高斯随机特征矩阵。Lemma 1证明该映射满足 `E[φ(x)ᵀφ(y)] = exp(xᵀy)`（无偏估计）。
  - **前缀状态压缩**：`M_i = Σ_{j≤i} φ(k̂_j)v_jᵀ ∈ R^(m×D_v)`（关联记忆状态），`a_i = Σ_{j≤i} φ(k̂_j) ∈ R^m`（归一化状态），两者均可增量更新——单步更新代价与历史长度无关。
  - 锚轴窗口化：`C_i = {max(1, i−w+1), …, i}`，仅对最近w个锚点显式计算。
  - 最终输出：`o_i = N_i / (Z_i + ε)`，其中 `N_i = Σ_{c∈C_i} (φ(z_ic)ᵀM_i) ⊙ u_c`，`Z_i = Σ_{c∈C_i} φ(z_ic)ᵀ a_i`，后接RMSNorm与学习门控。
- **Theorem 1（复杂度保证）**：固定特征秩m和锚窗口w时，总计算量为O(T·w·m·(D+D_v))，即**序列长度T的线性函数**；自回归推理时每头状态大小仅为 O(mD_v + m + w(D+D_v))，与序列长度无关。
- **实现细节**：
  - 自定义Triton前向/反向内核，采用32-token分块、在线最大值稳定（防止特征溢出）、分块边界状态重建策略；
  - 反向传播采用"查询并行"+"分块并行"两遍扫描，避免存储T×m×D_v张量；
  - 使用正交随机特征库（QR分解+符号修正+χ_D半径缩放），确保无偏性与低方差；诊断测试显示符号修正可使核近似误差从6×10⁻²（m=1024到262144均不下降）降至3×10⁻³（m=262144）。
  - 与KDA（Kimi Delta Attention）组合构建无softmax注意力模型：18层KDA + 6层LinSimp。

### 3. 实验设计

  - **数学场景**：FineMath-4+（高质量数学文本，SmolLM2引入），3B token切片，2k和16k上下文
- **评估benchmark**：ARC-Challenge、ARC-Easy、BoolQ、HellaSwag、OpenBookQA、PIQA、WinoGrande（7项，取未归一化原始准确率），另报告WikiText和LAMBADA困惑度。
- **对比架构**（24层、~330M参数、隐藏维度1024）：
  1. **标准注意力**（24层全softmax）
  2. **KDA混合**（18层KDA + 6层标准注意力，每4层替换一次）
  3. **KDA + LinSimp（web版）**（18层KDA + 3注意力 + 3 LinSimp）
  4. **KDA + LinSimp（无softmax）**（18层KDA + 6 LinSimp，主推方案）
  5. **Attention + LinSimp**（18层标准注意力 + 6层LinSimp）

- **三种实验设置**：

  - Math 2k：3B token（各架构FLOPs差异<5%，等token与iso-FLOP可视为同一运行）
  - Math 16k：约3B token iso-FLOP（KDA混合分得2.70B token，KDA+LinSimp分得3.14B token）
- **超参数**：LinSimp层6头，D=D_v=64，特征秩m=128（web实验m=64），锚窗口w=64；KDA层6个128维头，短卷积宽度4。

### 6. 主要结论与发现

- **主要结果**：
  - **Web 2k**：KDA+LinSimp组合接近但未超越KDA混合；但6层LinSimp优于24层标准注意力（验证损失3.6528 vs 3.6618）；精确窗口化WinSimp在iso-FLOP下因计算量大导致token预算缩减，困惑度最差。
  - **Math 2k**：KDA+LinSimp（无softmax）取得**最高平均准确率0.3900**和最高OpenBookQA准确率（0.188 vs KDA混合0.172 vs 标准0.144）。
  - **Math 16k（主结果）**：虽然iso-FLOP只分配给KDA+LinSimp 3.14B token（多于KDA混合的2.70B），但LinSimp在7项下游任务中**赢5项**，平均准确率从0.3809提升至0.3888（+0.0079），**LAMBADA困惑度从715.6降至602.6**（降幅15.8%）。
- **复杂度结论**：理论分析证实固定特征秩和锚窗口下，总计算量为O(T)线性，推理状态大小与T无关——这是对原始O(T³)和窗口化2-单纯形注意力的本质改进。
- **工程结论**：自定义Triton内核已接近成熟softmax内核的实测速度（1.03×），但尚未超越，反向传播仍有较大优化空间。

### 7. 方法优点

- **理论创新**：首次给出2-单纯形注意力的一模式（one-mode）核化推导，将三线性交互转化为标准线性注意力形式，为高阶交互机制的高效化提供了新思路。
- **兼顾全局与高效**：在保持一个token轴全局覆盖的同时实现线性复杂度，突破了双向窗口化变体的局部限制；固定大小推理状态也优于随序列增长的KV缓存。
- **正交随机特征设计严谨**：使用QR分解+符号修正+χ_D半径，确保高斯边缘分布与无偏性；诊断性数值实验验证了特征采样器的收敛行为。
- **工程实现完整**：自研Triton前向/反向内核，处理了在线最大值稳定、边界状态重建、无原子操作的反向累积等工程细节。
- **架构组合灵活**：LinSimp可作为标准注意力层的直接替代，也可与KDA等线性注意力架构组合，形成完全无softmax的模型，减少对softmax的依赖。
- **公平对比意识**：采用iso-FLOP规则控制计算预算，并进行参数匹配（±0.5%），尝试消除混淆变量。

### 8. 不足与局限

- **实验规模有限**：模型仅~330M参数，训练token最高3.14B，属于中小规模验证；缩放至更大模型/数据的行为与收益未知。
- **统计可靠性不足**：单一种子、无方差估计、无置信区间，结果差异（如+0.0079平均准确率）可能不完全稳健。
- **iso-FLOP度量的局限**：论文使用分析性操作计数而非实测墙钟/能耗，作者明确指出这不反映系统总成本；且KDA+LinSimp获得更多token部分源于"计算效率更高"的假设，实际吞吐（16k下20.2k vs 24.5k tok/s）反而更慢，说明分析性FLOPs与实际效率存在差距。
- **核近似误差**：随机特征近似虽无偏，但归一化后的比值在有限m下仍可能带来偏差；论文未深入分析m的选取对下游任务敏感度的影响。
- **锚窗口超参数**：w=64属于启发式选择，未系统研究w对长程依赖建模能力的影响；w过小时可能重新引入窗口化变体的局限。
- **内核性能未达最优**：反向传播大量点积导致性能瓶颈，作者自评为"功能性实现而非最终速度声明"；PyTorch参考路径（非CUDA/Triton）可能成为实际使用瓶颈。
- **与纯softmax模型对比缺失**：16k长上下文实验未包含纯标准注意力基线（因计算量过大会大幅削减token预算），无法直接对比优于标准注意力的程度。
