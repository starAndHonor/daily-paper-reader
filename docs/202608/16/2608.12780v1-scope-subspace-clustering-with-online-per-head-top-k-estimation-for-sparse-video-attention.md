## 摘要
扩散变换器（DiTs）在时空令牌上产生二次方自注意力成本。现有的免训练稀疏注意力方法通常从块级或聚类级代理分数构建稀疏掩码，这可能掩盖键之间的细粒度差异，并在激进稀疏下遗漏高贡献键。此外，此类代理分数可能导致过于集中的softmax分布，使得Top-p对于某些查询聚类保留过少的键。尽管固定的Top-k最小值缓解了这种失败模式，但共享值无法适应不同头和输入的变化。为解决这两个限制，我们提出了SCOPE，一种免训练的稀疏注意力框架，结合了3D-RoPE对齐的键子空间聚类和在线逐头Top-k估计，以实现高效的视频DiT推理。SCOPE将RoPE后的键划分为时间、高度和宽度子空间，独立聚类，并通过查找表聚合相应的质心分数，为每个查询聚类获得每个键的代理分数。基于现有的混合Top-p/固定Top-k选择，SCOPE通过平均每个头内初始保留的键数（按查询聚类大小加权）在线推导出头特定的Top-k值，并仅对初始保留键数低于该值的查询聚类选择额外键。然后在选定的原始键和值上计算稀疏注意力。在六个模型-任务配置中，SCOPE在保真度和延迟方面均持续优于现有的免训练基线，在720p HunyuanVideo上实现了高达1.99倍的端到端加速，相对于密集注意力PSNR为28.46 dB。

## Abstract
Diffusion Transformers (DiTs) incur quadratic self-attention cost over spatiotemporal tokens. Existing training-free sparse attention methods often construct sparse masks from block-level or cluster-level proxy scores, which can obscure fine-grained differences among keys and miss high contribution keys under aggressive sparsity. Moreover, such proxy scores may yield overly concentrated softmax distributions, causing Top-$p$ to retain too few keys for some query clusters. Although a fixed Top-$k$ minimum alleviates this failure mode, a shared value cannot adapt to variations across heads and inputs. To address both limitations, we propose SCOPE, a training-free sparse attention framework that combines 3D-RoPE-aligned key subspace clustering with online per-head Top-$k$ estimation for efficient video-DiT inference. SCOPE partitions post-RoPE keys into temporal, height, and width subspaces, clusters them independently, and aggregates the corresponding centroid scores through lookup tables to obtain per key proxy scores for each query cluster. Building on existing hybrid Top-$p$/fixed Top-$k$ selection, SCOPE derives a head-specific Top-$k$ value online by averaging the initial retained key counts within each head, weighted by query cluster size, and selects additional keys only for query clusters whose initial retained key counts fall below this value. Sparse attention is then computed over the selected original keys and values. Across six model--task configurations, SCOPE consistently outperforms existing training-free baselines in both fidelity and latency, achieving up to a $1.99\times$ end-to-end speedup on 720p HunyuanVideo with $28.46$ dB PSNR relative to dense attention.

# SCOPE：基于在线逐头Top-K估计的稀疏视频注意力子空间聚类——论文总结

## 1. 核心问题与整体含义（研究动机与背景）

- **问题起源**：现代视频扩散变换器（Diffusion Transformers, DiTs）将时空潜变量展平为成千上万的令牌（token），在自注意力计算中产生 O(N²d) 的二次方成本，成为高分辨率、长视频生成中的主要性能瓶颈。
- **现有免训练稀疏注意力的缺陷**：
  - 现有方法多依赖**块级（block-level）或聚类级（cluster-level）代理分数**构造稀疏掩码，导致同一块/簇内所有键共享相同的重要性估计，**掩盖了键粒度的差异**，在激进稀疏下容易遗漏高贡献的键。
  - **Top-p 选择可能过度集中于少量键**，导致部分查询簇保留的键过少；虽然固定 Top-k 下限可以缓解，但**全局共享的 Top-k 值无法适应不同注意力头与输入的变化**。
- **研究目标**：设计一个**免训练（training-free）**的稀疏注意力框架，在保持与密集注意力参考高保真度的同时，实现显著的端到端加速，并解决上述代理分数细粒度不足和计数分配不均的问题。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 整体框架

SCOPE 包含四个核心步骤（对应论文图 3）：

1. **全维度查询聚类（Full-Dimensional Query Clustering）**
   - 对后 RoPE 的查询矩阵 Q 使用 K-means 聚成 Cq 个小簇（Cq ≪ N），簇内所有查询共享同一代理排序和选键集合。
   - 查询质心仅用于选键，最终稀疏注意力仍使用原始查询向量。

2. **3D-RoPE 对齐的键子空间聚类与组合打分（3D-RoPE-Aligned Key Subspace Scoring）**
   - 基于 3D RoPE 将通道划分为时间（T）、高度（H）、宽度（W）三个互不相交的子空间。
   - 在每个子空间内分别对后 RoPE 键执行 K-means（每个子空间 Cm 个质心），得到各子空间的簇分配。
   - 将每个查询质心切片与对应子空间质心做点积，构建紧凑的得分查找表 Pm ∈ R^{Cq × Cm}。
   - 对每个键，仅需从三张表中索引并求和三个得分，得到代理 logit：  
     \[
     \tilde{s}_{c,j} = \frac{1}{\sqrt{d}} \sum_{m\in\{T,H,W\}} P^m[c, z^m_j]
     \]
   - 该组合打分机制使得**高维点积次数随子空间数线性增长，而可用于区分键的组合表示呈指数增长**（乘积量化思想），在计算开销与键区分度之间取得良好平衡。

3. **在线逐头 Top-k 估计（Online Per-Head Top-k Estimation）**
   - **混合 Top-p/固定 Top-k 选择**：对每个查询簇，先按代理概率分布计算 Top-p 保留数 t_c^(p)，再与全局固定最小值 k_fix = ⌈αN⌉ 取最大值作为基础保留数 b_c。
   - **在线逐头估计**：以查询簇大小加权平均当前头内所有基础保留数，得到头级最小值：  
     \[
     k_{\text{head}} = \left\lceil \frac{\sum_{c=1}^{C_q} n_c b_c}{\sum_{c=1}^{C_q} n_c} \right\rceil
     \]
   - 最终保留数为 r_c = max{b_c, k_head}，仅对基础保留数低于该值的簇进行扩展。该过程**完全在线、无需离线密集注意力画像或存储逐头调度表**。

4. **稀疏注意力执行**
   - 各查询簇使用选定的原始键与值计算稀疏注意力：  
     \[
     O_{Q_c} = \text{softmax}\left(\frac{Q_{Q_c} K_{S_c}^\top}{\sqrt{d}}\right) V_{S_c}
     \]
   - 代理质心、分配和得分仅用于选键，注意力计算本身不引入额外近似。

### 2.2 算法伪代码（论文附录 A，算法 1-3）

## 6. 主要结论与发现

- **SCOPE 在六个配置上均取得最高的密集参考保真度（PSNR、SSIM、LPIPS 三项全部第一）**，同时录得最低的端到端延迟。
- 相对密集注意力，SCOPE 实现 **1.67×–1.99× 的端到端加速**；在 HunyuanVideo-T2V 上达到 1.99× 加速，PSNR 为 28.46 dB。
- **3D-RoPE 对齐的子空间划分比随机划分或全维度聚类更优**：在相同质心数量下，3 维（T/H/W）划分的 PSNR 高于随机 3 维划分 0.29 dB，高于 4 维划分 0.18 dB，且延迟更低；进一步增加到 8 维仅提升 0.17 dB 但增加 84 秒，表明 T/H/W 划分是性价比最高的选择。
- **在线逐头 Top-k 估计有效**：在匹配实际保留密度的情况下，从“Top-p”到“Top-p+固定 Top-k”再到“+在线 Top-k”，PSNR 逐步提升，说明在线估计改善了不同查询簇之间的预算分配，而非单纯增加预算。
- **SCOPE 的代理打分显著提升了键粒度**：在达到约 95.8% oracle 召回率时，SCOPE 仅保留 28.8% 的键，而全维度聚类打分需要 55.0%，块级打分需要 76.3%，表明 SCOPE 有效减少了不重要键的过度保留。
- 运行时分析表明，SCOPE 的附加开销（聚类、打分、选键）远小于注意力的节省，能够稳定转化为端到端加速。

## 7. 优点：方法或实验设计上的亮点

- **创新性**：将 3D-RoPE 的天然通道划分与乘积量化思想结合，独立建模时空子空间，在**不增加高维打分成本的前提下指数级扩大键的可区分表示空间**。
- **免训练、即插即用**：无需修改预训练模型或重新训练，仅需单个前向的在线聚类与选键，易于集成到现有视频 DiT 推理流程。

- **公平性与严谨性**：与基线共享所有随机种子和采样配置，保证对比公平；在匹配注意密度的条件下评估，能体现相同预算下的算法效率。
- **验证充分**：提供了主结果、消融、召回率对比、运行时分解和定量/定性结果，证据链完整。
- **工程价值高**：同时优化保真度与延迟，在生成质量和速度之间取得优势，对实际部署有实用意义。

- **潜在偏差风险**：PSNR 等指标面向密集注意力输出计算，但生成质量评价（VBench）与密集参考并非完全一致；SCOPE 在 VBench 得分上略低于某些基线（如个别配置的 SubConsist）或与密集分数接近，可能因指标侧重不同导致不完全一致。
- **代理分数误差可能随模型/步骤变化**：虽然论文展示了匹配召回下的优势，但未深入分析在不同去噪阶段、不同注意力头中代理误差的分布变化，通用性有待进一步验证。
- **K-means 开销**：虽然总开销小于收益，但仍增加额外延迟；对于更短的视频或更小的模型，SCOPE 的加速比可能下降，论文未讨论这种边界情况。
