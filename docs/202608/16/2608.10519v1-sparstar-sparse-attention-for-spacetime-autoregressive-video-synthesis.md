## 摘要
InfinityStar通过图像和片段金字塔序列将视觉自回归生成扩展到视频。然而，其不断变化的尺度和跨片段上下文使得后期尺度的注意力计算成本高昂，并且从扩散或图像VAR模型中复用的稀疏模式变得不可靠。我们提出了SparSTAR，一种针对该场景量身定制的免训练块稀疏注意力方法。在每个高代价的尺度和注意力头上，SparSTAR从当前查询和键激活中对连续的键块进行评分，保留所需的条件上下文，并通过仅前向的稀疏路径执行所选块。我们分析了片段内的跨尺度一致性、跨片段边界的模式持续性，以及重用跨度越来越远的尺度时的质量退化。在这些分析中，重要的键块会发生偏移，表明在每个目标尺度上重新计算块选择比重用转移掩码更可靠。在720p文本到视频和图像到视频生成中，SparSTAR保留了每个标记和细化尺度，同时提供约1.6倍的端到端加速，并维持接近稠密InfinityStar的VBench和成对输出重建保真度。

## Abstract
InfinityStar extends visual autoregressive generation to video through a sequence of image and clip pyramids. Its changing scale and cross-clip context, however, leave late-scale attention costly and make sparse patterns reused from diffusion or image VAR models unreliable. We introduce SparSTAR, a training-free block-sparse attention method tailored to this setting. At each expensive scale and attention head, SparSTAR scores contiguous key blocks from the current query and key activations, retains required conditioning context, and executes the selected blocks through a forward-only sparse path. We analyze cross-scale consistency within a clip, pattern persistence across clip boundaries, and quality degradation as reuse spans increasingly distant scales. Across these analyses, important key blocks shift, showing that recomputing block selection at each target scale is more reliable than reusing a transferred mask. On 720p text-to-video and image-to-video generation, SparSTAR preserves every token and refinement scale while providing about a 1.6x end-to-end speedup and maintaining VBench and paired-output reconstruction fidelity close to dense InfinityStar.

### 1. 论文的核心问题与整体含义

- **研究背景**：视觉自回归（VAR）模型通过逐尺度预测生成视觉 token，InfinityStar 将其扩展至视频生成领域，提出了时空自回归（STAR）建模——先生成图像金字塔，再生成一段按顺序堆叠的片段金字塔。然而，其生成过程延续了“深尺度”注意力成本高昂的问题。
- **核心痛点**：尽管 InfinityStar 内部的 Spacetime Sparse Attention（SSA）已经限制了历史上下文，只保留前一 clip 的最终尺度作为视觉上下文，但在高分辨率下（例如 720p 最终尺度包含 72,000 个 token），当前片段内部各尺度仍需对所有可见键进行稠密注意力计算，计算量依然巨大。
- **现有方法失效的原因**：为视频扩散模型设计的稀疏注意力方法基于固定的 3D 潜空间网格，不适合混合了不同尺度 KV 上下文的 SSA 设置；面向图像 VAR 的 SparVAR 等跨尺度掩码迁移方法，在视频 VAR 中也会因为 KV 上下文在不同 clip/尺度间发生显著变化而变得不可靠。
- **论文核心目标**：为 STAR 视频生成模型量身打造一种免训练的稀疏注意力方案，在不改变模型权重、不跳过一个 token 或缩放尺度的前提下，降低高成本后期尺度的注意力开销，同时保持生成质量接近稠密基线。

### 2. 论文提出的方法论

论文先通过系统性分析建立动机，再提出方法，核心内容如下：

**（a）前置分析（研究动机）**围绕三个核心问题进行定量分析：
- **片段内的跨尺度模式一致性**：在 480p 上对比 token 级 Top-K（上限）、块级逐尺度重算 Top-K、跨尺度复用固定掩码和滑窗。结果显示跨尺度复用稀疏掩码会造成严重注意力质量丢失（平均约 35.6%），而逐尺度重算块级 Top-K 最接近 token 级上限（平均仅 4.64% 的差距）。
- **跨片段边界的模式持续性**：在相同参考上下文上对比复用 Clip 1 的模式与在 Clip 2 重新计算模式，发现 15% 预算下重新计算可保留 85% 注意力质量，而复用仅保留 56%——模式复用只在部分情况下可靠。
- **尺度距离的影响（越远越差）**：对比倒数第一个尺度做单次复用、每 2 个尺度更新抑或每个尺度均更新，结果表明重新计算每个尺度的模式（every-scale）比单次传输（single-transfer）在 PSNR 上提升 1.73 dB，仅增加 0.30 秒延迟，说明跨尺度复用带来的质量损失远大于动态重算带来的延迟代价。

**（b）方法核心（SparSTAR）**基于上述动机提出免训练的块稀疏注意力：

- **聚合查询–键块选择器**：
  - 将 Q 和 K 按注意力内核原有顺序划分为连续块，块大小 b=128 token；
  - 对每个 query 块和 key 块分别计算块内 token 向量的均值（即聚合向量），再利用缩放点积得到块与块之间兼容性得分 S_ij，作为排序依据；
  - 该得分是块内全部 token 两两预 softmax 兼容性的平均值，用于排序而非估计注意力质量。计算量为稠密点积的约 1/16,384，加减选块开销后，后期尺度的选择算术量仅占相应稠密 QK 算术量的 0.016%。
- **Clip 相关的保留与可选块策略**：
  - Clip 1：文本块 + 最终图像金字塔块始终保留，仅对当前尺度块进行稀疏选择；
  - Clip c≥2：仅文本块始终保留，前置 clip 最终尺度块与当前尺度块在统一的密度预算下联合排序。
- **缩放尺度密度调度**：按 token 数量分配不同的保留密度；720p 下后四个稀疏化尺度 s26–s29 分别使用密度 {0.625, 0.1875, 0.1875, 0.09375}。最终尺度（含 72,000 token）仅保留约 9.375% 的键块，因为该尺度占比最大（占稀疏化尺度的 74.6% 注意力成本）且注意力模式更集中。
- **前向传播稀疏执行（FastFlex）**：基于 FlashAttention/FlexAttention 编写仅前向模式，只写出前向字段（kv_num_blocks 和 kv_indices），省略仅反向需要的字段，避免构造反向索引结构；实测选块和掩码构建开销不足端到端延迟的 1.7%。

### 3. 实验设计

- **评估设置**：
  - 720p 5 秒、81 帧（主要由 1 个外观帧 + 80 帧 clip 金字塔组成）；

- **免训练、动态掩码**：无需训练或微调，纯粹依靠当前 Q/K 激活计算块级得分，动态生成每个尺度、每个头的掩码，没有参数开销。

- **加速幅度有限**：端到端 1.6× 的相对加速小于后续章节中 token 修剪（类 FastSTAR）方法，但这是以保真度为代价换来的；对于对速度极度敏感的应用场景，可能仍不够。
