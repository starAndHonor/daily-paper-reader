## 摘要
扩散大语言模型（dLLMs）通过在单次前向传播中预测多个掩码来加速语言生成。然而，现有的dLLMs在激进的并行策略下，早期去噪阶段的预测可能不可靠，导致错误传播到后续阶段。为了解决这个问题，我们提出了用于dLLMs的一致性强制（CForce）方法，这是一种蒸馏方法，迫使早期阶段的掩码预测与后期阶段的预测对齐。CForce在预先收集的自展轨迹上训练模型，从而改善了训练与推理的一致性。我们引入了置信度自适应KL散度作为蒸馏目标，以结合前向和反向KL的优点。我们进一步对一致性目标进行了理论分析，以解释为什么CForce能够近似最小化早期阶段的预测误差。关键的是，相同的公式同时适用于掩码到token的解码和可编辑解码；在可编辑情况下，后期的token到token细化为早期的掩码状态预测提供了额外的监督。在非编辑和可编辑的LLaDA模型上的实验显示，速度-质量权衡得到改善，尤其是在高并行解码预算下。代码可在以下网址获得：https://github.com/inclusionAI/dFactory。

## Abstract
Diffusion large language models (dLLMs) accelerate language generation by predicting multiple masks in a single forward pass. However, existing dLLMs can suffer from unreliable predictions in early denoising stages under aggressive parallelism strategies, leading to errors that can propagate to later stages. To tackle this issue, we present Consistency Forcing (CForce) for dLLMs, a distillation method to force the mask predictions of early stages to align with those of later stages. CForce trains the model on pre-collected self-rollout trajectories, thereby improving training-inference alignment. We introduce Confidence Adaptive KL Divergence as a distillation objective to conjoin the merits of forward and reverse KL. We further provide a theoretical analysis for the consistency objective to explain why CForce can approximately minimize the prediction error of early stages. Critically, the same formulation applies to both mask-to-token decoding and edit-capable decoding; in the edit-capable case, later token-to-token refinements provide additional supervision for earlier masked-state predictions. Experiments on non-edit and edit-capable LLaDA models show improved speed-quality trade-offs, especially under high-parallelism decoding budgets. - **研究对象**：扩散大语言模型（Diffusion Large Language Models, dLLMs），这类模型通过在单次前向传播中预测多个掩码（mask）来实现并行文本生成，具备显著的加速潜力。
- **核心问题**：现有的dLLMs在激进的并行解码策略（如低置信度阈值、高并行预算）下，**早期去噪阶段的预测往往不可靠**——模型在上下文信息不足的情况下过早承诺大量token，所产生的错误会随去噪过程**传播到后续阶段**，最终损害生成质量。这一问题在可编辑（edit-capable）dLLMs中尤为突出，因为此类模型允许后续token-to-token（T2T）细化来修正早期错误——但这些后期修正信号此前未被有效用于训练早期的掩码预测。
- **研究缺口**：已有的加速与蒸馏方法存在局限——推断期方法（如缓存、验证）未改变模型参数，不直接训练模型自身轨迹上的低上下文状态；训练期方法（如D2F、T3D等）依赖构造的、教师生成的或特权轨迹，其信息条件与学生的真实推断状态存在偏差。缺乏沿模型自身阈值解码轨迹训练"早期-后期"一致性的方法。
- **整体含义**：dLLM的加速不仅取决于减少去噪步数，更取决于**提升早期预测在高并行解码下的可靠性**。论文提出**CForce（Consistency Forcing）**，通过"一致性强制"蒸馏使早期低上下文状态的预测与后期信息更丰富状态的预测对齐，从而提升高并行解码的速度-质量边界。

## 2. 论文提出的方法论：核心思想、关键技术细节与公式说明

### 2.1 方法总览

CForce是一种训练后蒸馏方法，灵感来源于一致性模型（Consistency Models）。其核心思路是：**从预训练的dLLM出发，收集模型自身基于置信度阈值解码的自展轨迹，将轨迹划分为多个阶段（stage），并强制相邻阶段中的早期状态预测与后期状态的停止梯度（stop-gradient）预测对齐**——目标分支不参与梯度回传。这避免了引入冻结教师模型，实现了"自蒸馏"。

### 2.2 关键流程：分阶段轨迹构建

- 使用预训练模型 `q_θ₀`，通过置信度阈值解码（confidence-based threshold decoding）收集原生轨迹 `T = (s₀, s₁, ..., s_T)`。
- **阶段划分**：不使用每个原生步骤作为训练对（相邻原生状态差异太小、信号弱），而是设置一个**阶段大小 S**（即累积新揭示token数），每当累积的mask-to-token（M2T）揭示数达到S时保存一个阶段边界，最终得到分阶段轨迹 `T̄ = (s̄₀, s̄₁, ..., s̄_N)`。
- 对每个相邻阶段对，将位置划分为两部分：
  - **U_i**：两个阶段中仍保持掩码的位置（用于分布对齐）；
  - **Δ_i**：两阶段之间被揭示的位置（用于CE锚定）。
- 对于可编辑dLLMs，额外记录阶段级编辑集合 Ē_i（可见token在两阶段间发生改变的位置），使T2T修正信号也能反馈到早期M2T预测。

### 2.3 损失函数设计

**（1）置信度自适应KL散度（Confidence Adaptive KL Divergence, CAD）**

在仍处于掩码状态的位置集合U_i上，通过动态混合前向与反向KL来对齐学生分布 `p_stu` 与目标分布 `p_tar`：

```
L_CAD = (1/|U_i|) Σ_{j∈U_i} [ D_KL(p_tar ∥ p_stu) + c_j · D_KL(p_stu ∥ p_tar) ]
```

其中 `c_j = max_v p_tar(v)` 是后期阶段预测的置信度。设计动机：前向KL稳定控制分布漂移（对应理论上界的第一项）；反向KL具有强"模式寻找"（mode-seeking）能力，但仅在后期预测置信度高时才加权加入，避免目标不确定时过早崩溃。

**（2）CE锚定（CE Anchor）**

在刚被揭示的位置Δ_i上应用交叉熵损失，稳定token承诺：

```
L_CE = -(1/|Δ_i|) Σ_{j∈Δ_i} log q_θ(y_j | x, s̄_i, j)
```

该项控制理论误差上界中的"揭示边界token错误"。

**（3）课程学习（Curriculum Transition）**

训练初期阶段差距过大难以学习。随训练步数u逐渐增加后期状态中暴露的新揭示位置比例：

```
ρ_u = min(1, ρ₀ + (1 - ρ₀) · u / T_train)，ρ₀ = 0.1
```

初期目标状态接近学生状态，稳定学习；后期逐渐暴露完整的阶段过渡。

**（4）总目标**

```
L = L_CAD + λ_CE · L_CE
```

### 2.4 理论分析

论文证明了早期阶段预测误差（以总变差距离DTV度量）的上界：

```
D_TV(p_i^j, δ_yj) ≤ Σ_{r=i}^{rj-2} √(½D_KL(p_{r+1}^j ∥ p_r^j)) + (-log p_{rj-1}^j(y_j))
```

- 第一项：**相邻阶段分布漂移**（与CAD中的前向KL对应）；
- 第二项：**揭示边界token误差**（与CE锚定对应）。

由于CAD中反向KL项非负，优化L_CAD不会破坏前向KL对齐，同时还能锐化预测。因此CForce可视为优化早期预测误差上界的可处理代理。

## 7. 优点

## 8. 不足与局限

- **轨迹静态性**：论文在Limitations中也承认，训练依赖**预先收集的固定轨迹**。随着训练更新模型，缓存轨迹与实际推理轨迹逐渐偏离，可能限制训练信号与最终学生分布的匹配度。未来的在线轨迹收集与策略更新是必要方向。
- **并行度-质量固有折中**：在非编辑LLaDA2.0上，CForce虽然提升TPF显著，但平均Score仍低于基础模型（80.88 vs. 86.52）。这说明在高并行度下无法完全消除质量损失，只是改善了"代价/收益比"。
- **模型覆盖有限**：实验仅基于LLaDA2.0-mini和LLaDA2.1-mini两个小型变体，未验证对更大规模（如LLaDA2.0-100B）或其他dLLM架构（如d3LLM、Dream 7B等）的适用性。
- **数学基准提升不明显**：在GSM8K和MATH500上CForce的Score与基线持平甚至略降（如GSM8K从93.56降至92.27），代码基准才是主要增益来源。方法的普适性仍需更多验证。
- **训练成本**：需要预先收集大规模轨迹数据并单独进行多轮全参数微调（64块H800），对于资源受限的研究者门槛较高；轨迹收集也需要额外的推断资源。
- **评估遗漏**：未报告延迟/吞吐在batch size >1下的表现；对比方法中部分模型（如dUltra、DMax）虽做报告但未提供完整的controlled设置对齐细节；无模型输出多样性和鲁棒性分析。
