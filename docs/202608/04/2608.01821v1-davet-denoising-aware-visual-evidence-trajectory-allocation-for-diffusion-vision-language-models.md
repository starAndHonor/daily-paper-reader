## 摘要
扩散视觉语言模型（dVLMs）在掩蔽响应上迭代去噪，同时将每一步去噪条件建立在视觉证据上，使得视觉条件化成为一项可观的重复推理成本。与自回归解码不同，扩散生成会随着不确定性的演变反复访问整个响应。我们的分析表明，视觉证据需求强烈依赖于步骤，这促使在去噪步骤之间进行自适应分配。现有的推理加速方法通过解码侧策略或通过剪枝和合并进行视觉标记压缩来运作，但并未明确将视觉证据视为一种需求随扩散过程演变而变化的资源。因此，我们提出了去噪感知视觉证据轨迹分配（DAVET），这是一种无需训练的框架，根据演变的生成状态分配视觉证据。从阶段条件的证据轨迹出发，所提出的分配策略利用操作需求来设置证据储备，其在每个去噪步骤的分配由轨迹风险进行调节。DAVET通过从单一视觉编码构建的证据视图层次结构来实现最终的预算，将何时需要以及需要多少证据与如何构建证据视图分离开来。在两个代表性dVLMs（LLaDA-V和LaViDa）上，针对多个视觉理解基准进行评估，DAVET实现了平均1.55倍的速度提升，平均相对性能下降1.86%，表明去噪感知的视觉证据分配可以在很大程度上保持生成质量的同时降低视觉条件化成本。

## Abstract
Diffusion vision-language models (dVLMs) iteratively denoise masked responses while conditioning each denoising step on visual evidence, making visual conditioning a substantial recurring inference cost. Unlike autoregressive decoding, diffusion generation repeatedly revisits the entire response as uncertainty evolves. Our analysis reveals that visual evidence demand is strongly step-dependent, motivating adaptive allocation across denoising steps. Existing inference acceleration methods operate through decoding-side strategies or visual token compression via pruning and merging, but do not explicitly treat visual evidence as a resource whose demand evolves across the diffusion process. Therefore, we present Denoising-Aware Visual Evidence Trajectory Allocation (DAVET), a training-free framework that allocates visual evidence according to the evolving generation state. Starting from a phase-conditioned evidence trajectory, the proposed allocation policy uses operation demand to set an evidence reserve whose allocation at each denoising step is modulated by trajectory risk. DAVET realizes the resulting budgets through a hierarchy of evidence views constructed from a single visual encoding, separating when and how much evidence is needed from how the evidence views are constructed. Evaluated on two representative dVLMs, LLaDA-V and LaViDa, across multiple visual-understanding benchmarks, DAVET achieves an average speedup of 1.55$\times$ with an average relative performance drop of 1.86\%, showing that denoising-aware visual evidence allocation can reduce visual conditioning cost while largely preserving generation quality.

## 2. 方法论：DAVET 框架

### 2.1 核心思想

DAVET（Denoising-Aware Visual Evidence Trajectory Allocation）是一个**无需训练**的框架，将视觉证据视为一种"随扩散过程演变而变化的步骤相关资源"，而非固定输入。其核心设计理念是**将"证据分配策略"与"证据实现方式"解耦**——即先决定"何时、用多少证据"，再由独立的证据实现器（realizer）决定"如何构造证据视图"。

### 2.2 问题形式化

- 定义预算分配策略 π，根据生成状态 $s_t$ 和目标平均预算 $B$ 输出归一化预算 $b_t = \pi(s_t; B) \in [0,1]$。
- 证据实现器 $A$ 将编码后的视觉 token 序列 $v$ 和预算 $b_t$ 映射为步骤特定的表示 $v_t = A(v; b_t)$。
- 优化目标：在平均预算约束 $\frac{1}{T}\sum_{t=1}^{T} b_t \le B$ 下，最小化生成质量损失。

### 2.3 分配策略：三信号分解

DAVET 将每步证据预算表示为一个区间（**证据包络**，evidence envelope），由三个互补信号共同决定：

1. **相位条件证据轨迹（Phase-Conditioned Evidence Trajectory）**：
   - 用两方向相位族刻画骨干模型的证据需求模式：早期锚定 $p_t = 1 - (t-0.5)/T$，晚期验证 $p_t = (t-0.5)/T$。
   - 通过归一化使轨迹均值匹配指定预算，保留相位顺序但不预设具体证据等级。
   - 决定"何时"强调视觉证据，而非总量。

2. **操作条件证据储备（Operation-Conditioned Evidence Reserve）**：
   - 在去噪前用轻量级、免训练的确定性解析器 $g$ 将查询 $q$ 映射为五类操作之一：词汇读取、数值推理、实体定位、二值判断、一般理解。
   - 每类操作关联固定需求先验 $d(o) \in [0,1]$，用于控制证据包络的上边界（储备容量）。
   - 下轨迹为 $b = N(p_{1:T}; (1-\rho)B)$，上轨迹为 $\bar{b} = N(p_{1:T}; [1-\rho+\rho d(o)]B)$，其中 $\rho$ 为储备比例。
   - 决定"有多少额外证据可供使用"。

3. **轨迹风险调制（Trajectory-Risk Modulation）**：
   - 从生成状态中提取两个信号：**平均置信度** $\bar{c}_{t-1}$ 和**预测翻转率（churn）** $\chi_{t-1}$（连续两步间最高 logit token 发生变化的未解析位置占比）。
   - 轨迹风险定义为 $r_t = 1 - \alpha \bar{c}_{t-1}(1 - \chi_{t-1})$，$\alpha$ 控制稳定性信号的影响强度。
   - 最终预算通过包络内插值得到：$b_t = b_t + r_t(\bar{b}_t - b_t)$。
   - 决定"在每步实际动用多少储备"。

### 2.4 视觉证据实现

- 从**单一视觉编码**出发，预处理构建 $K=3$ 级有序证据视图：
  - **coarse**：结构化池化，保留全局覆盖、减少 token 数；
  - **mixed**：池化表示 + 固定子集未池化 token，恢复部分细粒度细节；
  - **high**：完整未压缩视觉 token 序列。
- 预算区间按三等分映射到三个视图（$b_t < 1/3$ 用 coarse；$1/3 \le b_t < 2/3$ 用 mixed；$b_t \ge 2/3$ 用 high）。
- 所有视图在去噪前一次性构建并全程复用，不重复运行视觉编码器。
- **兼容性**：剪枝、合并等机制均可作为证据实现器接入同一分配策略，只需暴露"有序证据-成本"层级接口。

## 3. 实验设计

### 3.1 骨干模型与数据集

- **骨干模型**：LLaDA-V、LaViDa（两个代表性 dVLM）。
- **数据集**：4 个视觉理解基准——
  - InfoVQA（信息图问答，ANLS 指标）
  - ChartQA（图表问答，relaxed accuracy）
  - DocVQA（文档问答，ANLS 指标）
  - TextVQA（场景文本问答，VQA accuracy）
- **生成配置**：生成长度和块长度均为 32；LLaDA-V 用 16 步去噪，LaViDa 用 32 步；确定性解码（temperature=0）。

### 3.2 对比方法

- **静态分辨率控制**：Static High（原始分辨率）、Static Mid（缩放至约 2/3）、Static Low（缩放至约 1/3）。
- **视觉 token 剪枝**：RedVTP（基于掩码响应信号估计 token 重要性的训练免剪枝方法）。
- **动态 token 合并**：D3ToM（基于响应演化引导的跨步骤 token 合并方法）。
- 公平性处理：对两种压缩方法施加相同 token 保留率（LLaDA-V 为 0.50，LaViDa 为 0.75）；D3ToM 官方实现不支持 LLaDA-V，按方法规范自行适配。

### 3.3 DAVET 配置

- 两个骨干共享相同的分配策略公式、查询解析器、操作分类法和 $K=3$ 证据层级。
- 相位方向与骨干对齐：LLaDA-V 用早期锚定（early grounding）；LaViDa 用晚期验证（late verification）。
- 超参数：LLaDA-V 用 $B=0.75, \rho=0.20, \alpha=1.0$；LaViDa 用 $B=0.45, \rho=0.20, \alpha=0.5$。配置在所有基准上固定。

## 6. 主要结论与发现

1. **视觉证据需求随去噪步骤变化，且模式因骨干而异**：LLaDA-V 表现为"早期锚定"（Q2–Q3 峰值），LaViDa 表现为"晚期验证"（Q8 峰值）。
2. **DAVET 在质量-效率权衡上优于现有方法**：
   - 在 LLaDA-V 上：平均质量保持 99.21%，平均加速 1.36×；
   - 在 LaViDa 上：平均质量保持 97.08%，平均加速 1.73×，且**在质量和速度两个维度上同时超过** RedVTP 和 D3ToM；
   - 整体：**平均加速 1.55×，平均相对性能下降仅 1.86%**。
3. **三个分配信号具有功能互补性**：相位提供时间结构（最大初始效率增益但可能损质量）；操作需求提供查询条件的储备容量（显著恢复质量）；轨迹风险控制状态依赖的储备使用（恢复部分效率且几乎不改质量）。
4. **同一分配策略可跨实现器有效**：池化、剪枝、合并三种实现器在固定策略下均保持在 1.25–1.78× 加速、质量损失 0.51–1.60% 范围内，说明分配策略与证据构造方式解耦有效。
5. **相位方向必须与骨干匹配**：反转相位方向造成严重质量下降（最高达 41.54%），而延迟几乎不变，证实了方向选择的决定性作用。

## 7. 优点

1. **问题定义新颖**：首次将 dVLM 中的视觉条件化成本显式建模为"步骤相关的可分配资源"，而非单纯压缩问题，洞察深刻。
2. **无需训练的通用框架**：不改变模型参数，直接适用于现有 dVLM，实用性强。
3. **分配与实现的解耦设计**：同一策略可适配池化、剪枝、合并等多种证据实现器，具有良好通用性和可扩展性。
4. **轻量级信号设计**：轨迹风险仅复用模型已有的预测输出（置信度和翻转率），不引入额外前向计算或阈值触发机制。
5. **受控实验设计严谨**：通过固定总高证据暴露量的干预实验揭示骨干依赖的时变需求模式，通过相位方向反转控制、均匀需求控制等实验排除混淆因素。
6. **证据充分**：涵盖组件消融、实现器泛化、超参数扫描、延迟分解等多个维度，结果可信度较高。

## 8. 不足与局限

1. **骨干覆盖有限**：仅验证 LLaDA-V 和 LaViDa 两个模型，无法确认策略在其他 dVLM 架构（如 Dimple、MMaDA）上的适用性。
2. **任务覆盖偏窄**：全部为 VQA 类视觉理解基准，未涉及更复杂的多模态推理、长答案生成或图像生成类扩散模型任务。
