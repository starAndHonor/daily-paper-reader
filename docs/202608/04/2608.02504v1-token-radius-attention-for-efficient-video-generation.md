## 摘要
视频扩散Transformer（VDiT）实现了高保真生成，但密集的3D自注意力带来了二次方的计算成本。现有的头部级和块级稀疏方法在查询之间共享计算预算，忽略了特定于Token的注意力需求。我们观察到保留密度因查询而异，但与注意力熵呈对数线性相关，而主导交互形成以查询为中心的邻域，其半径随Token变化。基于这些发现，我们提出了Token半径注意力（TRA），这是一种无需训练的框架，将查询熵映射为解析的Token预算，并无需显式键排序即可将其转换为时间衰减的半径。融合熵提取、预热重用和块稀疏掩码构建进一步减少了开销。在Wan2.1、Wan2.2和HunyuanVideo的七种T2V/I2V配置中，TRA仅保留9%–19%的注意力交互，实现了1.56倍–2.05倍的加速，同时保持具有竞争力的生成质量。代码可在https://github.com/IF-LAB-PKU/Token-Radius-Attention获取。

## Abstract
Video Diffusion Transformers (VDiTs) enable high-fidelity generation but incur quadratic cost from dense 3D self-attention. Existing head- and block-level sparse methods share computation budgets across queries, overlooking token-specific attention demand. We observe that retained density varies across queries yet correlates log-linearly with attention entropy, while dominant interactions form query-centered neighborhoods with token-dependent radii. Based on these findings, we propose Token Radius Attention (TRA), a training-free framework that maps query entropy to an analytic token budget and converts it into a temporally decayed radius without explicit key ranking. Fused entropy extraction, warm-up reuse, and block-sparse mask construction further reduce overhead. Across seven Wan2.1, Wan2.2, and HunyuanVideo T2V/I2V configurations, TRA retains only 9-19% of attention interactions and achieves 1.56x-2.05x speedup with competitive generation quality. Code is available at https://github.com/IF-LAB-PKU/Token-Radius-Attention.

## 一、核心问题与整体含义（研究动机与背景）

- **研究背景**：视频扩散 Transformer（VDiT）已成为高保真视频生成的主流架构，但其中的密集 3D 自注意力计算量随视频 Token 数 N 呈 O(N²) 增长，成为扩展与部署的主要瓶颈。
- **既有方法的不足**：现有训练无关的稀疏注意力方法大多在**头部级**（如 SVG、Radial Attention）或**块级**（如 SVG2、SpargeAttn、SVOO）做稀疏决策，在同一头或块内对**所有查询共享同一计算预算**。然而，由于 softmax 按查询独立归一化，每个查询所需的键数量天然是查询特定的；共享分配会导致集中型查询浪费计算、弥散型查询丢失关键信息，从而损害生成质量。
- **本文的核心观察**：
  - **观察 1**：同一层、同一头内不同查询的“保留密度”（为达到目标注意力质量 τ 所需的最小键比例）可相差数个数量级，且与注意力熵呈**对数线性关系**（R²≈0.94–0.99），说明熵可作为查询级预算的低成本信号。
  - **观察 2**：高注意力权重键围绕查询形成**以查询为中心的近似圆形邻域**，且注意力概率随二维空间距离近似**指数衰减**；圆的半径因查询而异。
- **整体含义**：作者提出 **Token Radius Attention（TRA）**，一种训练无关的稀疏注意力框架，通过“熵→预算→半径”的流水线将查询特定的计算需求转化为规则的空时支撑结构，在保持高质量的同时显著加速视频生成推理。

## 二、方法论：核心思想、关键技术细节与公式

- **总体流程**：TRA 分为三步：熵引导的 Token 预算估计 → 预算驱动的半径构造 → 高效掩码生成与块稀疏执行。
- **(1) 熵到预算映射（Entropy-to-Budget）**
  - 对查询 i 定义注意力熵 \(H_i=-\sum_j p_{ij}\log p_{ij}\)。
  - 通过“熵等效均匀支撑”近似：假设一个与原始分布熵相同的均匀分布，其支撑大小 \(m_i=\exp(H_i)\)，则估计达到目标质量 τ 所需的键数为 \(\hat K^\tau_i=\lceil \tau \exp(H_i)\rceil\)，对应预算 \(\hat B^\tau_i\approx \tau \exp(H_i)/N\)。
  - 该映射为闭式、单调、无参数，无需训练额外预测器，也无需逐查询键排序。
- **（2）预算到半径构造（Budget-to-Radius）**
  - 定义空间距离 \(d_s(i,j)\) 与时间距离 \(d_t=|f_i-f_j|\)。
  - 采用时间衰减规则 \(\phi(\delta)=\exp(-\gamma\delta)\)，帧 t 的半径为 \(r_{i,t}=r_i\phi(|t-f_i|)\)。
  - 先用连续面积近似初始化半径 \(\tilde r_i=\sqrt{\frac{\hat K^\tau_i}{\pi\sum_t \phi^2(|t-f_i|)}}\)，再通过离散格点计数和查找表选择最小候选半径，使离散支撑规模不小于目标键数。
  - 最终 Token 级掩码 \(M_{ij}=\mathbb{I}[d_s(i,j)\le r_i\phi(|f_j-f_i|)]\)。
- **（3）高效稀疏执行**
  - **Flash Radius Mask 核**：将每帧划分为 tile 并按 tile-major 重排 Token，使邻域交互聚集成更少的稠密块；核内融合距离计算、半径比较、包围盒剪枝、块剔除以输出头感知的块稀疏掩码，供 FlashInfer 执行。
  - **融合注意力熵核**：利用 \(H_i=\log Z_i-\sum_j p_{ij}s_{ij}\) 在在线 softmax 过程中累积熵，无需物化完整注意力矩阵。
  - **预热复用**：仅在去噪过程前 25% 的稠密步骤（及首个 Transformer 层）计算熵，后续稀疏步骤直接复用预算、半径与掩码，避免反复计算。
- 数学定义：\(\text{TRA}(Q,K,V)=\text{Softmax}(QK^\top/\sqrt{d}+B(M))V\)，其中不可见键掩码置 \(-∞\)；文本键保持稠密可见。

## 六、主要结论与发现

- **效率与质量的权衡**：TRA 在全部 7 个配置中取得**稀疏方法中最高的 VBench Overall**；在 Wan2.1-14B T2V 上几乎匹配稠密注意力（87.39 vs 87.41），同时获得 1.75× 加速。

## 七、优点

- **训练无关、即插即用**：无需重新训练模型，可直接应用于现有 VDiT 推理流程。
- **Token 级自适应与规则结构兼顾**：在查询粒度分配计算预算，同时通过半径-时间衰减掩码保持块稀疏执行效率，解决“自适应-效率”矛盾。
- **低开销决策机制**：利用熵的闭式映射与查找表，免去逐查询键排序；熵在预热阶段计算并复用，避免重复开销。
- **配套工程优化完整**：设计了专用 CUDA 核、tile-major 重排、块剪枝与投票机制，实际加速效果显著。
- **验证充分且有理论分析**：提供跨模型验证、分布化近似误差分析、熵稳定性分析，并公开代码，便于复现。

## 八、不足与局限

- **稀疏模式受限**：TRA 的支撑结构仍局限于基于空间距离的预定义模式，采用固定时间衰减规则，可能无法捕捉长程对象对应、非局部运动或内容相关的注意力结构（论文自身也指出此点）。
- **缺乏专用 Token 级稀疏内核**：当前通过块稀疏后端执行，tile 重排和块掩码只能减少冗余，块内仍存在无效计算；专用内核有望进一步提升实际效率。
- **实验对比公平性存疑**：Radial Attention 因加速策略限制采用了更低分辨率和不同帧数，可能对 TRA 有利；未给出多次运行的统计显著性。
- **算力信息不完整**：论文未报告使用的 GPU 数量、总推理时长或能耗，资源消耗维度不够透明。
- **验证范围有限**：仅覆盖 Wan 和 HunyuanVideo 系列，未验证于 CogVideoX 等其他 VDiT 架构；也未讨论文本-视频联合注意力中文本部分对整体预算的影响。
- **静态复用假设**：跨步熵稳定性支持预热复用，但极端情况下若去噪轨迹出现较大分布偏移，固定掩码可能造成质量退化（论文未详细探讨此风险）。
