## 摘要
近期的音视频生成模型可以在统一的扩散过程中合成同步的视频与声音，但其推理成本仍然较高，因为长视频标记序列需要在去噪步骤间反复进行注意力计算。目前已开发出多种针对视频生成模型的加速技术，包括低比特量化、注意力稀疏化以及特征缓存。然而，由于这些方法最初是为视频生成设计的，将其直接应用于音视频模型会忽略音频分支与视频分支之间的交互，从而可能破坏音视频同步。我们提出了一种面向高效音视频生成的同步感知加速框架。我们的关键观察是，双向音视频交叉注意力揭示了两个分支之间的结构化交互，高响应通常集中在少数与声音相关的视觉区域和时间区域。在这种交互模式的指导下，我们引入了一种受保护的稀疏注意力策略，该策略对同步关键令牌保留高保真计算，同时稀疏化冗余的注意力交互。通过在进行加速时显式考虑跨模态依赖性，我们的方法在保持视频质量、音频质量和音视频同步的同时，提高了推理效率。

## Abstract
Recent audio-visual generation models can synthesize synchronized video and sound in a unified diffusion process, but their inference cost remains high because long video token sequences require repeated attention computation across denoising steps.A variety of acceleration techniques have been developed for video generation models, including low-bit quantization, attention sparsification, and feature caching.However, since these methods are originally designed for video generation, directly applying them to audio-visual models overlooks the interactions between the audio and video branches and may therefore disrupt audio-video synchronization.We present a synchronization-aware acceleration framework for efficient audio-visual generation.Our key observation is that bidirectional audio-video cross-attention reveals structured interactions between the two branches, with high responses often concentrated on a few sound-related visual and temporal regions.Guided by this interaction pattern, we introduce a protected sparse attention strategy that preserves high-fidelity computation for synchronization-critical tokens while sparsifying redundant attention interactions.By explicitly accounting for cross-modal dependence during acceleration, our method improves inference efficiency while keeping video quality, audio quality, and audio-video synchronization.

# 论文总结：基于同步感知跨模态稀疏注意力的高效音视频生成

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：近期的音视频生成模型（如 Ovi、Harmony、LTX-2 等）通过双分支扩散架构，在统一生成过程中同步合成视频与音频。这类模型在去噪步骤中反复执行长序列注意力计算，导致推理成本极高。
- **问题**：现有面向视频生成的加速技术（低比特量化、注意力稀疏化、中间特征缓存）主要利用单模态内部的冗余性设计加速策略，直接迁移到音视频模型时会忽略音频分支与视频分支之间的**双向跨模态交互**，可能削弱或破坏音视频同步。
- **核心观察**：作者分析发现，双向音频-视频交叉注意力具有高度结构化的非均匀模式——音频查询对视频 token 的注意力集中在与声音产生相关（如发声物体、时间对齐事件）的少数视觉区域，视频查询对音频 token 的注意力也呈现类似的选择性。这种交叉注意力可作为一种**模型内部的显著性信号**，用于识别“同步关键计算”。
- **整体含义**：加速音视频生成不能仅依据单模态冗余做近似，而应显式考虑跨模态依赖，保护对同步至关重要的计算，同时稀疏或复用真正的冗余计算。基于此提出**同步感知（Synchrony-Aware）训练无关加速框架**，在提升推理效率的同时保持视频质量、音频质量和音视频同步。

## 2. 方法论

### 2.1 核心思想

- 利用双向交叉注意力生成模态特定的显著性图（saliency map），以此作为“共享重要性先验”，指导两种粒度的加速决策：
  - **Token 级**：对高显著性的视频/音频查询保留完整稠密注意力行（保护计算），对低显著性查询采用稀疏注意力。
  - **块级**：基于模态特征变化、保护区域变化和显著性漂移，决定是否复用之前的块输出（cache reuse），避免不安全复用。

### 2.2 关键技术细节

- **双向交叉模态显著性估计**：
  - 设视频 token 为 \(X_v \in \mathbb{R}^{N_v \times d}\)，音频 token 为 \(X_a \in \mathbb{R}^{N_a \times d}\)。
  - 对于音频到视频方向，计算注意力矩阵 \(A^{a\to v}_{t,\ell,h} = \mathrm{softmax}(Q_a K_v^\top / \sqrt{d_h})\)。
  - 聚合所有音频 query、头和选定的层，得到视频 token 显著性 \(s_{v,i}\)。类似地，由视频到音频的注意力得到音频 token 显著性。
  - 根据显著性分数选取保护查询集合：\(P_v = \mathrm{TopK}(\{s_{v,i}\}, \rho_v N_v)\)，其中 \(\rho_v\) 为保护比例。

- **滞后显著性重用（Lagged Saliency Reuse）**：
  - 由于交叉注意力在模态自注意力之后执行，当前交叉注意力无法指导同一去噪步骤中已执行的自注意力。
  - 采用指数移动平均更新缓存的显著性图：\(\bar{s}_v^t = \alpha \bar{s}_v^{t-1} + (1-\alpha) s_v^t\)，并每隔 \(K\) 个去噪步骤更新一次，减少开销并避免时序抖动。
  - 实验表明相邻步骤的显著性重叠高达约 0.93，因此可安全地本地窗口重用。

- **同步感知受保护稀疏注意力**：
  - 标准稀疏注意力通过掩码 \(M_{ij}\) 限制每个 query 的 key 子集。
  - 本文修改掩码：对属于保护集合的 query 行恢复全部 key 连接（即完整稠密注意力行），其余 query 仍采用原稀疏模式。
  - 公式化表示为：
    \[
    O_m = \mathrm{softmax}\left(\frac{Q_m K_m^\top}{\sqrt{d_h}} + \tilde{M}_m^t\right) V_m
    \]
    其中 \(\tilde{M}_m^t\) 对保护行置 0，对稀疏内连接置 0，其余为 \(-\infty\)。
  - 效果：同步关键 token 保留完整上下文，低显著性 token 继续走稀疏计算路径。

- **同步感知缓存重用（Cache Reuse）**：
  - 计算视频流、音频流各自的特征变化 \(\Delta_v, \Delta_a\)，以及保护区域内的特征变化 \(\Delta_p\) 和显著性漂移 \(\Delta_s\)。
  - 最终指标为：
    \[
    \Delta_{\mathrm{sync}} = \max(\Delta_v, \Delta_a, \lambda_p \Delta_p, \lambda_s \Delta_s)
    \]
    仅当 \(\Delta_{\mathrm{sync}} < \tau\) 时才复用缓存的块输出。
  - 该准则同时考虑双流特征变化、声音源区域变化和双向跨模态依赖漂移，比单模态的全局变化准则更安全。

- **推理复杂度**：
  - 视频自注意力的分数复杂度约为 \(O(H(\kappa N_v^2 + \rho_v N_v^2)d_h)\)，其中 \(\kappa\) 为稀疏保留比例，\(\rho_v\) 为小保护比例（默认 5%）。
  - 整体为训练无关（training-free），可直接用于可访问交叉注意力和块输出的双分支音视频生成模型。

## 6. 主要结论与发现

- 现有视频加速方法直接用于音视频生成会破坏跨模态证据，导致视觉质量或同步性下降。

## 8. 局限性

- **依赖双向交叉注意力的可访问性**：方法的核心引导信号来自音频-视频交叉注意力矩阵，因此仅适用于显式采用双分支并包含双向交叉注意力的生成模型。对于无交叉注意力或采用其他融合机制的模型，该框架无法直接应用。
- **显著性滞后引入潜在风险**：由于当前去噪步的自注意力执行先于交叉注意力，方法只能利用上一步（或若干步前）的显著性图来指导保护决策。尽管作者通过重叠度分析（约 0.93）论证了相邻步骤的稳定性，但在剧烈运动、快速场景切换或极端动态音源（如爆炸、瞬态强声）情况下，滞后显著性可能失效，导致保护区域偏离真正关键区域。
- **超参数调优成本**：保护比例 \(\rho_v\)、显著性更新间隔 \(K\)、缓存阈值 \(\tau\) 及权重 \(\lambda_p, \lambda_s\) 均需根据具体模型和内容类型进行调整。论文虽通过消融验证了合理性，但未提供自适应的选择机制，实际应用时可能需要针对新模型重新调参。
- **加速比受限于额外开销**：计算显著性图、维护缓存指标以及执行保护行掩码都需要额外运算。在 LTX-2.3 上仅获得 1.28× 加速，说明对于本身已高度优化的模型，本方法的边际收益有限；对于更快的设备或更短序列，额外开销占比可能进一步上升。
- **评估维度存在局限**：实验主要采用与稠密输出对比的保真度指标（PSNR/SSIM/LPIPS）和若干同步指标（Sync-C/Sync-D），但缺乏大规模真实用户主观评测，也未覆盖所有可能的音频类型（如语音、音乐混合场景）。音频质量仅用 VISQOL 衡量，粒度有限。
- **可复现性细节不足**：论文未报告使用的数据集来源（仅提及基于开源模型生成样本）、GPU 数量、总推理时间统计方差等细节，可能影响他人复现和公平比较。

## 9. 个人思考与启示

- **跨模态依赖可作为“计算重要性先验”**：本文的核心洞见——利用模型内部的交叉注意力识别同步关键计算——具有广泛的启发性。类似思想可迁移至其他多模态生成任务（如语音与音频、文本与视频、音频与虚拟形象等），只要生成模型内部存在可解释的跨模态交互信号，即可设计类似的保护-稀疏策略。
- **安全加速应尊重模型自身的注意力图**：作者证明了交叉注意力高响应区域与稀疏误差高发区域高度重合，这提示我们，模型内部的注意力模式本身就是计算重要性的“自然标注”，可替代人工启发式或额外训练的显著性预测器，且无需额外数据。
- **稀疏与缓存的融合可能是未来方向**：本文将 token 级稀疏与块级缓存结合起来，并用同一共享显著性先验协调两者。这种“先保护、后近似”的层次化思想可进一步与低比特量化、并行采样乃至扩散步蒸馏结合，形成更全面的推理优化栈。
- **训练无关方法的价值与边界**：训练无关方法的优势是即插即用，但其性能上限受限于模型架构。若能在训练阶段引入同步感知的稀疏性约束，或可进一步提升加速比与质量；这为未来的“架构-算法协同设计”提供了思路。
- **评价体系仍需完善**：音视频生成加速研究需要更统一、更全面的基准，包括不同分辨率、帧长、音频类型以及真实下游场景的测试，以便公正比较不同加速方法的通用性和鲁棒性。

## 总结

本文提出了一种训练无关的同步感知加速框架，通过双向交叉注意力生成显著性先验，在 token 级和块级同时实施“保护关键计算、稀疏冗余计算”的策略，在 Ovi 和 LTX-2.3 两个代表性音视频生成模型上验证了其在效率、质量和同步性之间的良好平衡。方法设计巧妙、论证充分，为多模态生成模型的推理优化提供了新的范式和实证基础。尽管存在对架构依赖、超参数敏感等局限，其核心思想——利用跨模态依赖信号指导安全近似——对领域内后续研究具有重要参考价值。
