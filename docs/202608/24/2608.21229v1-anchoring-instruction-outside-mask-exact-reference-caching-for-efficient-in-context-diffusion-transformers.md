## 摘要
全模态生成是广泛的内容创建和编辑应用的核心。上下文条件化对这种范式至关重要。它允许扩散 Transformer 在共享注意力序列中处理文本指令和视觉参考。然而，每个参考图像都会引入数千个 token。因此，计算量随参考数量快速增长。现有方法通过结构化稀疏注意力减少计算，这限制了参考 token 和目标 token 之间的交互。这种结构也使参考 K 和 V 独立于去噪目标，允许它们被计算一次并在步骤间复用。然而，它阻止了视觉参考关注文本指令。这显著降低了多参考编辑中的指令遵循和参考保真度。为解决这一冲突，我们联合重新设计了 token 序列和注意力掩码。我们的超越掩码设计使用静态文本锚点将指令连接到参考分支。它在不增加参数的情况下保留了精确的 K 和 V 复用。然而，这种直接的架构转换会降低生成质量。我们通过教师强制速度蒸馏，然后是一个短暂的在策略阶段（教师监督学生访问的状态）来恢复损失的性能。据我们所知，这是首次在扩散模型中将同策略蒸馏用于架构恢复。在三个图像编辑基准上，我们的方法匹配了全注意力生成质量。在五个参考图像下，它将完整的 40 步去噪过程加速了 3.92 倍，而静态文本锚点引入了可忽略的运行时开销；在我们的扩展研究中，十个参考时的加速比达到 5.47 倍。

## Abstract
Omnimodal generation is central to a wide range of content creation and editing applications. In-context conditioning is essential to this paradigm. It allows diffusion transformers to process text instructions and visual references in a shared attention sequence. However, each reference image introduces thousands of tokens. Computation therefore grows rapidly with the number of references. Existing methods reduce computation through structured sparse attention, which limits interactions between reference and target tokens. This structure also makes the reference K and V independent of the denoising target, allowing them to be computed once and reused across steps. However, it blocks visual references from attending to the text instruction. This substantially degrades instruction following and reference fidelity in multi-reference editing. To resolve this conflict, we jointly redesign the token sequence and attention mask. Our beyond-mask design uses static text anchors to connect the instruction to the reference branch. It preserves exact K and V reuse without adding parameters. However, this direct architectural conversion degrades generation quality. We recover the lost performance through teacher-forced velocity distillation, followed by a short on-policy stage in which the teacher supervises student-visited states. To our knowledge, this is the first use of on-policy distillation for architectural recovery in diffusion models. Across three image-editing benchmarks, our method matches full-attention generation quality. With five reference images, it accelerates the complete 40-step denoising process by 3.92x, while static text anchors introduce negligible runtime overhead; the speedup reaches 5.47x at ten references in our scaling study.

### 1. 核心问题与整体含义（研究动机与背景）

- **研究背景**：全模态（Omnimodal）生成系统旨在统一处理文本、图像、音频和视频。上下文条件化（In-context conditioning）是这一范式的核心机制，允许扩散 Transformer（Diffusion Transformer，DiT）将文本指令、目标图像和参考图像 token 拼接在同一注意力序列中联合处理。
- **核心痛点**：每个参考图像在 1024² 分辨率下约贡献 4000 个 token。当参考状态依赖演化中的目标时，模型必须在每个去噪步骤中重新计算参考相关的 K/V，计算量随参考图像数量线性乃至超线性增长。
- **现有方案的冲突**：
  - 结构化稀疏注意力（如 OminiControl2、EasyControl）通过隔离参考图像 token 与去噪目标，使参考 K/V 变得步骤无关，从而可以被**精确预计算并复用**，大幅降低计算成本。
  - 但这种隔离同时阻断了参考图像 token 访问**实时文本指令（live text）**的路径。由于文本-目标双向注意力会携带目标信息，若允许参考 attend 文本，参考 K/V 就会依赖演化中的目标，破坏精确缓存。
  - 结果是：**参考图像无法感知文本指令中"哪些视觉内容与指令相关"**，导致多参考编辑中的指令跟随和参考保真显著下降。
- **核心矛盾**：在原始 token 序列上仅修改掩码（mask）无法同时满足"参考可精确缓存"和"参考能访问实时指令"两个条件。作者通过依赖图分析证明了这一点（Theorem 1，详见附录 A）。
- **研究意义**：如何在保留精确参考缓存效率的同时，恢复参考分支对文本指令的感知能力，是实现高效多参考上下文编辑的关键问题。

### 2. 方法论：核心思想、关键技术细节

#### 2.1 核心思想概述

论文提出三种互补的技术组件，构成完整的解决方案：
1. **静态文本锚点（Static Text Anchors, ST）**：一种"超越掩码"（beyond-mask）的序列/注意力图设计，解决指令感知与精确缓存的冲突。
2. **两阶段蒸馏恢复（Two-Stage Distillation Recovery）**：修复架构转换造成的质量下降。
3. **精确参考缓存（Exact Reference Caching）**：在保证 K/V 可精确复用的前提下大幅降低推理延迟。

#### 2.2 静态文本锚点（Static Text Anchors）

- **Token 序列扩展**：将原始序列 `[LT; Xt; R]` 扩展为 `[LT; Xt; ST; R]`，其中 ST 是静态文本锚点，其时间步固定为 tST = 0。
- **注意力连接设计**：
  - ST 与 R 双向连接（互相关注）。
  - ST 和 R 均**不接收**来自 LT 或 Xt 的信息。
  - 原始分支保留 LT 与 Xt 之间的预训练交互，并继续 attend 到 R，但不 attend ST。
- **关键性质**：
  - 指令路径通过 ST → R 建立，但不打开 Xt → R 的目标路径，因此参考 K/V 保持步骤无关性。
  - **无新增参数**：ST 复用现有指令嵌入、注意力投影和 Transformer 权重。
  - **一次性预计算**：静态子图 `[ST, R]` 在去噪前只评估一次，仅缓存 R 的 K/V，ST 状态随即丢弃。
- **额外成本极小**：设 NR 和 NST 分别为参考和静态文本 token 数，额外注意力交互为 ΔAST = 2·NR·NST + NST²，仅在缓存构建时支付一次；由于 NST ≪ NR，运行时开销可忽略。实测中仅增加 0.3 秒（94.1s → 94.4s）。
- **规律性保持**：相比复杂掩码，ST 设计保持规则注意力布局，可直接使用 FlashAttention 等高性能内核。

#### 2.3 两阶段蒸馏恢复（Two-Stage Recovery）

架构转换（从全注意力到稀疏缓存结构）会使生成质量下降。作者提出两阶段恢复流程：

- **Stage 1：教师强制速度蒸馏（Teacher-Forced Velocity Distillation）**
  - 使用数据分布上的插值点（flow-matching interpolant xt = (1−t)x0 + tx1）作为查询状态。
  - 目标函数：最小化学生速度场与冻结的全注意力教师速度场之间的 L2 距离（v-MSE）。
  - 该阶段恢复大部分损失的质量，但会在数据分布状态上趋于饱和，无法覆盖学生推理轨迹上的状态。

- **Stage 2：同策略精炼（On-Policy Refinement）**
  - 让学生从噪声 z1 出发执行完整 rollout，采集自采样轨迹上的状态 zθt（使用 stop-gradient 阻止梯度回传采样器）。
  - 在这些学生访问状态上，用同一个教师提供速度目标，继续最小化 v-MSE。
  - 关键洞察：**教师强制蒸馏的数据前缀分布 ≠ 学生推理时的状态分布**。在当前学生轨迹上监督能直接纠正推理路径中的累积误差。
  - **据作者称，这是首次将同策略蒸馏用于扩散模型的架构恢复（architectural recovery）**。

#### 2.4 可扩展性分析（附录 C）

- 论文给出基于注意力交互计数的分析模型：R(NR) = T(NR+S)² / [(NR+NST)² + TS(NR+S)]。
- 证明在 T > 2 的合理条件下，加速比随参考 token 数单调递增，且渐近上限为 T 倍。

### 6. 主要结论与发现

1. **静态文本锚点有效解决"缓存-指令感知"冲突**：通过掩码外的静态指令路径，使参考 K/V 在保持精确可复用的同时获得指令感知能力，无需新增参数。
2. **同策略蒸馏对架构恢复至关重要**：教师强制蒸馏在实践中会饱和，继续增加训练步数无法突破瓶颈；同样步数的同策略监督能持续改善质量（8.019 → 8.185），证明"在哪查询教师"与"查询多少"同样重要。
3. **精确缓存可匹配全注意力质量**：在三个独立基准上，Text anchors 模型均与全注意力基线持平甚至略优（Overall 8.185 vs. 8.119）。

5. **方法与现有加速技术正交**：精确参考缓存主要移除参考侧的重复计算，可与量化、时间缓存、稀疏注意力等技术叠加。
