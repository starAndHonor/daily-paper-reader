## 摘要
视频扩散变换器处理长时空序列，使得自注意力成为高分辨率视频生成中的主要瓶颈。免训练稀疏注意力降低了这一成本，但自适应Top-$p$路由在多GPU序列并行下创造了不均匀的每头工作负载。由此产生的工作负载异构性将稀疏注意力转化为秩级掉队者问题。我们提出了\method{}，一种免训练的稀疏注意力系统，它在多GPU序列并行下提高了自适应稀疏注意力的分布式执行效率。\method{}使用Top-$p$路由、Top-$k$安全下限和视频感知块组织作为稀疏路由前端，然后在运行时修复物化掩码。运行时负载平衡通过P2P通信迁移少量重型头，以缩短当前关键路径。松弛感知稀疏增强用额外的高价值块填充剩余的非关键秩松弛，而重叠将调度和迁移开销隐藏在现有计算之后。在步骤蒸馏的Wan2.2 I2V上，\method{}将平均负载不平衡从1.34降低到1.08，并相比FlashAttention提供了$4.41\times$的注意力加速，同时实现了$2.02$--$2.11\times$的DiT推理加速，且视频质量具有竞争力。

## Abstract
Video Diffusion Transformers process long spatio-temporal sequences, making self-attention the main bottleneck in high-resolution video generation. Training-free sparse attention reduces this cost, but adaptive Top-$p$ routing creates uneven per-head workloads under multi-GPU sequence parallelism. The resulting workload heterogeneity turns sparse attention into a rank-level straggler problem. We present \method{}, a training-free sparse-attention system that improves the distributed execution efficiency of adaptive sparse attention under multi-GPU sequence parallelism. \method{} uses Top-$p$ routing, a Top-$k$ safety floor, and video-aware block organization as the sparse-routing frontend, then repairs the materialized mask at runtime. Runtime Load Balancing migrates a small number of heavy heads via P2P communication to shorten the current critical path. Slack-Aware Sparse Augmentation fills residual non-critical-rank slack with additional high-value blocks, while overlap hides scheduling and migration overhead behind existing computation. On step-distilled Wan2.2 I2V, \method{} reduces average load imbalance from 1.34 to 1.08 and delivers a $4.41\times$ attention speedup over FlashAttention, while achieving a $2.02$--$2.11\times$ DiT inference speedup with competitive video quality.

- **背景**：视频扩散 Transformer（Video DiT）在处理高分辨率、长时长视频时，时空 token 序列极长，自注意力的计算成本成为推理的主要瓶颈。例如，在单张 NVIDIA H20 GPU 上使用 Wan2.2-14B I2V 生成 5 秒 720p 视频约需两小时，其中注意力占推理总时间的 74.1%。虽然后续通过步骤蒸馏（step distillation）将去噪步数大幅减少（最高可提速 25 倍），但每步的序列长度和二次复杂度的注意力计算并未改变，注意力在少步数推理中仍然是主要瓶颈。
- **现有解决方案的不足**：训练自由（training-free）的稀疏注意力可以跳过低价值的查询-键交互，降低单次注意力成本。其中，自适应 Top-p 路由能根据每个注意力头的分布集中度动态调整保留块数，比固定 Top-k 更保真，但它在多 GPU 序列并行（Ulysses 风格）下引入了严重的**负载不均衡**：不同注意力头密度不同，导致各 GPU rank 上的实际工作量差异巨大，形成“掉队者”（straggler）问题，同步等待时间抵消了稀疏带来的收益。
- **核心问题**：如何在保留自适应稀疏注意力保真优势的同时，实现多 GPU 分布式执行的高效性和负载均衡。
- **整体含义**：论文提出 FVAttn，一种免训练、面向视频 DiT 推理的稀疏注意力系统，通过“路由决定算什么、负载均衡决定在哪里算、松弛感知增强把空闲算力转化为质量收益”的三段式协同设计，显著改善分布式稀疏注意力的执行效率与生成质量，为少步数视频扩散模型的规模化部署提供了新的系统级优化路径。

## 2. 论文提出的方法论

### 2.1 总体框架

FVAttn 在每次稀疏注意力层中执行以下流水线：

1. 构造自适应稀疏掩码（mask）；
2. 度量每个头的实际工作负载并执行带通信预算的 P2P 头迁移（Runtime Load Balancing, RLB）；
3. 在均衡后的残余空闲中增加额外的高价值稀疏块（Slack-Aware Sparse Augmentation, SASA）；
4. 执行块稀疏注意力；
5. 反向 All-to-All 恢复头顺序。

### 2.2 稀疏路由前端

- 采用 **Top-p 路由** 作为自适应性核心：根据每个查询块的注意力分布累计概率阈值 p 动态决定保留块数，分布集中则少保留，分布平坦或多峰则多保留。
- 增加 **Top-k 安全下限**：保证每个查询块至少保留 k 个块，防止路由估计误差导致过度稀疏化。
- 使用 **视频感知块组织**：沿 Hilbert 曲线重排块，使空间相邻 token 更容易落入相邻块，提升相似度估计质量。
- 路由过程同时输出每个头的密度（供 RLB 用）和块重要性排序（供 SASA 用），不增加额外计算。

### 2.3 运行时负载均衡（RLB）

- **核心观察**：Top-p 造成的负载不均衡具有高度局部性——大部分偏斜集中在少数“重头”上。因此，不需要全局重新分区，只需在掩码物化后迁移少量过载头即可修复关键路径。
- **形式化**：
  - 头 h 的工作量 \( L_h = \text{mean}_i \sum_j M_{h,i,j} \)；
  - rank r 的工作量 \( L_r = \sum_{h\in H_r} L_h \)；
  - 负载不均衡因子 \( \rho = \max_r L_r / (\frac{1}{R}\sum_r L_r) \)。
  - 目标：在单向单头迁移约束（每个 rank 最多发送并接收一个本地头，迁移约 20% 的本地头）下，最小化最大 rank 负载，并用方差作 tie-breaker。
- **实现细节**：所有 rank 通过一次轻量 all-gather 获取全局密度信息，然后各自独立执行确定性搜索，避免 rank-0 求解与广播同步。默认 8-GPU 下可枚举候选匹配，通用规模可构造单向环形拓扑。
- **效果**：Wan2.2 I2V 上将平均负载不均衡从 1.34 降至 1.08；进一步增加迁移预算收益很小，验证了少量迁移即可捕获大部分收益的判断。

### 2.4 松弛感知稀疏增强（SASA）

- **动机**：RLB 之后非关键 rank 仍可能有空闲时间（残余松弛）。这些空闲算力若不利用就会在同步等待中被浪费。
- **方法**：每个有足够松弛的 rank 计算额外稀疏预算 \( B_r = \eta_1 \Delta L_r \)，其中 \( \Delta L_r = L^{\text{new}}_{\max} - L^{\text{new}}_r \) 为当前 rank 到关键路径的间隙，\( \eta_1=0.8 \) 为增强系数。SASA 沿着路由阶段已经生成的块重要性顺序，将额外预算用于添加尚未被选中的高价值 key 块。
- **安全性约束**：要求 \( B_r \le \Delta L_r \)，且触发阈值 \( \eta_2=0.07 \) 避免微小松弛引入不必要的调度开销，从而保证不产生新的 straggler、不延长全局注意力时间。
- **与全局提高 Top-p 的区别**：全局提高阈值会增加所有 rank 工作量并延长关键路径；SASA 只在有松弛的 rank 上补充高价值块，不增加整体延迟。

### 2.5 运行时机制的分级启用策略

- 根据负载不均衡因子 \( \rho \) 决定是否启用额外机制：
  - \( \rho < k_1 \)（k1=1.05）：跳过额外机制；
  - \( k_1 \le \rho < k_2 \)（k2=1.10）：仅启用低开销的 SASA；
  - \( \rho \ge k_2 \)：先启用 RLB 修复关键路径，再启用 SASA 利用残余松弛。

### 2.6 高效实现与开销隐藏

- **CPU-GPU 重叠**：CPU 搜索 RLB 计划和计算 SASA 预算的同时，GPU 执行必要的 V 量化，隐藏调度成本。
- **计算-通信重叠**：P2P 头迁移异步发出后，GPU 继续处理非迁移头的量化和 SASA 增强，仅在真正需要迁移状态时才同步；对于闪退（flash fallback）分支，将注意力拆分为本地头与迁移头计算，与 P2P 传输重叠。
- **Overlap/Opt**：消除不必要的 CPU-GPU 同步，精简运行时管理和内核启动，最终将新增运行时组件的可见开销从串行的 ~2.6 ms（6.28%）降低到 ~0.7 ms（1.87%）。

## 6. 论文的主要结论与发现

1. **自适应稀疏注意力的保真优势与系统瓶颈并存**：Top-p 路由确实优于固定 Top-k，但其工作负载异构性在序列并行下会造成显著 rank 级 straggler。
2. **负载不均衡具有高度局部性**：少量重头贡献了大部分偏斜，因此受约束的 P2P 头迁移（每 rank 至多一头）即可将平均 \( \rho \) 从 1.34 降到 1.08，且通信与搜索开销极小。
3. **运行时修复优于历史布局复用**：相比 db-SP（基于历史/离线布局），RLB 在当前掩码物化后直接修复实际负载，在少步数视频 DiT（相邻步密度变化高达 97%）中更有效，速度和质量均有提升。
4. **松弛感知增强能“免费”提升质量**：SASA 在非关键 rank 的空闲时间内增加高价值块，不延长关键路径。在 RLB 基础上，Animate 上 PSNR 提升 0.458 dB、SSIM +1.7%、LPIPS -13.9%，而 DiT 延迟仅增加 0.03s。
5. **重叠优化可大幅隐藏可见开销**：通过 CPU-GPU 和计算-通信重叠，新增运行时组件可见开销仅占注意力时间的 1.87%。
6. **综合收益**：在 Wan2.2 I2V 上，FVAttn 相比 FlashAttention 实现 4.41× 注意力加速和 2.02–2.11× DiT 推理加速，同时保持或略微提升 VBench 得分；在 Animate 和 T2V 上也实现了“同速度更高质量”或“同质量更高速度”的 Pareto 改进。

## 7. 优点

- **问题定位精准**：识别了 Top-p 自适应稀疏注意力与多 GPU 序列并行之间的系统级矛盾，将其形式化为负载不均衡因子，并基于“少数重头造成大部分偏斜”的观察设计轻量修复，避免了昂贵全局重分区。
- **“事后修复”的新思路**：针对少步数视频推理中相邻步负载波动极大的特点（最大变化 97%），放弃基于历史/预测的布局策略，在掩码物化后直接使用实际负载进行修复，更符合真实执行状态。
- **三种机制互补清晰**：路由（选块）、RLB（定位）、SASA（填闲）各司其职，协同提升效率与质量，并且分级启停策略进一步降低了非必要开销。
- **开销可解释且可控**：建立联合收益模型 \( G = K - P - C - A \)，将负载均衡收益、通信、调度、增强开销统一量化，并通过重叠技术使可见开销控制在极低水平。
- **实验设计有区分度**：通过“+RLB 不改变质量但提速”“+SASA 不增延迟但提质量”“+Overlap 不改变负载但降延迟”三个层次的消融，清晰验证每个模块的设计目标。
- **实用性**：作为免训练、即插即用的运行时组件，可叠加在任意 Top-p 类稀疏注意力的后端，对现有部署友好。

## 8. 不足与局限

- **适用场景有限**：主要面向长时空序列的视频生成；对短序列或注意力稀疏性弱的任务（如许多图像生成任务），稀疏注意力的收益以及负载均衡/松弛增强的空间都会显著下降。
- **硬件依赖性强**：实验仅在 H20（8×，NVLink，CUDA 13.1）上验证。在 PCIe 连接、通信能力弱或计算/通信比不同的设备上，P2P 迁移和重叠策略的收益可能受限，需要重新校准迁移预算、触发阈值和重叠方式。
- **并行策略覆盖窄**：仅验证了 Ulysses 风格序列并行，未覆盖 Ring Attention、USP 等其他序列并行方案，也未涉及多节点场景。
- **Animate 数据集较小**：仅 20 个内部测试用例，实验的统计稳健性不足。
- **未给出统计显著性**：没有多次重复实验的标准差或置信区间，无法完全排除随机性。
- **基线调参细节有限**：对 Jenga、SVG2 等基线在不同 Top-p / Top-k 下的选择和调整过程描述较简略，可能影响对比的完全公平性。
- **质量评估体系存在片面性**：除 VBench 外，额外的保真度指标（PSNR 等）是与 FlashAttention 稠密输出对比的，可能与感知质量不完全一致；且稀疏方法在极低密度下可能出现过平滑等伪影，文中未做主观质量评测。
- **扩展性分析较浅**：图8展示了 2/4/8 GPU 下的表现，但没有更多 GPU 数量下的性能曲线，也没有讨论更大 batch 或多节点场景的适用性。
