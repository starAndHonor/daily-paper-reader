## 摘要
视频扩散Transformer（VDiT）实现了高保真生成，但密集的3D自注意力带来了二次方成本。现有的头级和块级稀疏方法在查询之间共享计算预算，忽视了token特定的注意力需求。我们观察到，保留密度在不同查询间变化，但与注意力熵呈对数线性相关，而主导交互形成以查询为中心的、具有token相关半径的邻域。基于这些发现，我们提出了Token半径注意力（TRA），一种免训练框架，将查询熵映射为解析令牌预算，并无显式键排序地将其转换为时间衰减半径。融合熵提取、预热重用和块稀疏掩码构建进一步减少了开销。在七种Wan2.1、Wan2.2和HunyuanVideo T2V/I2V配置中，TRA仅保留9-19%的注意力交互，实现了1.56倍至2.05倍的加速，同时生成质量具有竞争力。代码可在https://github.com/IF-LAB-PKU/Token-Radius-Attention获取。

## Abstract
Video Diffusion Transformers (VDiTs) enable high-fidelity generation but incur quadratic cost from dense 3D self-attention. Existing head- and block-level sparse methods share computation budgets across queries, overlooking token-specific attention demand. We observe that retained density varies across queries yet correlates log-linearly with attention entropy, while dominant interactions form query-centered neighborhoods with token-dependent radii. Based on these findings, we propose Token Radius Attention (TRA), a training-free framework that maps query entropy to an analytic token budget and converts it into a temporally decayed radius without explicit key ranking. Fused entropy extraction, warm-up reuse, and block-sparse mask construction further reduce overhead. Across seven Wan2.1, Wan2.2, and HunyuanVideo T2V/I2V configurations, TRA retains only 9-19% of attention interactions and achieves 1.56x-2.05x speedup with competitive generation quality. Code is available at https://github.com/IF-LAB-PKU/Token-Radius-Attention.

## 1. 核心问题与整体含义（研究动机）

- **背景**：视频扩散Transformer（VDiT）已成为高保真视频生成的主流架构，但其核心的密集3D自注意力机制在token数为N时需要计算O(N²)的交互，导致计算成本随视频时长和分辨率急剧增长，成为推理和部署的主要瓶颈。
- **现有方法的不足**：已有的稀疏注意力方法分为两类：
  - **头级方法**（如SVG、Radial Attention）：为每个注意力头分配固定的空间/时间稀疏模式；
  - **块级方法**（如SVG2、SpargeAttn）：选择重要的query–key块。
  - 这两类方法都**在同一头或块内对多个查询共享同一计算预算**，隐含假设组内所有查询的注意力需求相同。这与自注意力的行归一化性质相矛盾——不同查询的注意力集中程度差异很大，集中型查询只需少量键，而弥散型查询需要大量键。共享预算会导致在集中查询上浪费计算、在弥散查询上丢失重要键，从而损害生成质量。
- **本文目标**：实现**token级自适应的稀疏注意力**，使每个查询根据自身需求分配计算量，同时保持结构化、规则化以支持高效执行，兼顾适应性与效率。

## 2. 方法论：Token Radius Attention (TRA)

### 2.1 核心思想：熵→预算→半径（Entropy-to-Budget-to-Radius）

TRA是一个**无训练**的稀疏注意力框架，通过以下三个步骤实现查询级自适应稀疏：

### 2.2 关键洞察（Insights）

- **Insight I：Token特定的注意力稀疏性**  
  通过分析Wan/HunyuanVideo模型的注意力分布，发现：同一层、同一头内，不同查询为保留相同注意力质量（如τ=0.9）所需保留的键比例（保留密度Bτ）差异可达数量级；且**log Bτ与注意力熵H近似线性相关**（R²=0.94–0.99）。因此，熵可以作为查询级计算预算的紧凑信号，避免逐查询排序。

- **Insight II：Token半径注意力模式**  
  主导交互在空间上形成**以查询为中心的圆形邻域**，且归一化注意力概率随二维空间距离近似指数衰减。不同查询的邻域半径各不相同，且随时间帧距离增加而收缩。

### 2.3 具体方法

1. **熵到预算映射（Entropy-to-Budget）**  
   - 定义查询i的注意力熵：`H_i = -Σ p_ij log p_ij`。  
   - 采用**熵等价有效支持近似**：假设注意力为均匀分布在`m_i = exp(H_i)`个有效键上的分布，推导出达到目标注意力质量τ所需的键数估计：
     ```
     K̂τ_i = ⌈τ · exp(H_i)⌉
     ```
   - 对应保留密度约为 `B̂τ_i ≈ τ·exp(H_i)/N`，实现了无需完整注意力的解析式预算预测。

2. **预算到半径构建（Budget-to-Radius）**  
   - 将预算`K̂τ_i`转化为**以查询为中心的基础半径`r_i`**，利用时间衰减因子`ϕ(δ)=exp(-γδ)`对各帧施加半径收缩：`r_{i,t} = r_i · ϕ(|t - f_i|)`。  
   - 先由连续面积相等给出初始半径，再通过网格精确计数（等式12–13）选最小候选半径，使离散支持数达到目标键数。  
   - 最终掩码定义为：`M_ij = I[d_s(i,j) ≤ r_i · ϕ(|f_j - f_i|)]`，其中`d_s`是二维空间距离。  
   - 文本键始终保持可见。

3. **高效实现**  
   - **Flash Radius Mask Kernel**：将每帧划分为tile，按tile-major重排token，将不规则token级掩码转换为规则的块稀疏掩码，供FlashInfer执行。融合了距离计算、半径比较、块剪枝和token投票，避免逐头调度开销。  
   - **Fused Attention Entropy Kernel**：通过在线softmax状态重写熵公式`H_i = log Z_i - Σ p_ij s_ij`，在正向传播中同时累积熵，无需额外pass。  
   - **Warm-up重用**：仅在去噪前25%的密集步骤计算熵和掩码，后续稀疏步骤复用预算、半径和掩码，进一步降低开销。

## 8. 不足与局限

- **稀疏模式受限**：TRA采用预定义的、基于空间距离和时间衰减的固定模式，难以覆盖长程语义相关、非局部运动或场景依赖的注意力结构。
