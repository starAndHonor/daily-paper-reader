## 摘要
长上下文推理已成为大语言模型的一项标志性能力，但精确的稠密注意力仍因随序列长度二次增长而代价高昂。块稀疏注意力通过将每个查询块路由到一小组相关的键块，提供了一种硬件友好的替代方案，然而准确的免训练块路由仍然困难。现有路由器通常对 RoPE 后的 token 表示进行池化，这会将语义聚合与 RoPE 诱导的几何信息纠缠在一起，并通过高频相位抵消削弱局部位置线索。为解决这一失配问题，我们提出语义-几何解耦路由（Semantic-Geometric Decoupled Routing），一种免训练的块路由框架，它将语义聚合转移到 RoPE 前空间，并利用离线结构先验和相对块距离重建几何偏置。这种分解产生了显式的闭式块路由得分，无需 token 级搜索或事后校准。在长上下文文本和视频任务上的实验表明，我们的方法在 4K--128K 上下文下接近全注意力精度，路由开销保持在 3.4 ms 以下，并在 128K 上下文长度下相比 FlashAttn 实现了 5.03× 的加速。

## Abstract
Long-context inference has become a defining capability of large language models, but exact dense attention remains costly due to its quadratic scaling with sequence length. Block-sparse attention offers a hardware-friendly alternative by routing each query block to a small set of relevant key blocks, yet accurate training-free block routing remains difficult. Existing routers often pool post-RoPE token representations, which entangles semantic aggregation with RoPE-induced geometry and attenuates local positional cues through high-frequency phase cancellation. To resolve this mismatch, we propose \textbf{Semantic-Geometric Decoupled Routing}, a training-free block routing framework that shifts semantic aggregation to the pre-RoPE space and reconstructs geometric bias with an offline structural prior and relative block distances. This decomposition yields an explicit closed-form block routing score without token-level search or post-hoc calibration. Experiments on long-context text and video tasks show that our method approaches full-attention accuracy across 4K--128K contexts, keeps routing overhead below 3.4 ms, and achieves a 5.03$\times$ speedup over FlashAttn at a 128K context length.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：长上下文推理已成为大语言模型（LLM）的核心能力，但标准稠密自注意力对 token 两两计算交互，计算成本随序列长度**二次增长**（O(L²)），在长文档、多轮对话、长视频等场景中代价高昂。
- **块稀疏注意力的价值**：通过将连续 token 分组为局部块（block），把 token 级索引替换为粗粒度块路由，更契合 GPU 的 tiling 与矩阵计算模式，是硬件友好的稀疏化方案。其流程为“块路由（block routing）+ 稀疏注意力计算”。
- **核心痛点**：块路由的**准确性与轻量化**难以兼得。现有免训练路由器普遍对**RoPE 后（post-RoPE）**的 token 表示做平均池化来估计块亲和度，这带来两个问题：
  - **语义与几何纠缠**：语义聚合与 RoPE 诱导的位置旋转耦合在一起；
  - **高频相位抵消**：RoPE 用相位旋转编码位置，高频维度在相邻 token 间变化剧烈，池化后会产生破坏性相位干涉（destructive interference），削弱高频特征与局部位置线索（论文 Figure 1 展示了 post-RoPE 池化的高频能量损失）。
- **现有补救手段的不足**：token 级搜索（如 MInference、FlexPrefill）增加路由复杂度、侵蚀稀疏化收益；事后温度校准（如 Prism）可能放大噪声且无法完全恢复丢失特征。
- **整体含义**：论文提出 **SGDR（Semantic-Geometric Decoupled Routing）**，一个免训练块路由框架，将语义聚合移至 **pre-RoPE 空间**，并用**离线结构先验 + 相对块距离**重建几何偏置，得到**闭式块路由得分**，在保持全注意力精度的同时显著降低路由开销。

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想
从精确的 token 级注意力得分出发，把块路由重新表述为**动态语义相关性**与**内在几何先验**两部分，实现语义与几何的严格解耦。关键观察是：问题不在于使用位置信息本身，而在于**语义聚合与几何位置建模被耦合**。

### 2.2 宏观-微观几何解耦定理（附录 B.1）
- 定义块 i 与块 j 在第 f 个旋转子空间上的宏观注意力得分为块内所有 token 级内积的均值。
- 代入 RoPE 定义 \(x_{post} = x_{pre} e^{i\omega_f p}\)，通过坐标变换（绝对位置 → 局部偏移 n, m）分离出**宏观块距离 \(\Delta M = i-j\)** 与**微观 token 偏移 n, m**，得到：
  \[
  S_f(i,j) = \text{Re}\big(I_f(i,j) \cdot e^{i\omega_f B\Delta M}\big)
  \]
  其中 \(I_f(i,j)\) 是**完全在 pre-RoPE 空间**计算的微观相位干涉项。

### 2.3 从 O(B²) 到 O(1) 的块级近似（附录 B.2）
- 直接计算 \(I_f\) 仍需 O(B²)，为此引入**宽平稳（WSS）随机过程**假设与遍历性假设。
- 将 pre-RoPE 局部 token 分解为**块级均值语义中心**（如 \(\bar{q}^{(i)}_{pre,f}\)）与**零均值高频残差**；由于均值与残差的交叉项在期望下为零，干涉项近似为块均值内积：
  \[
  I_f(i,j) \approx \hat{C}_f(\Delta M) \cdot \big[\bar{q}^{(i)}_{pre,f} \cdot (\bar{k}^{(j)}_{pre,f})^*\big]
  \]
- \(\hat{C}_f(\Delta M)\) 即**归一化结构谱**，作为离线校准的几何先验。

### 2.4 离线几何刻画（Offline Geometric Profiling）
- 使用**任务无关的标准文本语料**离线校准，提取各层、各频率子空间的 pre-RoPE 隐状态。
- 定义微观相位干涉算子 \(M_f(i,j)\)，并将归一化结构谱形式化为其与块级语义内积之比的语料期望，用**复数最小二乘**估计以保证数值稳定。
- 极坐标分解：\(\hat{C}_f(\Delta M) = \hat{\Lambda}_f(\Delta M) \cdot e^{i\hat{\theta}_f(\Delta M)}\)
  - **结构幅度 \(\hat{\Lambda}_f\)**：距离感知的能量补偿器，恢复被均值池化干涉掉的高频对角特征（局部上下文）；
  - **结构相位 \(\hat{\theta}_f\)**：相位偏置，校正 RoPE 空间中目标宏观距离的旋转偏移。
- 超出最大校准距离（\(\Delta M > \Delta_{max}\)）时，几何先验趋于平稳噪声底，推理时对距离索引做**截断（clamp）**，此后由动态语义激活主导路由。

### 2.5 在线语义路由与闭式打分（附录 B.3）
- 将实时 pre-RoPE 均值池化特征投影到极坐标，得到幅度（语义能量）与相位角（内在语义相位）。
- 定义动态语义相位差 \(\Phi^{(i,j)}_f = \phi^{(i)}_{q,f} - \phi^{(j)}_{k,f}\)。
- 最终闭式块路由得分（Eq. 12）：
  \[
  S_{Block}(i,j) = \sum_f \underbrace{\hat{\Lambda}_f(i-j)}_{\text{离线先验}} \cdot \underbrace{\|\bar{q}^{(i)}_{pre,f}\|\|\bar{k}^{(j)}_{pre,f}\|}_{\text{在线语义}} \cdot \cos\Big(\underbrace{\omega_f B(i-j) + \hat{\theta}_f(i-j)}_{\text{宏观几何}} + \underbrace{\Phi^{(i,j)}_f}_{\text{在线宏观相位}}\Big)
  \]
- 随后施加因果掩码，用 **top-p 阈值**选择相关键块，构建稀疏掩码，仅在选中块内执行精确 token 级注意力。
- **复杂度**：实时张量计算仅为均值池化和相位差提取，路由得分降至近似 O(1)；幅度与几何相位项离线预计算、直接从内存加载。论文还实现了**自定义 Triton 内核**以发挥块级公式的硬件优势。

## 6. 主要结论与发现

- **精度**：在 4K–128K 上接近全注意力精度。RULER 上平均分最高（Llama-3.1: 87.55；Qwen-3-8B: 86.09），128K 时优于 Prism（+0.82）和 FlexPrefill（+0.69）。LongBench 上 40.73（Llama）/39.12（Qwen），在 Qwen-3-8B Few-shot Learning 上达 58.60，超过全模型（56.69）。PG19 平均 PPL 25.23，接近 FlashAttn（25.25）且优于 Prism（25.25）。视频任务保持全模型 99.5% 的性能（VideoMME 70.85 vs 71.22；LVB 64.96 vs 65.00）。
- **效率**：路由开销在所有长度下均低于 3.4 ms（128K 时 3.37 ms）；128K 下总注意力延迟从 451.03 ms 降至 89.59 ms，相比 FlashAttn 加速 **5.03×**，优于 MInference（4.79×）和 Prism（3.76×）。
- **消融**：全模型始终最优；去掉离线画像降至 78.87%，去掉宏观几何降至 73.84%，去掉在线相位降至 74.94%，纯语义（无位置）最差（67.26%），且长上下文退化更明显——证明各组件缺一不可。
- **可视化**：纯语义分布均匀无焦点；post-RoPE 池化削弱对角与局部特征；块中心 RoPE 过度孤立对角线；本方法同时恢复连续对角、局部上下文与远距离检索能力。

## 7. 优点（方法与实验设计亮点）

- **理论驱动、闭式解**：从 token 级注意力精确形式出发，经严格代数推导（附录 B.1–B.3）得到闭式块路由得分，而非启发式设计。
- **免训练、即插即用**：无需微调即可替换现有块路由模块，兼容 YaRN、Interleaved M-RoPE 等 RoPE 变体。
- **纯块级路由**：不依赖 token 级搜索或事后校准，实时计算仅为均值池化与相位差，复杂度近似 O(1)，硬件友好。
- **离线先验设计巧妙**：将几何信息沉淀为可离线预计算、推理时直接加载的“结构幅度 + 结构相位”，并采用距离截断处理超长距离。
- **公平性考量细致**：刻意选择公开已久的校准语料以避免语义泄漏带来的不公平比较。
- **实验维度完整**：跨任务、跨长度、跨模态（文本 + 视频）、含消融与可视化，效率对比严格同环境。
- **自定义 Triton 内核**：将块级公式真正落地到高效实现。

## 8. 不足与局限

- **架构限制**：仅适用于标准 Softmax 自注意力；不适用于去除标准 Softmax 矩阵的非注意力/线性注意力架构（如 Gated Delta Net、Lightning Attention）。
- **位置编码依赖**：数学框架依赖 RoPE 的几何结构，无法直接应用于可学习绝对位置嵌入等旧式位置编码。
- **假设依赖**：块级近似建立在宽平稳（WSS）与遍历性假设之上，对不满足该假设的分布或模型可能引入偏差。

- **数据覆盖**：离线画像语料（Paul Graham Essays、VideoChatGPT）相对单一，未讨论跨领域/跨语言泛化性。
- **未涉及训练场景**：作为免训练方法，未与 MoBA 等基于训练的可学习路由方案做直接对比，也未评估与训练式方法的组合潜力。
