## 摘要
视频扩散计算开销高昂，因为它需要在多个去噪步骤中执行一个大模型。即使采用步骤蒸馏，推理仍然昂贵，因为每个蒸馏后的步骤仍需要一次昂贵的模型评估。我们提出 TRACK：通过 top-K 选择的轨迹感知容量路由（TRajectory-Aware Capacity routing via top-K selection），一种异构去噪策略，在选定的步骤于兼容的大模型和小模型之间切换，从而降低每次去噪评估的平均成本。切换步骤通过校准过程确定。TRACK 首先用大模型展开一条参考轨迹。然后在每一步，也收集小模型的预测，并将其与大模型的预测进行比较，以获得相对不一致性分数。两个模型接收相同的潜在表示、时间步、条件输入和引导输入。在校准集上聚合该信号，会生成跨扩散步骤的不一致性分数图，从而为高效推理过程确定切换策略：对质量敏感的步骤继续使用大模型，而不一致性分数低的步骤则路由到小模型。推理在每一步只执行选定的模型，无需重新训练、更改架构或调度器，也无需在线双模型评估。在 Wan 2.1、Cosmos 3、TurboDiffusion 和 FastVideo 上，TRACK 分别实现了 1.95 倍、2.04 倍–2.73 倍、2.69 倍和 2.17 倍的加速，同时具有可比的总体质量和高度多样性保留。因此，TRACK 将自动化的、免训练的模型切换确立为视频扩散的一种实用加速范式。

## Abstract
Video diffusion is computationally expensive, as it requires executing a large model across many denoising steps. Even with step-distillation, inference remains expensive because every distilled step still requires a costly model evaluation. We present TRACK: TRajectory-Aware Capacity routing via top-K selection, a heterogeneous denoising strategy that switches between compatible large and small models at selected steps, reducing the average cost per denoising evaluation. The switching steps are determined using a calibration process. TRACK first rolls out a reference trajectory with the large model. Then at each step, the small model's prediction is also collected and compared against the large model's prediction to obtain a relative disagreement score. Both models receive the same latent, timestep, conditioning, and guidance inputs. Aggregating this signal over a calibration set produces a disagreement score map across diffusion steps, which determines a switching policy for an efficient inference process: quality-sensitive steps keep using the large model, while steps with low disagreement scores are routed to the small model. Inference executes only the selected model at each step, requiring no retraining, architecture or scheduler changes, or online dual-model evaluation. Across Wan 2.1, Cosmos 3, TurboDiffusion, and FastVideo, TRACK yields $1.95\times$, $2.04\times$-$2.73\times$, $2.69\times$, and $2.17\times$ speedups, respectively, with comparable aggregate quality and high diversity retention. TRACK thereby establishes automated, training-free model switching as a practical acceleration paradigm for video diffusion.

## 1. 核心问题与研究动机

- **背景瓶颈**：视频扩散模型（如 Wan 2.1 14B、Cosmos 3 Super 64B）需要在数十个去噪步上反复执行数十亿参数的大模型，推理延迟是部署的首要瓶颈。
- **现有加速路线的盲区**：
  - *步数削减*类方法（DPM-Solver、分布匹配蒸馏、LCM、SDXS、TurboDiffusion、FastVideo 等）压缩采样轨迹，但通常需要额外训练，且每一步仍是全量模型评估，成本不降。
  - *单步成本削减*类方法（特征缓存、流式执行、稀疏计算、模型共享等）降低单次前向开销。
  - 二者之外仍存在一处未被利用的冗余：**在采样器与步数确定后，所有剩余步骤都以均一成本分配给同一个模型**。
- **模型切换（model switching）思路**：用"大模型保质量、小模型保速度"的异构容量分配来降低每步的平均模型成本，与步数削减**互补相乘**而非竞争。
- **为何不能简单切换**：基于固定时间边界或单向 handoff 的朴素策略无法刻画视频生成的复杂时空动态——两个模型可能总体误差相近，却在空间细节、镜头运动、帧间一致性上于特定时间步发生分歧；未校准的容量削减还可能改变结构承诺并导致样本多样性坍缩。
- **核心研究问题**：给定一对可互换的大/小 checkpoint，如何**自动、离线地判定哪些去噪步可以安全切换到小模型**，同时保护质量敏感步、保留生成多样性。

## 2. 方法论

### 2.1 总体框架

TRACK（**TR**ajectory-**A**ware **C**apacity routing via top-**K**）分两阶段：

- **离线校准阶段**：在共享的"全大模型参考轨迹"上，逐步采集大、小模型的配对预测，计算归一化分歧分数图，导出切换策略 π。
- **在线执行阶段**：每一步只执行策略指定的**单个**去噪器，共享 latent、条件与调度器状态推进。

### 2.2 形式化基础

- 记去噪步索引 i 的噪声视频 latent 为 x_{t_i} ∈ R^{C×F×H×W}，调度器时间步递减 t_0 > … > t_{N−1}。
- 引导预测（含 classifier-free guidance，引导强度 w）：
  p_m(x_{t_i}, t_i) = f_m(x_{t_i}, t_i, ∅) + w·(f_m(x_{t_i}, t_i, τ) − f_m(x_{t_i}, t_i, ∅))，m ∈ {L, S}
- 调度器更新：x_{t_{i+1}} = S(x_{t_i}, p_m(x_{t_i}, t_i), t_i, h_i)，h_i 为多步求解器所需历史状态。
- **TRACK 只改变"由哪个模型提供预测"**，不改时间步序列、预测目标、调度器及其状态演化。
- **兼容模型对的条件**：共享 latent 表示、输出形状、条件接口、预测目标与调度器语义；内部架构与参数量可不同（如 Wan 家族 14B/1.3B）。

### 2.3 参考轨迹校准

- 给定小型校准集 D = {d_j}（j = 1…M），每个 prompt 正常初始化，**全程用大模型 rollout 完整参考轨迹**。
- 在每次调度器更新之前，用**完全相同的**参考 latent x^{(j)}_{t_k}、时间步、正/负条件、引导尺度分别评估大、小模型，因此配对预测**仅去噪器不同**。
- 记录配对后，仍由大模型预测推进轨迹，保证后续探测始终位于全大模型参考路径上。
- 该校准开销**仅离线发生**，不计入在线推理。

### 2.4 归一化预测分歧分数

- 单样本单步相对分歧（用大模型预测幅度归一化，ε 防止除零）：
  r_{j,k} = ‖p_S(x^{(j)}_{t_k}, t_k) − p_L(x^{(j)}_{t_k}, t_k)‖₂ / max(‖p_L(x^{(j)}_{t_k}, t_k)‖₂, ε)
- 跨校准集求均值得到最终步级分歧分数：
  q_k = (1/M) Σ_{j=1}^{M} r_{j,k}
- **q_k 越低 ⇒ 大小模型越一致 ⇒ 该步越适合用小模型**。

### 2.5 用 Top-K 切换求解约束轨迹发散最小化

- 定义平方发散代价 W_k = q_k²，松弛切换变量 β_k ∈ [0,1]，使用小模型带来的收益为 −C_0 Σ_k β_k（C_0 为用户指定的成本常数，如硬件延迟）。
- 盒约束优化：arg min_{β_0,…,β_{N−1} ∈ [0,1]} Σ_k (W_k − C_0) β_k
- 目标对 β_k **线性且可分离**，故最优解为阈值解：
  β*_k = 1（W_k < C_0），β*_k = 0（W_k > C_0）
- **固定预算 K 的实用形式**：把 q_k 最小的 K 个步路由给小模型，其余保留大模型。由于 q_k ≥ 0，按 q_k 排序等价于按 W_k = q_k² 排序；把 C_0 取在第 K 小与第 K+1 小的 W_k 之间，即可精确选中这 K 步。**指定 C_0 等价于指定 K**，连续松弛天然存在离散最优解，无需额外的混合整数建模。

### 2.6 推理

- 严格按离线策略 π 执行：x_{t_{i+1}} = S(x_{t_i}, p_{π(i)}(x_{t_i}, t_i), t_i, h_i)。
- 每步仅一个 checkpoint，无缝传递共享 latent、条件与调度器状态；**无需学习式路由模块，也无需在线双模型同时评估**。
- 单步延迟为 C_m 时，总去噪成本约为 Σ_i C_{π(i)}，加上常规调度器开销；校准是一次性离线设置，**部署期零额外开销**。
- 策略可**连续或非连续**（可在中途切回大模型），突破单向 handoff 的限制。

- **速度-质量权衡优于等预算切换**：在相同小模型调用次数下，TRACK Top-K 在四条流水线上均取得比 First-K（T-Stitch）、Last-K、Random-K 更好的质量保持，说明"选哪些步"比"选多少步"更关键。
- **与步数削减正交互补**：在 FastVideo（3 步）、TurboDiffusion（4 步）等已高度压缩的蒸馏流水线上，TRACK 仍能进一步降低平均单步成本，验证了"轨迹压缩"与"容量分配"两个维度的可叠加性。
- **分歧分数的结构性规律**：q_k 在采样轨迹上呈非均匀分布——通常在高噪声/低噪声两端与中间语义成形阶段表现出不同的一致性水平，这解释了为何固定时间边界的 First-K / Last-K 策略次优，也解释了单向 handoff 的局限。
- **多样性保护**：相比 All-Small 或过度激进的容量削减，TRACK 在保持与全大模型相近的成对 DreamSim 距离方面更优，缓解了"结构承诺改变导致模式坍缩"的问题。
- **能耗收益**：在单张 A100 上，去噪循环的累计 GPU 能耗随小模型替换步数下降而降低，TRACK 在选定 K 下获得可测量的能耗节省。
- **人工评测**：与全大模型成对比较中，TRACK 在视觉质量与 prompt 遵循度两个维度上被判定为与全大模型相当（无明显质量退化），同时具备实际延迟优势。

## 7. 结论与贡献

- **核心贡献**：提出一种**免训练、离线校准、在线单模型执行**的轨迹感知容量路由方法，把"哪些去噪步可以安全用小模型"这一决策问题形式化为可分离的阈值优化，并证明连续松弛天然给出离散最优解（Top-K），无需混合整数建模或学习式路由器。
- **方法层面的价值**：
  - 将模型切换从"固定边界/单向 handoff"推广到**任意、可非连续**的步级路由；
  - 与步数削减方法**正交**，可作为其上层插件叠加使用；
  - 部署期零额外开销（每步只跑一个模型，无在线双模型评估）。
- **实证层面的价值**：在四条主流文生视频流水线上系统验证了速度-质量-多样性-能耗的多维权衡。

## 8. 优点

1. **问题切入精准**：识别出"步数固定后每步均一成本分配"这一被忽视的冗余，与既有加速路线正交。
2. **方法简洁且理论清晰**：归一化分歧分数 + 线性可分离代价 → 阈值/Top-K 最优解，推导干净，实现成本低。
3. **工程友好**：免训练、离线一次性校准、在线单模型前向，兼容同家族不同规模 checkpoint，落地门槛低。
4. **实验设计有对照意识**：等预算消融严格控制了小模型调用次数，避免"用得多所以快"的混淆；参考轨迹校准保证配对预测的可比性。
5. **同时报告质量、多样性与能耗**，而非只看 FVD/CLIP 类单一指标，贴合真实部署关注点。

## 9. 局限与存疑

- **算力与校准成本报告不足**：未给出校准集规模 M、校准耗时/算力，也未说明主实验所用 GPU 型号与数量；仅有单卡 A100 的能耗实验配置明确。
- **校准集依赖性**：q_k 由小型校准集估计，其跨 prompt 分布的稳定性、对分布外输入的泛化性未充分讨论；若校准集偏差较大，路由策略可能次优。
- **模型对约束**：方法要求大/小模型共享 latent 表示、输出形状、条件接口、预测目标与调度器语义，跨家族（如不同 VAE 或不同噪声调度）的异构对不适用，通用性受限。
- **质量判定标准偏软**："与全大模型可比"主要基于自动指标与人工成对偏好，缺乏显著性检验与更严格的统计保障。
- **基线覆盖有限**：未与免训练缓存类、稀疏注意力类等单步成本削减方法直接对比，难以判断 TRACK 相对这些路线的相对优势。
- **成本常数 C_0 的物理含义**：虽然指定 C_0 等价于指定 K，但 C_0 与真实硬件延迟的对应关系、如何在不同硬件上迁移 K 值，论文讨论较少。

## 10. 可复现性评估

- **正面因素**：方法免训练，核心步骤（参考轨迹 rollout、配对评估、q_k 计算、Top-K 路由）描述明确，理论上易于复现；使用公开模型（Wan 2.1、Cosmos 3）与公开评测集（VBench、EvalCrafter、T2V-CompBench）。
- **风险因素**：校准集构建方式、M 的取值、K 的具体工作点、随机种子设置、DreamSim 与 VBench 的具体版本与后处理细节若未在附录完整给出，复现结果可能出现偏移；算力信息缺失也影响成本复现。

## 11. 总体评价

TRACK 是一篇**问题定义清晰、方法轻量且理论干净**的视频扩散加速工作。它没有去卷"更少步数"或"更快的单步算子"，而是开辟了"异构容量在时间轴上如何分配"这一正交维度，并用归一化分歧分数把该问题化归为可分离阈值优化，得到免训练、部署期零开销的 Top-K 路由策略。实验在四条主流流水线、250 prompt 上覆盖速度、质量、多样性、能耗四个维度，等预算消融设计严谨。主要短板在于算力/校准成本报告不充分、校准集代表性未验证、基线族较窄，以及质量可比性缺乏统计检验。总体而言，**方法贡献与工程实用性强于实证严谨性**，适合作为现有步数削减与单步加速方案之上的通用插件。
