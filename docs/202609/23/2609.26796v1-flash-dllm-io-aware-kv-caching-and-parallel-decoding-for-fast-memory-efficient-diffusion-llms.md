## 摘要
扩散大语言模型（dLLM）近来已成为自回归 LLM 的一种有前景的替代方案，能够实现非自回归文本生成。然而，其实际部署仍受限于低效推理，这在很大程度上是由于缺乏有效的键值（KV）缓存和可扩展的并行解码机制。现有加速方法通常孤立地研究 KV 缓存与并行解码，忽视了当缓存复用与并行 token 验证联合应用时出现的 I/O 瓶颈。在这项工作中，我们提出了 Flash-dLLM，一个无需训练的推理加速框架，用于快速且内存高效的 dLLM。Flash-dLLM 首先将 GPU 内存 I/O 识别为启用 KV 缓存的 dLLM 推理中的主要瓶颈，并通过 I/O 感知的融合 KV 缓存内核来解决该问题，以减少冗余内存移动。基于这种优化的缓存机制，Flash-dLLM 进一步提出了一种高效的 KV 缓存驱动草稿-验证解码策略，其中 dLLM 本身同时充当起草器和验证器，无需辅助模型。这种统一设计在保持生成质量的同时实现了更快的解码，并提升了对更长序列和更大批大小的可扩展性。在数学推理和代码生成基准上的大量实验表明，Flash-dLLM 在推理速度和内存效率方面均持续优于现有最先进的 dLLM 加速方法。特别是，在 GSM8K 和 HumanEval 上，它相比此前最强基线 Elastic-Cache 分别实现了 5.1 倍和 11.0 倍的加速。

## Abstract
Diffusion Large Language Models (dLLMs) have recently emerged as a promising alternative to autoregressive LLMs by enabling non-autoregressive text generation. However, their practical deployment remains limited by inefficient inference, largely due to the absence of effective Key-Value (KV) caching and scalable parallel decoding mechanisms. Existing acceleration methods typically study KV caching and parallel decoding in isolation, overlooking the I/O bottlenecks that arise when cache reuse and parallel token verification are jointly applied. In this work, we introduce $\textbf{Flash-dLLM}$, a training-free inference acceleration framework for fast and memory-efficient dLLMs. Flash-dLLM first identifies GPU memory I/O as a dominant bottleneck in KV-cache-enabled dLLM inference and addresses it with an I/O-aware fused KV-cache kernel that reduces redundant memory movement. Building on this optimized cache mechanism, Flash-dLLM further proposes an efficient KV-cache-driven draft-and-verify decoding strategy, where the dLLM itself serves as both drafter and verifier without requiring an auxiliary model. This unified design enables faster decoding while preserving generation quality and improving scalability to longer sequences and larger batch size. Extensive experiments on mathematical reasoning and code-generation benchmarks demonstrate that Flash-dLLM consistently outperforms existing state-of-the-art dLLM acceleration methods in both inference speed and memory efficiency. In particular, it achieves $5.1\times$ and $11.0\times$ speedups over prior strongest baseline Elastic-Cache on GSM8K and HumanEval, respectively.

## 1. 核心问题与整体含义

- **背景**：扩散大语言模型（dLLM）通过迭代去噪实现非自回归文本生成，在可控生成、全局序列精修与并行性上具有潜力，但推理效率显著落后于成熟的 AR LLM 系统。
- **核心瓶颈**：
  - dLLM 在去噪迭代中反复重建与搬运 KV 状态，更新 token 集合不断变化，导致频繁的 KV 缓存读写；朴素 KV 缓存虽减少浮点计算，却引入大量 GPU 显存访问开销（图 1a 显示内存受限操作主导延迟）。
  - 每个去噪步处理全序列，但仅少数 token 对当前预测有显著影响（图 1b：中间层 top-32 被关注 token 贡献约 50% 注意力权重）。
  - 置信度动态：许多 token 在早期已语义确定，但置信度未越过保守阈值，造成"token 就绪"与"token 提交"的错配（图 1c：平均置信度与早期可解码 token 数正相关，r=0.48）。
- **整体含义**：现有加速方法（Fast-dLLM、Elastic-Cache 等）孤立研究 KV 缓存与并行解码，忽视了二者联合应用时的 I/O 瓶颈。Flash-dLLM 提出统一的免训练框架，将 dLLM 固有的并行性转化为实际 wall-clock 加速与显存可扩展性。

## 2. 方法论

### 核心思想
- 联合优化 **I/O 感知 KV 缓存（Flash-Cache）** 与 **KV 缓存驱动的并行 draft-and-verify 解码（Flash-Verify）**，无需辅助模型、无需训练。

### Flash-Cache（IO 感知 KV 缓存）
- **融合内核**：将 QKV 投影、RoPE、缓存写入合并为单个 Triton 内核，在 SRAM 内完成投影与 RoPE，直接将 K/V 写入 KV 缓存，消除中间张量物化。传统实现每层 HBM 流量约 `4×O(Qd_model) + O(Nd)`，融合后大幅降低；RTX 3090 上实现 1.37× 加速。
- **Scheduled Flash Attention**：将 batch 划分为多个序列块，用 block table 对齐 query 块与对应 KV 块，应对缓存阶段与更新阶段序列长度差异大、batch 内样本进度不一致的问题，支持灵活增删块。
- **选择性缓存更新（Constrained cache update）**：仅维护并更新固定预算 βt 的最受关注 token 集合。注意力得分公式：
  - `at_i = Σ_l (1/H) Σ_h (1/|M^t_βm|) Σ_{j∈M^t_βm} S^{t,l,h}_{j,i}`，i ∈ D^{<t}
  - 跟踪集 `T^{t+1} = top-k({at_i : i ∈ D^{<t}}, βt − |D^t|) ∪ D^t`，下一步查询集 `Q^{t+1} = M^{t+1}_βm ∪ T^{t+1}`，将每步计算限制在 βt + βm。

### Flash-Verify（KV 缓存驱动 draft-and-verify）
- **动机**：置信度感知解码只接受 ci ≥ ϵ 的 token，浪费大量正确但未过阈值的预测。
- **流程**：
  - **Draft 阶段**：在 Qt = T^t ∪ M^t_βm 上运行模型，掩码位置按置信度分为 confident 集 D^t（≥ϵ，直接接受）与 search 集 S^t（<ϵ，待验证）。
  - **Verify 阶段**：构造新查询，含三组——调整后的跟踪集 Tv、search 位置填入草稿预测（draft view）、同位置填入 [MASK]（mask view）；两者共享位置嵌入，但通过融合 Triton 内核中的因果注意力掩码隔离，使跟踪上下文不能注意 draft view，同一位置的 draft 与 mask view 也不能互相注意。
  - **接受规则**：`accept(i) = I[x̂i = x̃i] · I[c̃i ≥ γ]`，按因果顺序依次接受，遇首个不匹配即停止。
  - 验证 pass 复用同一融合内核与预分配 KV 缓存，额外开销与 2βm 成正比而非全序列。
- **理论保证（附录 C）**：
  - 单 token 偏差：`TV(π_i, p^i) = 1 − c̃i ≤ 1 − γ`
  - 块偏差：`TV(π_A, p_A) = 1 − Π c̃_ik ≤ 1 − γ^m ≤ m(1−γ)`
  - 由于验证掩码在因果顺序下构建，p_A 是模型对块的真正联合分布，不引入并行解掩码的依赖误差。

## 6. 主要结论与发现

- **速度**：Flash-Cache 在贪心解码下实现 8.0×–58.5× 加速；置信度感知下 17.0×–102.2×；Flash-Cache + Flash-Verify 达到 148.0–210.6 tokens/s，加速比 22.3×–148.2×。
- **相对 Elastic-Cache**：GSM8K 加速 5.1×、HumanEval 加速 11.0×。
- **精度**：GSM8K-512 上 Flash-Verify+Flash-Cache 同时取得最高精度 83.02% 与最高吞吐 210.6 t/s；数学任务上组合方法距最佳精度不超过 1.78pp；256-token 代码任务差距约 3.60–3.66pp。
- **显存与扩展性**：batch size 16 时显存约 26GB，比 Fast-dLLM 的 50GB 减少约 48%；batch 32 仍可线性扩展，Fast-dLLM 在 batch 24 OOM。
- **解码效率**：Flash-Verify 每步解码 5.7 tokens，置信度感知为 2.8，贪心为 1.0；batch 32 时比置信度感知快约 43.2%。
- **权衡**：γ 与 βt 提供互补控制；提高精度约 3.18pp 会使吞吐下降约 52.6%。

## 7. 优点

- **统一视角**：首次指出 KV 缓存复用与并行验证联合时的 GPU 显存 I/O 瓶颈，并给出系统级解决方案。
- **免训练、无辅助模型**：dLLM 自身兼任 drafter 与 verifier，通过双视图因果掩码实现自验证，部署成本低。
- **I/O 感知内核设计**：融合 QKV 投影、RoPE、缓存写入，消除中间物化，并配合 block table 调度应对变长序列。
- **选择性缓存更新**：基于注意力稀疏性只更新最有影响的 token，减少冗余访存。
- **理论支撑**：附录 C 给出 Flash-Verify 的逐 token 与块级 TV 偏差上界，论证 γ 门控的意义。
- **实验扎实**：多任务、多长度、多 batch、多超参，含 5 seed 统计、Pareto 前沿与定性样例；显存与吞吐均优于基线。

## 8. 不足与局限

- **模型覆盖有限**：仅在 LLaDA-1.5 上验证；未在连续空间扩散语言模型或其他 dLLM 架构（如 Dream、LLaDA 2.0）上测试。
