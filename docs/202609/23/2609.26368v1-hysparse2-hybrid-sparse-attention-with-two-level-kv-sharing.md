## 摘要
长时程与多轮智能体通常生成简短动作，并处理来自工具和环境的长观测。不断增长的上下文要求高效预填充、紧凑的 KV 缓存存储以及准确的长上下文检索。为满足这些需求，我们提出 HySparse2，一种具有两级 KV 共享的混合稀疏注意力架构。在外层，KV Bridging 采用 YOCO 风格的自解码器与交叉解码器结构，但仅桥接全注意力层。自解码器使用混合滑动窗口注意力（SWA），而交叉解码器使用混合稀疏注意力。交叉解码器中全注意力层的 KV 缓存由自解码器中全注意力层的隐藏状态生成。在内层，HySparse2 保留 HySparse 的核心 KV Reuse 设计，并做了两项改进。首先，它将块级稀疏性替换为 token 级稀疏性，以实现更精细的长上下文检索。其次，它从稀疏层中移除了独立的 SWA 分支，转而将近期 token 的滑动窗口强制纳入稀疏选择。这种两级 KV 共享使得所有交叉解码器 KV 缓存都可以由自解码器隐藏状态构建。因此，预填充可以在自解码器之后退出，跳过所有交叉解码器层。在 80B-A3B MoE 模型上，HySparse2 在长上下文检索和多轮智能体任务上优于 HySparse 和 Hybrid SWA，同时大幅减少预填充计算量和 KV 缓存存储。

## Abstract
Long-horizon and multi-turn agents typically generate short actions and process long observations from tools and environments. This growing context demands efficient prefill, compact KV-cache storage, and accurate long-context retrieval. To meet these demands, we introduce HySparse2, a hybrid sparse attention architecture with two-level KV sharing. At the outer level, KV Bridging adopts a YOCO-style self-decoder and cross-decoder structure, but bridges only full-attention layers. The self-decoder uses hybrid sliding-window attention (SWA), while the cross-decoder uses hybrid sparse attention. The KV caches for full-attention layers in the cross-decoder are generated from the hidden states of full-attention layers in the self-decoder. At the inner level, HySparse2 retains HySparse's core KV Reuse design with two refinements. First, it replaces block-level sparsity with token-level sparsity for finer long-context retrieval. Second, it removes the separate SWA branch from sparse layers and instead forces a sliding window of recent tokens into the sparse selection. This two-level KV sharing allows all cross-decoder KV caches to be constructed from self-decoder hidden states. Prefill can therefore exit after the self-decoder, skipping all cross-decoder layers. On an 80B-A3B MoE model, HySparse2 outperforms HySparse and Hybrid SWA on long-context retrieval and multi-turn agentic tasks, while substantially reducing prefill computation and KV-cache storage.

  - 块级稀疏在长程多轮检索中精度不足，token 级稀疏更适合精细检索。

## 2. 方法论：核心思想与关键技术

- **总体架构**：HySparse2 将骨干分为：
  - **自解码器**：混合全注意力与滑动窗口注意力，负责局部建模和构建全局 KV。
  - **交叉解码器**：混合全注意力与稀疏注意力，负责全局检索。
- **两级 KV 共享**：
  - **外层 KV Bridging**：只在自解码器与交叉解码器的全注意力层之间桥接。
  - **内层 KV Reuse**：每个混合块内，稀疏层复用全注意力层的 KV cache 与选择索引。

### 外层：Full-Attention-Only KV Bridging

- 对一对全注意力层 \((i,j)\)，其中 \(i\) 在自解码器，\(j\) 在交叉解码器：
  - 交叉解码器层 \(j\) 的 K/V 来自自解码器层 \(i\) 的隐藏状态：
    - \(K_j^{cross} = \text{Proj}_K^j(H_i^{self})\)
    - \(V_j^{cross} = \text{Proj}_V^j(H_i^{self})\)
    - \(Q_j^{cross} = \text{Proj}_Q^j(H_j^{cross})\)
- 每个交叉解码器全注意力层仍有自己的 K/V 投影，因此共享隐藏状态来源但生成不同 KV cache。
- 每层保留独立 Q 投影，作用于自身当前隐藏状态。
- 支持两个解码器使用不同混合比例，一个自解码器全注意力层可供给多个交叉解码器全注意力层。

### 内层：Cross-Layer KV Reuse 的两项改进

- **Token 级稀疏选择**：
  - 用 token 级 top-\(k\) 替代 HySparse 的块级稀疏。
  - 在全注意力层计算精确 token 分数，后续稀疏层复用被选中 token 的 KV 条目。
  - 论文认为这更适合多轮长上下文智能体，因为需要精确检索历史中的关键 token。
- **移除独立 SWA 分支，强制局部窗口**：
  - 不再在稀疏层中保留单独 SWA 分支。
  - 将最近 \(128\) 个 token 强制纳入稀疏选择，再在窗口外选择最高分 token。
  - 局部与全局 token 都从同一份全注意力 KV cache 读取。
  - 这样交叉解码器无需构建自身隐藏状态对应的局部 KV 后缀，预填充可在自解码器后完全退出。
- **全注意力的作用**：
  - 保留少量全注意力层作为“索引器”，用精确注意力分数为后续稀疏层提供 oracle token selection。
  - 无需单独索引器模块或辅助蒸馏目标。
  - 但全注意力仍昂贵，因此比例保持较小。
- **推理架构**：
  - **Prefill-Decode 分离**：预填充节点只部署自解码器和 KV Bridging 投影。49 层模型中只需前 25 层，预填充节点内存需求约减半。
  - 交叉解码器全注意力 KV cache 在预填充节点计算后传给解码节点，因为投影后 KV 小于源隐藏状态。
  - **推测解码**：预训练使用一个 MTP 层，条件于自解码器/交叉解码器边界隐藏状态；后训练可替换为更大 DFlash 风格 drafter，未来可支持异步草稿与验证。
