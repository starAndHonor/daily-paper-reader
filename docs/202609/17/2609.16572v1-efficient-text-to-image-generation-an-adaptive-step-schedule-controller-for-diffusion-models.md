## 摘要
文本到图像扩散模型通常使用固定数量的去噪步数，以平衡时间成本和图像质量。然而，最优步数取决于输入文本提示的复杂度。我们提出一种自适应扩散控制器，无需额外训练模型，即可动态调整步数，以高效生成高质量图像。通过利用具有不同步长的混合步数调度，并评估每个时间步的误差项差异，我们的方法在不同调度之间切换以优化性能。在 COCO 和 DiffusionDB 上的实验表明，我们的方法在保持视觉保真度的同时减少了推理时间，为文本到图像扩散模型提供了一种更高效的替代方案。

## Abstract
Text-to-image diffusion models often use a fixed number of denoising steps, balancing time costs and image quality. However, the optimal number of steps depends on the complexity of the input text prompt. We propose an adaptive diffusion controller that dynamically adjusts the number of steps to generate high-quality images efficiently, without additional model training. By leveraging a mixture of step schedules with varying step sizes and evaluating the error term discrepancy at each timestep, our method transitions between schedules to optimize performance. Experiments on COCO and DiffusionDB show that our approach reduces inference time while maintaining visual fidelity, offering a more efficient alternative for text-to-image diffusion models.

# 论文深度总结：面向扩散模型的自适应步数调度控制器（ADSC）

## 1. 核心问题与研究背景

- **研究动机**：文本到图像扩散模型（如 Stable Diffusion）在推理时需要多次前向去噪，计算开销大。业界普遍采用**固定步数**（如 50 步）来权衡时间与质量。
- **核心痛点**：
  - 固定步数是一种"一刀切"策略，忽略了不同文本提示（prompt）与随机种子（seed）对生成难度的差异。
  - 简单提示（如"猫、车、桌子"）用固定步数会**冗余计算**；复杂提示（如含键盘细节、路牌文字的物体）用固定步数则可能**质量不足**。
  - 现有加速方案（知识蒸馏、NAS、量化、DDSM 等）大多**需要额外训练**，且仍然使用固定步数调度，未做到按任务自适应。
- **整体含义**：论文提出 **ADSC（Adaptive Diffusion Step Controller）**，在不训练模型的前提下，为每个文本提示动态分配"刚好够用"的去噪步数，实现**质量保持下的推理加速**。

## 2. 方法论

### 2.1 核心思想
- 利用**条件噪声估计与无条件噪声估计之间的余弦距离**作为收敛启发式：
  - 余弦距离大 → 文本描述的内容尚未生成 → 采用**小步长**精细去噪。
  - 余弦距离小 → 内容已基本生成 → 切换到**大步长**调度，加速收敛。
- 整个去噪过程由**最长调度开始**，检测到收敛后逐级切换到更短的调度（步长更大）。

### 2.2 异构调度控制空间
- 控制空间 $C = \{S_1, S_2, ..., S_K\}$，包含 $K$ 个步数递减的调度，满足 $N^k > N^{k+1}$，且相邻调度的步长严格递增。
- 当在调度 $S_k$ 的第 $t_i^k$ 步检测到收敛时，切换到下一调度 $S_{k+1}$ 中**时间步最接近**的位置：$j = \arg\min_{j'} |t_{j'}^{k+1} - t_i^k|$。
- 最终混合调度 $M = \bigcup_{k=1}^{K} \{t_{st}^k, ..., t_{end}^k\}$，即各调度片段的拼接。
- 算法流程（Alg. 1）：从 $k=1$ 开始，逐步遍历时间步；未收敛则将当前步加入混合调度并前进；一旦收敛则 $k \leftarrow k+1$ 并对齐到最近时间步，直到结束。

### 2.3 收敛判据（基于余弦距离的肘点检测）
- 在 Classifier-Free Guidance 下，总噪声估计为 $\hat{\epsilon} = \epsilon_u + \gamma(\epsilon_c - \epsilon_u)$，其中 $\gamma=7.5$。
- 定义余弦距离 $d_{cos}(t) = d_{cos}(\epsilon_u, \hat{\epsilon})$，其随去噪推进呈类反指数衰减。
- 为抑制曲线抖动导致的**局部极小值误判**，先做**指数平滑**：
  $$\tilde{d}_{cos}(t_i) = \alpha d_{cos}(t_i) + (1-\alpha)\tilde{d}_{cos}(t_{i-1})$$
- 计算平滑曲线的一阶、二阶导数：
  $$\tilde{d}_{cos}'(t_i) = \tilde{d}_{cos}(t_i) - \tilde{d}_{cos}(t_{i-1})$$
  $$\tilde{d}_{cos}''(t_i) = \tilde{d}_{cos}(t_{i+1}) + \tilde{d}_{cos}(t_{i-1}) - 2\tilde{d}_{cos}(t_i)$$
- 收敛条件：当 $|\tilde{d}_{cos}'(t_i)| < \delta_1$ 且 $|\tilde{d}_{cos}''(t_i)| < \delta_2$ 时，判定达到肘点，触发调度切换。

## 6. 主要结论与发现

- ADSC 可将平均去噪步数从 50 步降至 **约 18–25 步**（部分场景**减少超过 50%**），同时保持甚至提升视觉质量。
- **COCO 结果**：
  - DDIM+ADSC（18.89 步）：CLIP-I 95.70 vs 固定 19 步 92.40（+3.3%），DINO 92.42 vs 84.12（+8.30%）。
  - PNDM+ADSC（24.48 步）：CLIP-I 94.10 vs 92.60（+1.50%），DINO 89.24 vs 84.96（+4.28%）。
  - DDIM+ADSC 甚至**超过固定 31 步**基线。
- **DiffusionDB 结果**：
  - DDIM+ADSC（18.06 步）：CLIP-I 95.10 vs 91.90（+3.2%），DINO 89.36 vs 82.96（+6.4%）。
  - PNDM+ADSC：CLIP-I 无明显提升，DINO 下降 1.59%，表明 ADSC **与 DDIM 兼容性更好**。
- **CLIP-T 基本持平**，说明文本对齐能力未受损。
- **延迟几乎不变**：ADSC 与相同步数的固定调度耗时相当（差异在小数点后两位）。
- 扩展对比中，**DDIM+ADSC 在所有调度器中取得最佳 CLIP-I / DINO**（表 3）。
- 复杂提示（如笔记本电脑键盘、路牌文字）所需步数明显更多，验证了"步数应随提示复杂度变化"的假设。

## 7. 优点

- **免训练、即插即用**：可直接挂载到现有扩散采样器（DDIM/PNDM），无需蒸馏或架构修改，部署成本低。
- **任务自适应**：按 prompt + seed 的实际收敛情况动态分配步数，避免了"一刀切"。
- **启发式有理论直觉**：用条件/无条件噪声方向差异（余弦距离）作为内容是否生成到位的信号，并借助平滑 + 一/二阶导数检测肘点，思路清晰、计算开销小。
- **异构调度空间设计巧妙**：相邻调度步数减半，保证时间步重合，使切换对齐自然、误差可控。
- **实验验证较全面**：两个数据集、多个调度器、多指标 + 定性图，结论有一定说服力。
- **质量-效率双赢**：在相同平均步数下，CLIP-I/DINO 优于固定步数基线，甚至超过更高步数基线。
