## 摘要
将语言模型扩展到长上下文受限于自注意力的二次成本。块稀疏注意力提供了一种高效替代方案，但选择保留块仍是瓶颈。传统块选择需要对所有查询-块对进行评分，因此在序列长度上仍是二次复杂度。为解决此问题，我们提出 PISA，一种采用金字塔式 Top-$K$ 选择策略的块稀疏注意力机制。其主要思想是在不同层级逐步缩小候选范围，从而更高效地找到最相关的键。具体而言，我们构建键的由粗到细层次结构，并从最粗层级开始选择。在每个层级，对有限候选集应用 LogSumExp 评分，以选择进入下一更细层级的候选，直至到达最细层级。通过池化，我们构建 $O(\log N)$ 个键层级，总体复杂度为 $O(N\log N)$，其中 $N$ 表示序列长度。我们为训练和推理开发了硬件感知的 Triton 内核，将分层路由和 LogSumExp 评分融合在一起，而无需物化查询-键评分矩阵。我们进一步在语言建模任务上评估了我们的方法。与基线相比，我们的方法在常识推理等基准上达到相当的性能，同时在检索任务上取得更好的结果。

## Abstract
Scaling language models to long contexts is limited by the quadratic cost of self-attention. Block sparse attention offers an efficient alternative, but selecting the retained blocks remains a bottleneck. Conventional block selection requires scoring all query-block pairs and therefore remains quadratic in sequence length. To address this issue, we propose PISA, a block-sparse attention mechanism that employs a pyramid Top-$K$ selection strategy. The main idea is to gradually narrow down the candidates across different levels, making it more efficient to find the most relevant keys. Specifically, we construct a coarse-to-fine hierarchy of keys and perform selection from the coarsest level. At each level, LogSumExp scoring is applied to a bounded candidate set to select candidates for the next finer level, continuing until the finest level is reached. Through pooling, we construct $O(\log N)$ levels of keys, yielding an overall complexity of $O(N\log N)$, where $N$ denotes the sequence length. We develop hardware-aware Triton kernels for both training and inference, fusing hierarchical routing and LogSumExp scoring without materializing the query-key score matrix. We further evaluate our method on language modeling tasks. Compared with the baseline, our method achieves comparable performance on benchmarks such as commonsense reasoning while delivering better results on retrieval tasks.

# 论文总结：Block Sparse Attention with Log-Linear Complexity（PISA）

## 1. 核心问题与研究动机

- **背景**：将语言模型扩展到长上下文已成为重要需求，但全自注意力的计算复杂度随序列长度呈二次增长（$O(N^2)$），在长序列上代价过高。
- **块稀疏注意力的定位**：通过将键/值划分为大小为 $C$ 的连续块、让每个查询只关注被选中的 $K$ 个块，可将注意力计算本身降至线性。块稀疏注意力通常分两阶段：Top-$K$ 块选择 + 在选中块上计算注意力。
- **核心瓶颈**：传统块选择需要对每个查询与**所有**候选键块（约 $N/C$ 个）计算相关性得分，全序列选择阶段的总复杂度仍为 $O(N^2/C)$。因此，尽管注意力计算是线性的，**块选择阶段反而成为长上下文建模的主要计算瓶颈**。
- **整体含义**：论文提出 PISA（Pyramid Sparse Attention），通过层次化的粗到细 Top-$K$ 选择，把块选择复杂度从二次降到 $O(N\log N)$，并配套硬件感知内核，使长上下文稀疏注意力在理论上和工程上都更可行。

## 2. 方法论

### 2.1 核心思想
- 构造键块的**由细到粗金字塔层次**，选择时从最粗层开始，逐层缩小候选范围（由粗到细），每层只对**有界候选集**评分，避免与所有细粒度块做穷举比较。
- 使用 **LogSumExp（LSE）评分**代替简单均值评分，以更准确地估计块的真实注意力质量。

### 2.2 层次构造（由细到粗）
- Level 0 为原始键（单例块），$M_0 = N$。
- 第一个聚合步以 $g_0 = C$ 形成叶块，$M_1 = M = \lceil N/C \rceil$，即论文中的 leaf blocks。
- 更高层以 $g_\ell = g = 2$ 聚合相邻子块：$M_{\ell+1} = \lceil M_\ell / g_\ell \rceil$。
- 每个块的摘要向量通过**递归均值池化**得到：父块摘要 = 子块摘要的均值；当每步合并等长子块时，摘要等于块内所有原始键的均值。
- 层次总层数为 $L = O(\log N)$。

### 2.3 选择流程（由粗到细）
- 对每个查询 $q_t$，在最粗层初始化候选集 $A^{(L)}_t = \{1\}$。
- 在每一层 $\ell$：对候选集计算得分，用 `Select K` 保留得分最高的 $K$ 个块，得到 $I^{(\ell)}_t$；再将选中块展开为其子块，构成下一更细层的候选集 $A^{(\ell-1)}_t = \bigcup_{i \in I^{(\ell)}_t} \mathrm{Ch}_{\ell-1}(i)$。
- 由于分支因子 $g$ 固定，每层候选规模有界：$|A^{(\ell-1)}_t| \le gK$。
- 若某层候选数不超过 $K$，则全部保留、无需评分。
- 最终叶层保留的块 $I_t = I^{(1)}_t$ 用于在原始键/值上计算稀疏注意力。

### 2.4 LSE 评分
- 中间层候选块 $i$ 的得分为其子摘要上的 LSE：$s^{(\ell)}_{t,i} = \log \sum_{r \in \mathrm{Ch}_{\ell-1}(i)} \exp(q_t^\top \bar{k}^{(\ell-1)}_r / \sqrt{d})$。
- 叶层候选块则对原始键做精确 LSE。
- 附录给出理论分析：归一化后的子均值 LSE 与父块原始键 LSE 之间存在夹逼关系（$\frac{1}{g}\sum_j m_j \le \hat{F}(B) \le F_q(B)$），说明 LSE 比均值更接近真实块质量；同时 LSE 的一阶、二阶 Taylor 展开分别对应 PISA-1（均值）和 PISA-2（均值 + 半方差），PISA 不做截断因而更精确。

### 2.5 内核实现
- 遵循 NSA 的 GQA 设定，同一 KV 头对应的查询头共享选中块。
- **训练/prefill 两阶段内核**：
  - Stage 1：并行于查询位置与 KV 头，逐层执行中间层选择；对共享 KV 头的多个查询头求 LSE 得分之和作为块得分，再做 Select K 并展开子块。
  - Stage 2：对候选叶块按 KV 头分组、再按查询分块（$Q_{tile}=4$），每个程序加载一个键块并复用于多个查询，计算精确 LSE 后做最终 Top-$K$。
- **解码单阶段内核**：从最粗层一路选到叶层，融合为单次内核启动，避免多次启动开销；缓存均值金字塔，仅增量更新当前叶均值及其祖先路径。
- 两阶段设计的原因（IO 分析）：训练/prefill 时两阶段通过键块复用降低叶层 Q/K IO（当 $GQ + C/Q_{tile} < C$ 时成立，配置 $GQ=16, Q_{tile}=4, C=64$ 满足）；解码时每簇只有一个查询、无跨查询复用，故用单阶段避免重复加载查询。

### 2.6 复杂度
- 每查询选择复杂度 $O(\log N)$，全序列训练/prefill 为 $O(N\log N)$；解码平均每步 $O(\log N)$（含偶发的缓存扩展代价）。
- 与 BSA/MoBA/NSA/HiLS 等 $O(N^2)$ 方法形成对比。

## 6. 主要结论与发现

- PISA 在语言建模与常识推理上**与 BSA、NSA、HiLS 相当**，训练损失在多数尺度上略优。

## 7. 优点

- **理论贡献清晰**：把块选择的复杂度从 $O(N^2/C)$ 降到 $O(N\log N)$，并给出完整的复杂度推导与 IO 成本分析。
- **评分函数有依据**：用 LSE 替代均值，并用 Jensen 不等式与 Taylor 展开证明其更接近原始键 LSE；PISA-1/PISA-2 作为一阶/二阶截断提供了自然的消融对照。
- **算法与硬件协同设计**：针对训练/prefill 与解码分别设计两阶段/单阶段内核，融合层次路由与 LSE 评分、不物化 Q-K 得分矩阵，并利用键块复用降低 IO。
- **实验较为系统**：多尺度、多任务、含选择质量诊断与效率基准，诊断实验复用 Full-Attention Q/K 保证公平。
- **工程实用性**：解码缓存只需 $O((N/C)d)$ 元素且按固定比例扩容，平均每步 $O(\log N)$，适合长上下文推理场景。

## 8. 不足与局限

- **实验规模有限**：最大模型仅 2.67B、预训练 100B tokens + CPT 10B tokens，未验证更大规模（如 7B+、万亿 token）下的表现与相对增益。
- **未报告算力细节**：缺少 GPU 型号、数量、训练时长等信息，难以评估实际训练成本与可复现性。
