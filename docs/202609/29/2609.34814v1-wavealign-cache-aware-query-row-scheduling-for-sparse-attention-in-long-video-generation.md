## 摘要
基于扩散Transformer（DiT）的长视频生成会产生极长的 token 序列，使注意力成为主要的推理瓶颈。动态稀疏注意力可减少计算量，但其实际加速仍受限，因为不规则的查询行执行会降低 L2 缓存局部性并增加 HBM 流量。我们提出 WaveAlign，一个面向动态稀疏注意力的轻量级、缓存感知查询行重排序框架。WaveAlign 将行排序建模为一个优化问题，并通过两个阶段对其进行近似。第一阶段推导稀疏掩码行的低秩 SVD 表示，并将具有相似 K/V 访问模式的查询行分组，从而增加并发调度行之间的 K/V 重叠。第二阶段利用流式 GPU 调度，在每个波次内按 K/V 块数量降序对行排序，从而使当前波次的短行之后紧接着下一波次的长行。这使 K/V 访问在波次边界上对齐，并使共享块在淘汰前可被复用。一个自适应跳过模块可避免无收益的重排序。通过仅置换查询行和掩码行，WaveAlign 保持了稀疏注意力语义，且无需更改现有方法或后端内核。在两种 GPU 架构、两种视频 DiT 和四种稀疏注意力方法上，WaveAlign 将 L2 缓存命中率从 28.48%--36.35% 提升至 79.38%--89.06%，将 HBM 读取流量最多降低 92.11%，并在不损失质量的情况下实现最高 1.25 倍的内核加速和 1.17 倍的端到端生成加速。

## Abstract
Long-video generation with diffusion transformers (DiTs) produces extremely long token sequences, making attention a dominant inference bottleneck. Dynamic sparse attention reduces computation, but its realized speedup remains limited because irregular query-row execution degrades L2 cache locality and increases HBM traffic. We present WaveAlign, a lightweight, cache-aware query-row reordering framework for dynamic sparse attention. WaveAlign formulates row ordering as an optimization problem and approximates it with two stages. The first stage derives a low-rank SVD representation of sparse-mask rows and groups query rows with similar K/V access patterns, increasing K/V overlap among concurrently scheduled rows. The second stage exploits streaming GPU scheduling by sorting rows within each wave in descending order of their K/V-block counts, so that short rows from the current wave are followed by long rows from the next. This aligns K/V accesses across wave boundaries and enables shared blocks to be reused before eviction. An adaptive skip module avoids unprofitable reordering. By only permuting query and mask rows, WaveAlign preserves sparse-attention semantics and requires no changes to existing methods or backend kernels. Across two GPU architectures, two video DiTs, and four sparse-attention methods, WaveAlign raises the L2 cache hit ratio from 28.48%--36.35% to 79.38%--89.06%, reduces HBM read traffic by up to 92.11%, and achieves up to 1.25x kernel and 1.17x end-to-end generation speedup without quality loss.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：扩散 Transformer（DiT）已成为长视频生成的主流范式，但视频序列极长（如 401 帧 720p 视频对应 364K token），注意力模块占据推理时间的 73%–90%，是主要瓶颈。以 Wan2.1-14B 为例，单张 H100 生成该视频需 10,678 秒，其中注意力占 85.86%。
- **现有方案的不足**：动态稀疏注意力（MInference、FlexPrefill、XAttention、SpargeAttn 等）通过只计算重要 K/V 块来减少 FLOPs，但实际加速远低于计算量削减比例——实测加速仅为理论上限的约 80%（差距达 1.09×–1.26×）。
- **根本原因**：论文通过 NCU 剖析与 Roofline 分析发现，稀疏化使注意力从**计算受限**转变为**内存带宽受限**。密集注意力 HBM SOL 为 49.38%、L2 命中率 46.51%；而稀疏方法 HBM SOL 升至 79%–88%、L2 命中率骤降至 14%–22%。
- **两大根因**：
  - **空间离散的 K/V 访问**：同一波次内查询行选择的 K/V 块彼此重叠极少，访问并集超出 L2 容量，导致块在被复用前即被驱逐。
  - **NNZ 引发的时间错位**：各行非零块数量不同，执行时间不一，流式调度下短行提前完成并拉入下一波次的行，使共享块访问在时间上被拉开，超出复用距离。
- **整体含义**：WaveAlign 提出一种轻量、缓存感知的查询行重排序框架，仅置换查询行与掩码行，不改变稀疏注意力语义与后端内核，即可将稀疏注意力从内存带宽受限拉回计算受限，填补"FLOPs 削减"与"实际加速"之间的鸿沟。

## 2. 方法论：核心思想与关键技术细节

### 核心思想
- 查询行之间相互独立，输出可逆序恢复；因此可对查询行与掩码行联合重排，将访问相似 K/V 块的行聚到同一波次，提高跨 SM 的 L2 复用、降低 HBM 流量。
- 将行排序建模为优化问题：将掩码行划分为 k 个波次（每波最多 W 行），最小化同一波次内行间距离（即最大化 K/V 访问重叠），约束为每行恰好出现一次（`P_h P_h^T = I`）。该问题为 NP-hard，故采用两阶段近似。

### 第一阶段：基于 SVD 的全局空间排序
- **列中心化**：对掩码做 `M̃ = (I − (1/M_B)11^T)M`，保持行间成对距离不变。中心化的关键作用是消除"行工作量（NNZ）"这一常数方向——否则首个奇异向量会被行质心占据。
- **低秩距离保持嵌入**：由 SVD 分解 `M̃ = Σ σ_t u_t v_t^T`，行间距离可精确分解为 `‖M̃[i]−M̃[j]‖² = Σ σ_t²(u_t[i]−u_t[j])²`。取秩 r=2 的截断嵌入 `(σ₁u₁[i], σ₂u₂[i])`，由 Eckart–Young 定理保证这是最小二乘意义下最优的低维距离保持嵌入。
- **极角排序**：将每行表示为二维点 `(u₁[i], u₂[i])`，按极角 `a_i = atan2(u₂[i], u₁[i])` 排序，把环展开成一维执行序列，角度相邻的行倾向于共享更多 K/V 块。选 r=2 的理由是：两维已足以捕获粗粒度邻域结构，且是能通过极角化为全序的最小嵌入（r≥3 无廉价且旋转鲁棒的线性化方案）。
- **无矩阵中心化子空间迭代（MFCSI，算法 1）**：不显式构造 `M̃` 或 M_B×M_B 的 Gram 矩阵，中心化仅作为两个稀疏矩阵–向量乘的秩-1 修正（`M̃^T X = M^T X − (1/m)c(1^T X)` 等），每次迭代仅 O(nnz)，几何收敛，T 取 5–15 即可（因极角排序对平面内旋转与符号翻转不变）。

### 第二阶段：NNZ 引导的波内时间对齐
- 在第一阶段排序后按每 W 行分桶，桶内按 NNZ 降序排序。
- 效果：波次边界处"长行接短行"互补分配，限制执行偏斜累积，使相邻波次中访问相似 K/V 块的行在更短复用距离内完成访问，将第一阶段的"空间重叠机会"转化为"时间上的实际复用"。

### 运行时协调与自适应跳过
- **算法 2**：逐头独立处理——先 Stage 1 全局排序并分桶，再 Stage 2 桶内按 NNZ 降序细化，拼接得到最终置换 `P_h`。
- **自适应跳过**：三类情况跳过重排——(1) 短序列 K/V 工作集可完全放入 L2；(2) 掩码过稀疏，剩余工作量不足以摊销开销；(3) 相邻行本身已高度相似。通过从掩码提取轻量统计量并结合离线剖析的核延迟与重排成本，自动判断是否启用。
- **语义保持**：仅置换查询与掩码行，每行仍访问完全相同的 K/V 块，输出经逆置换恢复原序，不修改稀疏算法与后端内核。

### 实现要点
- 集成于 vLLM-Omni，新增两个 PyTorch 算子（重排、逆重排）。
- 在 A40/FlashInfer 上，将原生"优先 K/V 头维度"的调度改为"优先查询序列维度、K/V 头串行执行"（仿 FlashAttention4），避免多头并发争抢 L2。

## 6. 主要结论与发现

- WaveAlign 将 L2 缓存命中率从 **28.48%–36.35% 提升至 79.38%–89.06%**，HBM 读取流量降低 **80.71%–92.11%**。
- 核级加速最高 **1.25×**（H100 上 XAttention），端到端生成加速最高 **1.17×**（Wan2.1-T2V-14B），LTX2.3 上最高 1.14×。
- A40 因 L2 仅 6MB，对行排序更敏感：O+WA 最高达 1.599×（XAttention）/1.520×（SpargeAttn），O+Seq+WA 组合最优（相比 Original 最高 1.635×/1.601×）。
- Roofline 分析显示 WaveAlign 使四种稀疏核从内存带宽受限跨越"脊点"回到计算受限区域。
- 消融表明两阶段互补：Stage 1 单独仅带来约 1.03× 加速、L2 命中率升至 34.88%–44.47%；Stage 2 单独贡献更大（1.091×–1.147×，L2 至 68.35%–78.71%）；两者结合最优。
- 自适应跳过在短序列（25K/49K/98K）和低保留密度（1.7%/6.7%）时正确回退，避免负收益；从 197K、14.5% 密度起启用并取得 1.14×–1.20× 加速。
- 与通用重排算法相比，WaveAlign 是唯一同时具备有效局部性提升（L2 命中率 76.72%）与可接受在线开销（19.85ms，净加速 1.210×）的方法；Hypergraph/MinHash/LSH 虽提升 L2 但预处理开销巨大（甚至导致整体变慢），Clustering 开销低但几乎无局部性改善。
- 生成质量（PSNR、SSIM、LPIPS、VBench ImgQual/SubCons）在重排前后**完全一致**，验证了语义保持性。

## 7. 优点（方法与实验设计亮点）

- **即插即用、零侵入**：仅置换查询与掩码行并逆置换输出，不改稀疏算法与后端内核，兼容 FlashAttention4、FlashInfer 等，可直接集成到 vLLM-Omni。
- **理论扎实**：将重排形式化为优化问题，用 SVD 低秩嵌入与 Eckart–Young 定理给出"最优低维距离保持"的理论依据，而非启发式；中心化步骤的必要性有清晰论证。
- **极低开销**：MFCSI 无矩阵、仅 O(nnz)/迭代，T 仅需 5–15；重排开销仅占 WaveAlign 总注意力延迟的 1.1%–3.2%（H100）。
- **两阶段互补设计巧妙**：Stage 1 解决"空间重叠机会"，Stage 2 解决"时间复用实现"，消融清晰证明两者缺一不可。
- **自适应保护机制**：避免在短序列/高稀疏度下因重排开销造成性能回退，体现了工程实用性。
- **实验维度丰富**：跨架构、跨模型、跨稀疏方法、跨序列长度，并包含与通用重排算法的横向对比、NCU 剖析、Roofline 与掩码可视化，论证链条完整。
- **发现具有普适价值**："稀疏注意力变为内存带宽受限"这一洞察对后续稀疏注意力系统优化具有指导意义。

## 8. 不足与局限

- **算力信息缺失**：未报告

GPU 总数量、总实验时长、能耗与成本等汇总性算力统计，读者无法据此估算复现该工作所需的资源规模；仅有单次推理延迟作为参照。
- **端到端覆盖不完整**：端到端实验中排除了 MInference 与 FlexPrefill（理由是掩码构造成本过高），因此"1.17×/1.14× 端到端加速"只在 XAttention 与 SpargeAttn 上得到验证，对掩码构造成本更重的稀疏方案，WaveAlign 的实际收益（及其重排开销是否仍可忽略）尚不明确。
- **嵌入维度 r=2 的选择偏启发式**：虽然论文论证了 r=2 是"能廉价线性化为全序的最小维度"，但并未给出 r 与 L2 命中率/加速比之间的定量权衡曲线，也未讨论在 L2 更小或掩码结构更复杂时是否应改用 r=3 配合空间填充曲线等其他线性化方案。
- **逐头独立排序，缺乏跨头协同**：算法 2 对每个头单独求置换，未利用不同头之间 K/V 访问集合的相似性做联合优化；若多头共享部分 K/V 块，跨头对齐可能带来额外的 L2 复用空间，但这会显著增加求解复杂度，论文未探讨该折中。
- **硬件参数强绑定**：波大小 W 由 SM 数量与每 SM 的 CTA 数决定（H100 为 132、A40 为 168），自适应跳过的阈值也来自离线剖析，因此部署到 L2 容量、SM 数不同的新设备（如消费级 GPU、多卡张量并行场景）时需要重新校准，论文未给出自动标定方法。
- **任务域验证较窄**：实验全部集中于视频扩散 Transformer 的 T2V 生成，未在长上下文 LLM 解码/预填充、多模态长序列等同样受注意力带宽瓶颈困扰的场景上验证，方法的外推性有待检验。
- **质量评估的局限**：PSNR/SSIM/LPIPS/VBench 只能证明"重排前后一致"（语义保持性），并不能反映稀疏注意力本身相对密集注意力的质量损失，因此无法判断 WaveAlign 是否在质量—效率权衡曲线上优于"降低稀疏度换取带宽节省"这一朴素替代方案。
- **统计严谨性**：除 NCU 剖析取三次运行中位数外，端到端与核级延迟均未报告多次随机种子的方差或置信区间，加速比的稳定性缺乏量化说明；与通用重排算法的对比也仅覆盖单一序列长度与配置。
- **近似最优性无界**：原问题为 NP-hard，两阶段近似（SVD 排序 + NNZ 分桶）虽在实验中有效，但论文未给出相对最优解的近似比或下界，理论上无法保证在分布外掩码上仍接近最优。

## 9. 总体评价与启示

- **贡献定位**：WaveAlign 的价值不在于提出新的稀疏注意力算法，而在于指出并修补了稀疏注意力系统栈中被长期忽视的一环——**稀疏化把瓶颈从算力搬到了内存带宽，而这一搬移本身是可以被"数据布局"再次搬回去的**。这是一个典型的"系统与算法协同"贡献。
- **方法论层面**：将"提升缓存复用"转化为"对稀疏掩码做距离保持的低维嵌入与一维排序"，并用 SVD + Eckart–Young 定理给出可解释的最优性依据，思路干净且开销极低，具备被后续工作借鉴的形式化范式价值。
- **工程层面**：零侵入、即插即用、自适应回退三点使其具备真实部署价值，尤其是在 L2 稀缺的边缘/消费级 GPU 上收益更显著（A40 上最高 1.6×），说明该方法对硬件差异有正向适应性。
- **对后续研究的启示**：
  1. 稀疏注意力加速的评测应同时报告 FLOPs 削减率与实测加速比，并给出带宽/缓存层面的归因分析；
  2. 查询行重排序可与更激进的缓存管理策略（如 K/V 块驻留、跨层预取、多卡间 L2 分区）结合；
  3. 跨头、跨层的联合置换与调度是尚未开采的优化空间；
  4. 将该思路迁移到 LLM 长上下文解码、MoE 稀疏路由等同样面临"离散访问 + 负载错位"的负载，可能具有普适潜力。
