## 摘要
视频生成在内容创作与娱乐领域具有广泛的应用。扩散Transformer提升了生成视频的质量，但随着视频分辨率和时长的增加，对时空token的注意力计算变得越来越昂贵。我们提出DraftAttention2，一个无需训练的框架，利用低分辨率草稿注意力图来联合选择注意力块并分配其数值精度。具体而言，空间二维平均池化和最大池化的查询与键捕获互补的区域统计量，以估计块重要性；共享排序将更高精度分配给重要块，将较低精度分配给较不重要但保留的块，并在可配置预算下跳过其余块。我们的分析将稀疏化误差与注意力加权量化误差分离，确立了何时用低比特计算恢复被跳过的交互能够收紧输出误差上界。这一分析促使在低精度下保留更多交互，同时为具有更大注意力质量的块保留更高精度。为了将这些细粒度分配转化为实际加速，我们进一步开发了融合的操作数准备，以及一个具有精度特定阶段的单一注意力核，在不同精度间共享数据移动、softmax统计量和输出累加。实验表明，我们的方法相比现有高效视频生成方法实现了更优的质量-效率权衡。值得注意的是，其优势在少步视频扩散中尤为明显，在该场景下，将稀疏性与4位和8位混合精度计算相结合，可显著提升生成质量，同时保持显著加速。代码可在 https://github.com/anemoi-project/anemoi 获取。

## Abstract
Video generation has broad applications in content creation and entertainment. Diffusion transformers have advanced the quality of generated videos, but attention over spatiotemporal tokens becomes increasingly expensive as video resolution and duration increase. We present DraftAttention2, a training-free framework that uses the low-resolution draft attention map to jointly select attention blocks and assign their numerical precision. Specifically, spatial 2D average- and max-pooled queries and keys capture complementary regional statistics to estimate block importance, and a shared ranking assigns higher precision to important blocks, lower precision to less important retained blocks, and skips the rest under configurable budgets. Our analysis separates sparsification error from attention-weighted quantization error, establishing when recovering skipped interactions with low-bit computation tightens the output-error bound. This analysis motivates retaining more interactions at low precision while reserving higher precision for blocks with larger attention mass. To translate these fine-grained assignments into practical speedups, we further develop fused operand preparation and a single attention kernel with precision-specific phases, sharing data movement, softmax statistics, and output accumulation across precisions. Experiments demonstrate that our method achieves a superior quality-efficiency trade-off over existing efficient video generation methods. Notably, its advantage is particularly pronounced for few-step video diffusion, where jointly combining sparsity with 4- and 8-bit mixed-precision computation substantially improves generation quality while retaining significant acceleration. Code is available at https://github.com/anemoi-project/anemoi

  - 现有加速路线分为两类：**稀疏注意力**（保留部分交互）与**低比特量化**（提升矩阵乘法吞吐），二者可互补结合。
  - 已有块级混合精度方法（如ThriftAttention、BMAttn）多为二值保留/跳过的扩展，缺乏对**稀疏与精度联合分配**的系统性理论指导。
- **整体含义**：论文提出免训练框架 DraftAttention2，将“是否保留块”的二元决策推广为“跳过 / 低精度计算 / 高精度计算”的**联合稀疏–精度分配**问题，用低分辨率草稿图同时指导块选择与数值精度分配，在保持生成质量的同时显著加速DiT推理。

## 2. 方法论

### 2.1 核心思想
- 构造**低分辨率草稿注意力图**（draft attention map），以区域（region）为基本单位，联合决定每个查询–键区域对是跳过、低精度计算还是高精度计算。
- 关键洞察：**适度重要的交互用低比特计算恢复，可能比直接稀疏化更有利于收紧输出误差上界**；而最高精度的预算应留给注意力质量最大的块。

### 2.2 关键技术细节

**（1）空间分组与草稿注意力**
- 将每帧划分为连通区域 $\{R_a\}$，token数平衡且有容量上界。
- 对每个区域构造平均描述子 $\bar{Q}_a$ 与逐通道最大描述子 $Q_a^{\max}$，键同理。
- 草稿注意力图（公式2）：
  $$A = (1-\lambda)\,\mathrm{softmax}\Big(\frac{\bar{Q}\bar{K}^\top}{\sqrt{d}}\Big) + \lambda\,\mathrm{softmax}\Big(\frac{Q^{\max}(K^{\max})^\top}{\sqrt{d}}\Big)$$
  - 平均池化保留区域平均logit；最大池化提供均值之外的通道变异信息；$\lambda$ 控制二者贡献，$\lambda=0$ 退化为纯平均引导。

**（2）联合分配算法（Algorithm 1）**
- 在head内对所有 $R^2$ 个区域对按 $A_{ab}$ 降序排序。
- 给定head级配额 $T_{16}, T_8, T_4$：前 $T_{16}$ 个分配给16位路径，接下来 $T_8$ 个给INT8，再接下来 $T_4$ 个给NVFP4，其余跳过。
- 总保留预算 $T = T_{16}+T_8+T_4$；由于排序在整个head内进行，不同查询区域可拥有不同数量的保留块与不同精度组合，在共同head预算下自适应。

**（3）理论分析**
- **Lemma 3.3（注意力加权量化误差）**：将输出误差分解为稀疏化项与量化项：
  $$\|\mathbf{O}^{\text{dense}}_u - \hat{O}_u\|_2 \le \underbrace{2V_{\max}\delta_u}_{\text{稀疏化}} + \underbrace{m^{(8)}_u\varepsilon_8 + m^{(4)}_u\varepsilon_4}_{\text{量化}}$$
  其中 $\delta_u$ 为被丢弃的密集注意力质量，$m^{(p)}_u$ 为分配给各精度的保留注意力质量。
- **Proposition 3.4（从稀疏到混合精度）**：在保留相同16位支撑的前提下，v2用低比特恢复部分被v1跳过的交互，其误差界优于v1的条件为：
  $$\tau_8\varepsilon_8 + \tau_4\varepsilon_4 < 2V_{\max}\,\tau\,(1-\delta_{v2})$$
- **Theorem 3.6（重要性引导精度分配）**：固定保留支撑与精度配额，当 $0\le\varepsilon_8\le\varepsilon_4$ 时，将16位分配给 $T_{16}$ 个最大注意力质量的块、INT8给接下来 $T_8$ 个、NVFP4给剩余，可使误差上界最小化。这为按草稿分数排序分配精度提供了理论依据。

**（4）硬件高效执行**
- **融合操作数准备**：采用紧凑的 ragged 2D 空间分区（优先最小总周长，保持空间局部性），将Q/K重排、平均/最大池化、量化融合为单一核；V的重排与转置也融入操作数打包。
- **相位执行**：对每个查询块，将保留的键块按 NVFP4 → INT8 → 16位 分组，在单一注意力核内顺序处理。精度切换次数 $n_{\text{switch}} = \max(n_{\text{phase}}-1,0) \le 2$，与保留块数无关。
- **跨精度累加**：所有相位共享FP32行最大值、指数和与输出累加器（在线softmax）；相位边界通过轻量重缩放（如公式8的进入/退出变换）保持数值一致性，最终只归一化一次，避免逐精度输出写入与额外合并核。

## 6. 主要结论与发现

- **质量–效率权衡更优**：在HunyuanVideo和MiniMax-H3上，DraftAttention2的稀疏配置达到最高 **2.38×** 和 **2.33×** 加速，优于同类稀疏基线；在与SpargeAttention、SageAttention3匹配速度下，生成质量与密集输出保真度更高。
- **混合精度有效**：小比例高精度预算能降低与密集输出的误差；纯低比特在零稀疏度时仍存在无法通过减少稀疏消除的量化误差，而选择性高精度可缓解。
- **少步扩散优势突出**：在4步与8步MiniMax-H3上，由于去噪步数少、误差难以被后续步骤修正，联合稀疏+4/8位混合精度相比纯稀疏方法在相似加速下显著提升质量与保真度（如4步下PSNR从稀疏基线的约19.2–19.6提升至22.38）。
- **MaxPool带来稳定增益**：平均+最大混合草稿在相同块预算下改善误差–延迟权衡，并在固定稀疏度与精度预算下提升VBench表现。
- **理论意义**：验证了“适度重要交互用低比特恢复”可收紧误差上界，且按注意力质量排序分配精度是最优的。

## 7. 优点

- **方法层面**：
  - 免训练、即插即用，可适配现有视频扩散模型。
  - 将稀疏与混合精度统一到**同一重要性排序**下，允许不同查询区域自适应地获得不同保留块数与精度组合，比固定比例或二值决策更灵活。
  - 理论分析严谨，从误差分解推导出低比特恢复的有利条件与精度分配的最优排序，为设计提供依据。
- **工程层面**：
  - 融合操作数准备避免了重复的全局内存搬运，池化描述子与量化操作数一次生成。
  - 相位化执行使精度切换次数上界为2，与块数无关；跨精度共享在线softmax状态，避免逐精度输出与合并核。
  - 紧凑ragged 2D分区在保持空间局部性的同时减少padding（每帧小于一个块）。
- **实验层面**：
  - 覆盖两个主流模型与少步生成这一实用场景，对比方法多样，指标全面（质量+保真度+速度）。
  - 开源代码，便于复现与推广。

  - **评测范围**：主要围绕 VBench 与像素/感知相似度，缺少人类主观评测、文本–视频对齐的细粒度失败案例分析，以及长视频中时序一致性的专项度量。
  - **基线覆盖**：与部分更新的稀疏注意力或量化工作（如面向视频 DiT 的最新方法）未做对比，且部分基线需要按其超参重新调优，比较可能受调参公平性影响。
  - **可复现细节**：延迟测量的批大小、精度（FP16/BF16）、是否启用 torch.compile 或 CUDA Graph 等工程设置未完全披露，跨平台速度数字的可比性受限。

## 9. 总体评价与启示

- **定位**：DraftAttention2 是一篇典型的“系统 + 理论”型加速工作，其价值不在于提出全新的注意力机制，而在于把**稀疏化与混合精度量化统一为一次重要性排序下的资源分配问题**，并用误差分解给出该分配为何合理的解释。
- **最核心的贡献**：将“保留 / 跳过”的二值决策扩展为“跳过 / 低精度 / 高精度”的三值决策，并指出**低比特计算可以作为稀疏化的“误差补偿”而非仅是吞吐优化手段**——这是与 ThriftAttention、BMAttn 等工作的关键区别，也是其在少步扩散场景中收益最明显的原因。
- **工程与理论的配合**：相位化执行（切换次数 ≤ 2）、跨精度共享在线 softmax 状态、融合操作数准备，三者共同保证了“算法上更细粒度的分配”不会在实现上被调度与内存搬运开销吃掉，这是方法能真正落地的前提。
- **对后续研究的启示**：
  1. **自适应超参**：可将 $\lambda$ 与配额 $T_{16}/T_8/T_4$ 建模为受延迟预算约束的优化问题，用少量校准样本在线求解，替代人工配置。
  2. **跨步误差建模**：把单步误差界嵌入去噪轨迹的误差传播分析，有望解释并进一步放大少步场景下的优势。
  3. **更一般的资源维度**：当前在“精度”维度上做分配，同一框架原则上可扩展到 KV 缓存驻留层级、注意力头剪枝、token 合并等其他资源维度。
  4. **硬件无关性**：若低比特格式可映射到更通用的后端（如 INT8/FP8 的通用内核），方法的适用范围将显著扩大。
- **适用建议**：对于**去噪步数少、单步误差难以被后续步骤修正**的实时视频生成场景，该方法收益最大；对于步数很多、对最终质量极度敏感的场景，建议保留较高比例的高精度预算，并优先在低注意力质量区域启用稀疏化。
