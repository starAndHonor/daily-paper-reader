## 摘要
近期关于锚定扩散语言模型的工作通过使用有监督的重要 token 目标来塑造中间潜在空间，从而改进去噪。在这项工作中，我们引入基于时间（自监督）的锚定，它无需此类目标即可学习并复用潜在锚点。我们的关键观察是，锚点编码了干净序列的持久属性，例如其语义意图、全局结构或中间计划。尽管随着 token 画布的演化，其隐藏表示会变得过时，但其语义内容在邻近的扩散时间步之间仍然有用。这是通过一个两阶段架构实现的：一个相对昂贵的锚网络生成潜在缓存状态，一个轻量级去噪网络在每个反向步骤中使用融合模块，将缓存的潜在状态与当前状态智能地结合。这赋予锚定一种潜在空间缓存的解释：锚网络被周期性地评估，而其缓存表示会在多个反向步骤中复用。我们将该框架实例化为 TADM:Post-train 和 TADM:Pretraining：前者对预训练 DLM 进行时间锚定化，后者在预训练期间学习基于时间的锚点。在 DiffusionGemma-26B 上应用时，TADM:Post-train 在多个数学、代码和 STEM 基准（GSM8K、AIME26、GPQA-Diamond、LiveCodeBench-v6、HumanEval、MMLU-Pro）上将吞吐量提高约 49% 至 79%。TADM:Pretraining 相对于标准单阶段 DLM 将 Transformer 层计算量最多减少 38%，实测吞吐量比 ADLM 最多高出 73%。

## Abstract
Recent work on anchored diffusion language models improves denoising by shaping an intermediate latent space with supervised important-token targets. In this work, we introduce time-based (self-supervised) anchoring, which learns and reuses latent anchors without requiring such targets. Our key observation is that anchors encode persistent properties of the clean sequence, such as its semantic intent, global structure, or intermediate plan. Although their hidden representations become stale as the token canvas evolves, their semantic content remains useful across nearby diffusion times. This is implemented through a two-stage architecture consisting of a relatively expensive anchor network that generates the latent cache state and a lightweight denoising network that intelligently combines the cached latent state with the current state at each reverse step using a fusion module. This gives anchoring a latent-space caching interpretation: the anchor network is evaluated periodically, while its cached representation is reused across multiple reverse steps. We instantiate this framework as TADM:Post-train, which time-anchorizes pretrained DLMs, and TADM:Pretraining, which learns time-based anchors during pretraining. Applied to DiffusionGemma-26B, TADM:Post-train improves throughput by approximately 49% to 79% on several math, code, and STEM benchmarks (GSM8K, AIME26, GPQA-Diamond, LiveCodeBench-v6, HumanEval, MMLU-Pro). TADM:Pretraining reduces Transformer-layer computation by up to 38% relative to a standard single-stage DLM, achieves up to 73% higher measured throughput than ADLM.

# 论文总结：Time-Anchored Diffusion Language Models（TADM）

## 1. 核心问题与研究动机

- **背景**：扩散语言模型（DLM，如 LLaDA、Dream、DiffusionGemma）通过迭代去噪整段序列实现并行生成与双向注意力，具备纠错能力，但**推理时需要对同一画布反复执行整模型前向**，成本远高于自回归解码。
- **已有方案及其局限**：ADLM（Anchored Diffusion Language Model）把去噪网络拆成"锚网络 + 去噪器"两阶段，先预测一批**信息量大的锚 token** 以降低剩余 token 的条件不确定性。但其训练**依赖任务相关的重要 token 监督信号**，标注未必可得，可扩展性受限。
- **本文核心问题**：能否**无需显式锚 token 目标**，让模型自行学习"可跨扩散时间步复用"的潜在锚表示？
- **关键观察**：锚点编码的是干净序列的**持久属性**（语义意图、全局结构、中间计划）。随着 token 画布演化，锚点的**隐藏表示会"过时"**，但其**语义内容在邻近扩散时刻仍然有效**。
- **整体含义**：该观察把"锚定"重新解释为一种**潜在空间缓存（latent-space caching）**——不是去检测哪些 KV 状态没变（如 dKV-cache、d²cache），而是**学习一个可被复用、并可用当前状态修正的潜状态**。

## 2. 方法论

### 2.1 核心思想与模型分解
- 把去噪网络拆为四个组件：
  - **轻量共享网络** `S_θS`：每步都执行，编码当前画布；
  - **昂贵锚网络** `A_θA`：承载大部分计算量，**仅周期性执行**；
  - **微型融合模块** `Φ_ϕ`：把当前表示与缓存锚融合；
  - **轻量去噪网络** `D_θD`：每步都执行，输出干净 token 分布。
- 标准"新鲜"前向：`c_t = S(z_t)` → `h_t = A(c_t)` → `x_θ = D(h_t)`。

### 2.2 锚缓存与融合（算法流程）
- 在**锚刷新步 `t'`**：计算并缓存 `h_{t'} = A(S(z_{t'}))`。
- 在后续步 `t < t'`（锚网络被跳过）：`c_t = S(z_t)`，经融合模块得到修正锚表示
  `h̃_{t|t'} = h_{t'} + g_ϕ(c_t, h_{t'}) ⊙ Δ_ϕ(c_t, h_{t'})`，再 `x_θ(z_t, z_{t'}) = D(h̃_{t|t'})`。
- **推理策略（Anchor-Cache Inference）**：锚缓存每 `K` 步刷新一次，共享网络与去噪器每步执行。
- **成本模型**：`C_full = T(L_S+L_A+L_D)`，`C_cache = T(L_S+L_D) + ⌈T/K⌉·L_A`，相对成本 ≈ `(L_S+L_D+L_A/K)/(L_S+L_A+L_D)`。**K 越大，越省算力**，形成可调的质量–算力权衡。

### 2.3 训练目标
- 理想目标是缓存诱导分布下的损失 `L_cache = E_{(t,t')~π_K} E_{(z_t,h_{t'})~d_{θ,πK}}[ℓ(x_θ(z_t,z_{t'}), x)]`，但需在训练中跑反向生成，成本高，故分两条路线近似：

- **TADM:Post-train（后训练路线）**
  - 基于 DiffusionGemma（USDM）。为缓解训练/推理分布不匹配，采用 **rollout 构造**：采样缓存年龄 `k ∈ {0,1,2}` 与噪声态 `z_{t'}`，投影到采样网格后**先算一次锚并缓存**，再用固定缓存锚执行 k 步反向转移（**stop-gradient**），随后重新前向并开启自动微分。
  - 损失：`L_cache = E[L_CE + λ_KD · D_KL(p_{θ0}(·|z̃_t) ‖ x̂)]`，`λ_KD = 1`，第二项为对冻结教师的知识蒸馏，防止输出分布被破坏。
  - **只需训练融合模块**（本文仅 3.1M 参数），主干冻结。

- **TADM:Pretraining（预训练路线）**
  - 从零训练时不用 rollout（轨迹太差且昂贵），改用**解析式前向加噪** `q(z_{t'}|z_t)` 生成陈旧锚状态；采用吸收态掩码扩散（π = m），以 ReMDM 的重掩码后验为参考。
  - 缓存式反向过程分解为 `p_θ(z_s | z_t, z_{t'})`，即去噪预测 `x_θ(z_t, z_{t'})` 显式条件于更早（更噪）的锚状态。
  - **定理 5.1（T-ANELBO）**：`−log p_θ(x) + γL_Anchor ≤ L_T-ANELBO`，其中扩散项权重 `λ_t = (1−σ_t)(α_t−α_s)/(1−α_t)`。该目标由重建项、先验项、时间锚定扩散项与可选锚监督项组成。
  - **`γ = 0` 即完全自监督**（无需锚 token 目标）；`γ > 0` 时可叠加监督锚信号。锚 token 选为在 `z_{t'}` 中被掩码位置的干净 token 目标。

### 2.4 关键设计细节
- **融合模块（后训练版）**：采用**成对注意力（paired attention）**，同时缓存锚刷新步的**浅层表示 C₀** 与深层锚 H₀；对当前浅层 C 与 C₀ 使用同一归一化尺度与投影，构造 `M_{t,t'} = ϕ(Z,U) − ϕ(Z₀,U)`，再用逐 token 门控 `g` 做残差更新。
  - **恒等性保证**：当 `C = C₀` 时 `M = 0`，融合输出精确等于缓存锚 `H₀`；且 `W₂`、`b₂` 零初始化，使训练起点等价于冻结主干。
- **预训练融合模块**：门控残差 MLP，`h̃ = LN(h_{t'} + g ⊙ Δ)`，输出投影零初始化。
- **时间采样**：预训练中 `t` 连续采样，`K ∈ {1,2,4,8}`、`T ∈ {128,…,4096}`，缓存年龄 `k ~ U{0,…,K−1}`，`t' = min(1, t + k/T)`，使训练时的陈旧度与推理对齐。
