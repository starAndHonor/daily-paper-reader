## 摘要
扩散模型在生成任务中取得了显著成功，但其固有的顺序采样过程带来了严重的计算瓶颈。近期的时域并行（Parallel-in-Time, PinT）求解器尝试通过在时间步滑动窗口上并行生成来缓解这一问题，仅当逐步变化稳定时才推进窗口。然而，这种重叠窗口机制迫使网络重复评估相同的时间步。当迭代之间的输入变化极小时，这些冗余评估会导致显著的计算浪费。为解决这一低效问题，我们提出 ParaAnya，一种与并行采样算法无关的输出缓存机制，可减少函数评估次数（NFE）。ParaAnya 缓存扩散模型的输入-输出对，并在重叠时间步复用缓存输出。通过仅将缓存未命中的时间步分派给 GPU 工作进程，我们的方法消除了冗余计算，同时保留了底层算法更新规则的结构。我们将 ParaAnya 集成到四种代表性并行采样算法中，并在 Stable Diffusion v1.5 上评估其性能。在八块 GPU 上使用 DDIM 评估的四个并行采样器中，ParaAnya 相比未缓存的对应方法提供了 1.30--2.43 倍加速，并将 NFE 最多减少 70.1%，相比单 GPU 串行采样最高可达 5.62 倍加速，同时保持相当的 CLIP 分数。

## Abstract
Diffusion models have achieved remarkable success in generative tasks, but their inherently sequential sampling process introduces a severe computational bottleneck. Recent Parallel-in-Time (PinT) solvers attempt to mitigate this by parallelizing generation across a sliding window of timesteps, advancing the window only when step-wise changes stabilize. However, this overlapping window mechanism forces the network to repeatedly evaluate the same timesteps. When the input variations between iterations are minimal, these redundant evaluations lead to significant computational waste. To address this inefficiency, we propose ParaAnya, an output cache mechanism agnostic to the parallel sampling algorithm that can reduce the number of function evaluations (NFE). ParaAnya caches input-output pairs of diffusion models and reuses the cached output at overlapping timesteps. By dispatching only cache-miss timesteps to GPU workers, our approach eliminates redundant computation while preserving the structure of the underlying algorithms' update rules. We integrate ParaAnya into four representative parallel sampling algorithms and evaluate its performance on Stable Diffusion v1.5. Across four parallel samplers evaluated with DDIM on eight GPUs, ParaAnya provides $1.30$--$2.43\times$ speedups over their uncached counterparts and reduces NFE by up to 70.1\%, reaching up to a $5.62\times$ speedup over single-GPU serial sampling while maintaining comparable CLIP scores.

# ParaAnya 论文总结

## 1. 核心问题与整体含义

- **背景**：扩散模型在图像、音频生成等任务上表现优异，但采样过程本质上是顺序的——每一步去噪都依赖上一步的结果，导致单样本延迟难以通过常规批推理缩短（批推理只提升吞吐，不缩短单条轨迹）。
- **已有方案**：时域并行（Parallel-in-Time, PinT）方法沿扩散轨迹的时间维度暴露并行性，把多个时间步放入滑动窗口并发处理，仅在窗口前部状态收敛后才推进窗口。代表性方法分两类：
  - Picard 迭代类：ParaDiGMS、ParaTAA、ParaSolver；
  - Parareal 类：SRDS。
- **核心痛点**：滑动窗口的重叠机制会迫使网络对同一时间步反复求值。当相邻迭代的输入潜变量变化很小时，这些重复评估纯属计算浪费。
- **量化证据**：作者对 100 步 DDIM、30 条提示词进行 profiling，发现 **39.93%** 的 drift 评估是在重访时间步，且该时间步的潜变量平均变化小于 0.05。
- **研究意义**：论文指出 PinT 采样中的冗余并非并行的必然代价，而是一个可用系统级缓存消除的浪费；且该缓存应做到**算法无关、即插即用、不改变原算法更新规则**。

## 2. 方法论

### 2.1 核心思想
- 在 drift 评估（网络前向）之前放置一个**输出缓存**，把每个时间步最近一次被评估的「输入潜变量 + 网络输出」成对缓存。
- 当当前潜变量与缓存输入足够接近时直接复用缓存输出；否则才真正调用网络。
- 只把**缓存未命中**的时间步批量分发给 GPU worker，从而在保持原求解器更新规则不变的前提下减少函数评估次数（NFE）。

### 2.2 关键技术细节与流程
- **缓存结构**：协调器维护映射 $C: t \mapsto (\hat{x}_t, \hat{\varepsilon}_t)$，其中 $\hat{\varepsilon}_t = \varepsilon_\theta(\hat{x}_t, t)$，保证缓存不变性。
- **差异度量**：用逐元素 $L_1$ 范数除以潜变量维度 $D$，得到每坐标平均绝对偏差
  $$\delta_t^k = \frac{1}{D}\|x_t^k - \hat{x}_t\|_1$$
  归一化设计使阈值 $\tau_{cache}$ 在不同潜变量分辨率下可比。
- **命中/未命中划分**：对当前窗口 $W$ 划分
  - 命中集 $H^k = \{t \in W : \delta_t^k < \tau_{cache}\}$
  - 未命中集 $M^k = W \setminus H^k$
  - 首次进入窗口的时间步一律视为未命中。
- **输出组装**：$t \in H^k$ 用缓存 $\hat{\varepsilon}_t$，$t \in M^k$ 才真正调用 $\varepsilon_\theta(x_t^k, t)$；所有未命中项合并为**单次批前向**。
- **缓存更新**：仅对未命中项写回 $C[t] \leftarrow (x_t^k, \varepsilon_t^k)$，保证缓存输出始终对应真实网络评估结果。
- **兼容性**：对 Parareal 类（如 SRDS）的粗/细求解器评估同样适用同一机制，不修改其更新规则。

## 6. 主要结论与发现

- **一致加速**：将 ParaAnya 集成到 4 种 PinT 采样器后，在所有 DDIM 步数配置下 wall-clock 加速比均匹配或优于未缓存版本；相比未缓存对应方法提升 **1.30–2.43×**。
- **NFE 大幅下降**：NFE 最多减少 **70.1%**（如表 3 中 τ=0.1 时从 176 降至 57）。
- **相比单卡串行**：8 卡下最高达 **5.62×** 加速（ParaTAA + ParaAnya，N=100）。
- **质量保持**：CLIP 分数变化极小（SRDS 几乎为 0），说明缓存未损害文本-图像对齐。
- **窗口大小存在权衡**：增大窗口并不总提升加速比——小窗口 GPU 利用率不足，大窗口延长 Picard 预测时域、增加收敛迭代。DDPM 最佳 P=64；DDIM 下 ParaSolver 最佳 P=8、ParaAnya 最佳 P=16。
- **缓存容差可调**：增大 $\tau_{cache}$ 单调增加命中率、降低迭代数与 NFE；但小容差（0.001/0.005）因缓存开销反而比不缓存更慢。**τ=0.05** 在 CLIP 不降的前提下取得 3.08× 加速，是较优折中；τ=0.1 最快（3.56×）但 CLIP 略降至 31.19。
- **硬件扩展性**：所有基线方法在 1–2 卡时甚至出现 sub-1.0× 的负加速，随 GPU 增加转正；ParaAnya 在所有 GPU 数量下都改善基线，例如单卡把 ParaSolver 从 0.41× 提升到 1.02×。

## 7. 优点

- **算法无关、即插即用**：不修改底层求解器的更新规则，可直接接入 Picard 与 Parareal 两大类方法，泛化性强。
- **免训练**：纯推理期系统级优化，不涉及模型微调或再训练，部署成本低。
- **问题定位精准**：先用 profiling（39.93% 冗余评估、变化 <0.05）量化冗余，再设计针对性缓存，动机-方法闭环清晰。

- **实用价值明确**：在 GPU 资源紧张时（1–2 卡）可把负加速转为正加速，对实际部署有直接意义。
