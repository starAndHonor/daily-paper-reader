## 摘要
特征缓存通过用先前计算的激活值的预测替代昂贵的网络评估来加速扩散采样。然而，仅基于过去特征的预测无法直接纳入当前去噪状态的变化。我们研究廉价的、新近计算的特征能否作为观测来校正这些预测。我们提出了一种用于加速冻结扩散模型的观测校正Koopman框架。利用校准轨迹，我们辨识出有限维、时变的Koopman近似，其联合描述浅层与深层网络特征的增量。在加速采样过程中，这些算子预测昂贵的深层特征的演化，而所观测浅层特征的新息则校正预测状态。周期性的完整评估用于刷新观测器，且所有生成模型参数保持不变。该形式化方法使得时间预测与观测校正之间能够进行受控比较。在每个数据集三次10,000张图像的运行中，在相同的四部分步调度下，与逐通道仿射预测相比，我们的方法将配对的Inception特征MSE在CIFAR-10上降低了19.9\%，在十类ImageNet子集上降低了11.9\%。匹配的消融实验将额外4.54\%和4.67\%的降低归因于观测校正。该观测器相较于DDIM-50实现了1.89倍和1.85倍的实测加速，在无需重新训练去噪器的情况下支持更高的参考采样器保真度。

## Abstract
Feature caching accelerates diffusion sampling by replacing expensive network evaluations with predictions from previously computed activations. However, forecasts based only on past features cannot directly incorporate changes in the current denoising state. We investigate whether inexpensive, freshly computed features can serve as observations for correcting these predictions. We introduce an observation-corrected Koopman framework for accelerating frozen diffusion models. Using calibration trajectories, we identify finite-dimensional, time-dependent Koopman approximations that jointly describe the increments of shallow and deep network features. During accelerated sampling, these operators predict the evolution of expensive deep features, while innovations in the observed shallow features correct the predicted state. Periodic full evaluations refresh the observer, and all generative-model parameters remain unchanged. This formulation enables controlled comparisons of temporal prediction and observation correction. Across three 10,000-image runs per dataset, our method reduces paired Inception-feature MSE by $19.9\%$ on CIFAR-10 and $11.9\%$ on a ten-class ImageNet subset relative to channelwise affine prediction under the same four-partial-step schedule. Matched ablations attribute additional reductions of $4.54\%$ and $4.67\%$ to observation correction. The observer achieves $1.89\times$ and $1.85\times$ measured speedups over DDIM-50, supporting improved reference-sampler fidelity without retraining the denoiser.

# Koopman Observers for Diffusion Acceleration 论文总结

## 1. 核心问题与整体含义

- **研究动机**：扩散模型通过反复调用去噪网络生成样本，推理成本高昂。特征缓存（如 DeepCache）通过复用中间激活降低开销，预测方法（如 TaylorSeer、FastCache）进一步外推特征演化。
- **核心问题**：仅基于过去特征的预测无法直接纳入**当前去噪状态**的变化。由于近似误差会改变后续网络输入，历史轨迹的信息性逐渐下降。
- **关键观察**：即使跳过深层计算，部分前向仍可廉价地获得**新鲜的浅层特征**。本文追问：这些浅层特征能否作为**观测（measurements）**来校正深层特征预测？
- **与既有工作的区别**：RACER 用预测分歧调整信任与刷新决策；本文则构建显式的**测量新息**（预测与观测浅层特征之差）来更新未观测的深层状态。
- **整体含义**：将扩散加速形式化为一个**状态估计问题**——深层特征为未观测状态，浅层特征为测量，时变仿射 Koopman 近似提供动力学，观测器用测量新息闭环校正预测。

## 2. 方法论

### 2.1 核心思想

- 将去噪网络划分为浅层计算 $S_\theta$、昂贵深层计算 $D_\theta$ 与最终读出 $R_\theta$。
- 深层特征仅在完整评估步计算；跳过步由因果估计器 $G_k$ 依据历史状态与当前浅层观测给出 $\hat{d}_k$。
- 采用 **Koopman 观测器**结构：预测 → 观测新息校正 → 周期性全量刷新，所有去噪器参数保持冻结。

### 2.2 联合增量可观测量

- 从校准特征增量的二阶矩得到正交通道基 $P_d$、$P_s$，配合归一化尺度 $\sigma_d$、$\sigma_s$，构造联合增量观测：
  - 深层增量投影 $u_k = P_d^\top (d_k - d_{k-1})/\sigma_d$
  - 浅层增量投影 $y_k = P_s^\top (s_k - s_{k-1})/\sigma_s$
  - 联合状态 $v_k = [u_k;\, y_k]$
- 浅层增量 $y_k$ 在部分评估中始终可观测；深层增量 $u_k$ 需要连续两次完整评估才能测得。

### 2.3 离线算子与增益辨识

- 使用完整采样轨迹，按**完整轨迹**划分校准/验证/诊断集，避免同一轨迹的补丁与条件分支跨集泄漏。
- 用仿射 EDMD 式回归辨识时变算子 $(A_{k-1}, b_{k-1})$，并加入**单位先验**正则（偏好增量持续性）。
- 用浅层拟合残差回归深层拟合残差，学习增益 $L_{dk}$，最终增益矩阵 $L_k = [L_{dk};\, I_r]$，保证 $HL_k = I_r$（浅层分量被精确校正）。

### 2.4 观测校正预测流程

- **预测**：$\bar{v}_k = A_{k-1}\hat{v}_{k-1} + b_{k-1}$
- **新息**：$\nu_k = y_k - H\bar{v}_k$
- **校正**：$\hat{v}_k = \bar{v}_k + L_k\nu_k$
- **重构**：$\hat{d}_k = \hat{d}_{k-1} + \sigma_d P_d J\hat{v}_k$
- 校正后的浅层分量满足 $H\hat{v}_k = y_k$；深层分量通过标定的跨特征残差关系更新。

### 2.5 刷新与计算成本

- 每轮预测以**两次连续完整评估**初始化 $\hat{d}_a = d_a$、$\hat{v}_a = v_a$；后续部分步递归应用校正；下一次完整评估对在当前加速样本上重置估计。
- 在线成本近似：$T_{\text{online}} \approx mT_{\text{full}} + (N-m)T_{\text{partial}}$，$T_{\text{partial}}$ 包含浅层计算、投影、预测、校正与保留的读出/采样器操作。

### 2.6 误差传播与理论性质

- 误差递推呈 **Luenberger 观测器**形式：$e_k = (I_{2r} - L_kH)(A_{k-1}e_{k-1} + \rho_k)$，浅层误差分量消失。
- 深层误差递推中，测量通过**耦合块** $A_{yu}$ 传播信息；若动力学块对角（如逐通道模型），$A_{yu}=0$，校正仅作用于残差。
- **命题 1**：在标定残差分布下，使用增益 $L = \Sigma_{uy}(\Sigma_{yy}+\gamma I)^{-1}$ 校正**不会增加**单步均方深层误差；$\gamma=0$ 时为最小二乘最优，误差二阶矩为 Schur 补。该比例衡量深层增量通过浅层增量的可观测程度。
- 作者明确不声称闭环收缩性，误差随 episode 长度累积，故需频繁刷新。
