## 摘要
块扩散语言模型在生成过程中会保留一个大型键值（KV）缓存，并在每个去噪步骤中对其执行注意力计算，这同时限制了内存容量与生成速度。降低这些开销需要决定：哪些历史 token 用于当前块的去噪（选择），以及哪些保留在内存中以供未来块使用（驱逐）。我们提出 MaskAhead，这是一种无需训练的方法，通过单一的基于掩码查询的排序机制同时解决这两项任务。当前块的掩码引导选择，而对即将到来的掩码块的探测引导驱逐。二者均根据 KV 条目对注意力输出的估计贡献对其进行排序。我们的量化变体 Q-MaskAhead 直接基于低位 KV 计算选择与注意力，从而在很大程度上保留被选中的条目。在 Fast-dLLM-v2、DreamReasoner 和 LLaDA2.0-mini 上的实验涵盖了长生成推理、长提示问答以及大海捞针式检索。在长提示问答任务上，相对于稠密推理，MaskAhead 平均将 KV 内存减少 9.5 倍，平均 F1 损失为 1.2 个百分点。Q-MaskAhead 将内存缩减提升至 20.1 倍，平均 F1 损失为 2.3 个百分点。在批大小为 32 的系统性能剖析中，MaskAhead 相对于稠密推理实现了 1.23 倍的端到端加速和 1.68 倍的解码阶段加速。

## Abstract
Block diffusion language models keep a large key-value (KV) cache throughout generation and attend to it at every denoising step, limiting both memory capacity and generation speed. Reducing these costs requires deciding which past tokens to use for denoising the current block (selection) and which to keep in memory for future blocks (eviction). We propose MaskAhead, a training-free method that solves both tasks with a single mask-query-based ranking mechanism. Current-block masks guide selection, while probes of upcoming masked blocks guide eviction. Both rank KV entries by their estimated contribution to the attention output. Our quantized variant, Q-MaskAhead, computes selection and attention directly from low-bit KV, largely preserving the selected entries. Experiments on Fast-dLLM-v2, DreamReasoner, and LLaDA2.0-mini cover long-generation reasoning, long-prompt question answering, and needle-in-a-haystack retrieval. On long-prompt QA, MaskAhead reduces KV memory by $9.5\times$ on average with a 1.2-point mean F1 loss relative to dense inference. Q-MaskAhead increases the reduction to $20.1\times$ with a 2.3-point mean F1 loss. In a batch-32 systems profile, MaskAhead achieves $1.23\times$ end-to-end and $1.68\times$ decode-stage speedups over dense inference.

# MaskAhead 论文中文总结

## 1. 核心问题与研究动机

- **背景**：扩散语言模型（dLLM）通过反复去噪掩码位置实现并行解码，相比自回归生成更快；但并行解码削弱了联合预测 token 之间的依赖，因此当前系统普遍采用**块扩散**（block diffusion）——按块顺序生成，块内并行去噪。
- **代价来源**：块扩散恢复了因果前缀与 KV 缓存，后块复用前块的 K/V。随着提示与回复增长，**长上下文推理要为同一段历史付出两次代价**：
  - 常驻缓存显存持续增大；
  - 每个去噪步都要重复读取更长的前缀。
- **两个本质不同的决策**：
  - **选择（selection）**：当前块剩余去噪步该读哪些历史 token（临时、可刷新）；
  - **驱逐（eviction）**：哪些条目应保留给未来块（不可逆、物理删除后无法恢复）。
- **已有方法的不足**：
  - 稀疏读取类（MAGE、HERALD、SparseD、FlashBlock）只减少读取，**完整缓存仍驻留**在 GPU 或 host 内存；
  - 全注意力 dLLM 的驱逐方法（Sparse-dLLM、MaskKV）不适用于块扩散的"持续追加 + 活跃块内掩码"结构；
  - AR 驱逐方法（H2O、StreamingLLM、Expected Attention、DapQ）必须在缺少未来查询的情况下做保留决策。
- **核心洞见**：块扩散在生成未来块之前就暴露了**掩码查询**——当前块掩码可用于临时读取选择，未来掩码块探针可作为驱逐的"前瞻预测"。MaskAhead 检验这种前瞻证据在"保留不可逆且存储紧张"的场景下是否最有用。

## 2. 方法论

### 2.1 核心思想
- **一个排序机制，两个查询视野**：
  - **当前块掩码查询** → 选择临时读取集 $R_t$；
  - **未来掩码块探针**（block-causal, no-write probe）→ 排序持久保留集 $S_t$；
  - 二者用同一套"注意力输出敏感度"评分规则，按层、按 KV 头独立应用。

### 2.2 评分公式（文字说明）
- 从单条目删除恒等式出发：删除条目 $i$ 并重归一化后，输出变化量为
  $$\|\mathbf{o}_q-\mathbf{o}_{q,-i}\|^2=\frac{p_{q,i}}{1-p_{q,i}}\|\mathbf{v}_i-\mathbf{o}_q\|^2$$
  即**注意力质量相同的条目，其删除对输出的影响也可能不同**。
- 对查询群体 $Q$，定义：
  - 池化注意力 $a_i(Q)=\frac{1}{|Q|}\sum_{q\in Q}p_{q,i}$；
  - 注意力质心 $c(w)=\frac{\sum_j w_j v_j}{\sum_j w_j}$；
  - 价值感知分数 $f_i(w)=w_i\|v_i-c(w)\|^2$，即用"与注意力质心的偏差"加权。
- 两个排序：
  - $s^{\text{read}}_i=f_i(a(Q^{(1)}_t))$，仅用当前块第一步的全掩码查询；
  - $s^{\text{retain}}_i=f_i(\sum_{m=1}^{M}a(Q^{(m)}_t))$，聚合当前块 + 未来 $M-1$ 个块的探针查询。
- 注意：单条目恒等式只解释动机，不构成子集选择问题的最优解保证。

### 2.3 算法流程
1. 对活跃缓存 $I_t$ 跑当前块第一步全掩码步骤，收集 $Q^{(1)}_t$；
2. 用 $s^{\text{read}}$ 取 TopK 得到 $R_t$，gather 到临时读取缓冲区；
3. **若为驱逐检查点**：在不写入持久 KV 的情况下探测 $t+1,\dots,t+M-1$ 块的掩码；用 $s^{\text{retain}}$ 排序，保护初始 4 个 sink 位置与 64 长度近期窗口；把持久 KV 物理压缩到预算 $C_t$；
4. 用 $R_t$ 完成剩余去噪步，最终化当前块并按原始逻辑位置追加 KV。
- 关键超参：驱逐间隔 $E=4$ 块，探测视野 $M=4$ 块（含当前块 + 未来 3 块）；前 2 层保持 dense 以做读取选择；读取预算 $k_t=\min(N_t,\max(128,\lceil0.05N_t\rceil))$，保留预算 $C_t=\max(256,\lfloor0.1N_t^{\text{seen}}\rfloor)$。

### 2.4 Q-MaskAhead（量化变体）
- 直接以 **4-bit KV** 存储并从中计算选择与注意力，**不保留 bf16 shadow cache**；
- Key 采用 32 位置分组、逐通道非对称量化；Value 采用 32 通道分组、逐 token 量化，配 fp16 元数据；不完整 key 组保持 bf16；
- 驱逐后完整 key 组按位拷贝、部分组重分组；
- 意义：把"选择、保留、精度"三个维度解耦，验证紧凑缓存下排序是否仍然稳定。
