## 摘要
稀疏注意力是降低扩散 Transformer 在长序列生成任务（如视频和高分辨率 3D 资产生成）中延迟的主要方法。然而，现有方法在高稀疏度下会降低生成质量和保真度。通过受控的 oracle 比较，我们将这种退化归因于三个来源：token 分组带来的约束、不准确的交互选择，以及 token 被丢弃时损失的注意力贡献。在此分析指导下，我们提出元缓存稀疏注意力（Meta-Cached Sparse Attention，MC-Sparse），这是一个无需训练的框架，它在选择单个键值（KV）token 的同时，将相似查询组织成按 tile 对齐的分组，以实现高效的 GPU 执行。MC-Sparse 缓存元数据，包括查询分组、使用精确注意力概率选出的 KV 索引，以及稠密注意力与稀疏注意力输出之间的残差，并在后续去噪步骤中复用这些元数据。在视频和 3D 生成模型上，MC-Sparse 相比现有稀疏注意力基线，对稠密注意力输出具有更高的保真度，并实现更大的去噪加速，且无明显质量下降。相对于稠密注意力，它在 Minimax-H3-Base 上实现 1.80 倍去噪加速，在 3D 资产生成上实现 2.32 倍加速，且质量损失均可忽略不计。

## Abstract
Sparse attention is a primary approach to reducing the latency of diffusion transformers in long-sequence generation tasks, such as video and high-resolution 3D asset generation. However, existing methods can degrade generation quality and fidelity at high sparsity levels. Through controlled oracle comparisons, we trace this degradation to three sources: constraints imposed by token grouping, inaccurate interaction selection, and the attention contributions lost when tokens are discarded. Guided by this analysis, we propose Meta-Cached Sparse Attention (MC-Sparse), a training-free framework that selects individual key-value (KV) tokens while organizing similar queries into tile-aligned groups for efficient GPU execution. MC-Sparse caches metadata comprising query groups, KV indices selected using exact attention probabilities, and residuals between dense and sparse attention outputs, and reuses them across subsequent denoising steps. Across video and 3D generation models, MC-Sparse achieves higher fidelity to dense-attention outputs and larger denoising speedups than existing sparse-attention baselines, without visible quality degradation. Relative to dense attention, it delivers a $1.80\times$ denoising speedup on Minimax-H3-Base and a $2.32\times$ speedup on 3D asset generation, both with negligible quality loss.

## 1. 核心问题与整体含义
- **研究动机**：扩散 Transformer（DiT）在视频、3D 资产生成等长序列任务中表现突出，但注意力随 token 数呈二次增长，成为推理延迟瓶颈。
- **核心问题**：稀疏注意力可降低延迟，但现有方法在高稀疏度下会明显损失生成质量与对稠密注意力输出的保真度，形成“稠密-稀疏注意力差距”。
- **关键分析**：作者通过受控 oracle 比较，将差距拆解为三类误差：
  - **结构绑定误差**：KV token 被绑定为块、同一查询组共享选择，限制可保留交互。
  - **选择误差**：用 mean pooling 等近似分数选择交互，无法准确反映真实注意力质量。
  - **丢弃尾部误差**：被丢弃 token 仍带非零注意力贡献，造成输出偏差。
- **整体含义**：论文提出免训练框架 MC-Sparse，同时追求更细粒度选择、更准确选择和丢弃贡献补偿，在高稀疏度下缩小与稠密注意力的保真差距，并提升实际 GPU 执行效率。

## 2. 方法论
- **核心思想**：
  - 不再以整个 KV 块为基本选择单位，而是选择**单个 KV token**。
  - 将相似 query 组织为**tile 对齐的等大小组**，兼顾选择质量与 GPU 效率。
  - 在少数 anchor 步计算精确选择和稠密-稀疏残差，后续 reuse 步复用元数据，摊销成本。
- **基础公式**：
  - 稠密注意力：`O_full = Softmax(QK^T / sqrt(d)) V`，`A_ij` 为 query i 到 key j 的注意力权重。
  - 稀疏注意力通过 mask `M` 限制交互：`O_sparse = Softmax(QK^T / sqrt(d) + M)V`。
- **精确 KV 选择**：
  - 对查询组 `G_g` 和预算 `K`，oracle 选择目标为最大化组内累计稠密注意力质量：
    `S*_g = argmax_{|S|=K} sum_{i in G_g} sum_{j in S} A_ij`。
  - 该方法基于输出误差与丢弃注意力质量相关的动机，避免 mean pooling 打分偏差。
- **结构绑定误差缓解**：
  - **Token-level KV selection**：跨块边界选择单个 KV token，kernel 在线 gather 所选 K/V，不重打包为块。
  - **Tile-aligned query grouping**：使用 Fast PDDP 的 median-split 版本，递归按主方向投影并在中位数处切分，直到每组恰好 `C` 个 query，匹配 GPU query tile 大小。
- **选择误差缓解与跨步复用**：
  - 仅在 anchor 步计算精确选择，后续步骤复用 query 分组和 KV 索引。
  - 论文发现，复用较早步的精确选择优于每步重新计算 mean-pooled 选择。
- **丢弃尾部误差补偿**：
  - anchor 步记录残差：`R_tau = O_full_tau - O_sparse_tau`。
  - reuse 步输出：`O_hat_t = SparseAttn(Q_t, K_t, V_t; G_tau, S_tau) + R_tau`。
  - 残差与 query 组、KV 索引按同一刷新计划更新。
- **算法流程**：
  - 若为 anchor 步：运行 FlashAttention 稠密注意力，构造 query 组，执行精确 KV 选择，计算稀疏输出和残差，缓存 `(G, S, R)`。
  - 若为 reuse 步：用当前 Q/K/V 和缓存元数据执行 token-sparse attention，并加回残差。
- **高效实现**：
  - Fast PDDP：批处理 power iteration，按树深度并行，减少内存与耗时。
